The offline public root and approved scanner policy are configured here by protected maintainer review. Independent signed reviews live in `reviews/SHA256.json` and must name the exact candidate commit.

No permissive example root, unsigned clean result or bypass switch is provided. Root/admission/review keys are separate from online catalog and author login credentials. Real review signers attest the complete reports; formatting green alone does not admit a package.

The external worker must verify its protected workflow/code identity. A PR workflow's own status is not sufficient provenance, because contributors can propose workflow changes. CODEOWNERS/branch protection and the canonical VOOL catalog signatures remain mandatory.
