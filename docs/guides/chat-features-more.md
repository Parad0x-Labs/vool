# More chat features

This page adds to [Chat features](chat-features.md).

## Under each message

Buttons sit under every message:

* **Copy** copies the message exactly as it was written. Under an answer you also get
  **Copy text** (plain text, without formatting) and, where your system allows it,
  **Copy rich** (with formatting, for apps such as a word processor).
* **Try again**, under an answer, asks the same question again as a new message. The earlier
  answer stays in the chat.
* **Edit**, under your own message, puts it back in the message box so you can change it and
  send it again. Attachments are not carried over: attach them again before you send.
* **Download this answer as PDF** saves that one answer as a PDF file.
* **Report** and the thumbs-down button report a wrong answer or another problem with it.
  You see the report text, with private details removed, before anything is sent.

Code blocks in an answer have their own copy button, which copies the code exactly.

Right-click a picture in the chat for **Copy image** and **Copy path**. On a Mac you also get
**Open in Preview** and **Show in Finder**.

When you have scrolled up, **↓ Latest** jumps back to the newest message.

## Chat list actions

Each chat in the sidebar has, next to **Rename**, **Archive** and **Delete**:

* **Pin chat to the top** (and **Unpin chat**) keeps it above the others.
* **Set chat emoji or colour** marks it so it is easy to spot. **Clear emoji & colour**
  takes the mark off.
* **Move to project** moves the chat into one of your projects.

Each project in the sidebar has **New chat in this project**, **Set project emoji or
colour**, **Rename project**, **Delete project** and **Reveal folder in Finder** (**Show
folder** on Linux), which opens the project's folder.

## If VOOL restarts in the middle of a task

When VOOL was closed or restarted before it finished answering, the chat says **Reply
interrupted: VOOL stopped before it finished answering.**, with what you asked.

* **Ask again** sends the same question again in this chat.
* **Resume or cancel…** appears when VOOL saved the work so far. It opens the Activity panel,
  where a card, **Task interrupted by application restart**, offers **Resume** (carry on from
  the last point VOOL saved), **Cancel task** and **Review activity** (the saved steps and
  records of what had already happened).

Nothing carries on by itself: you choose.
