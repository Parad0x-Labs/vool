# See what leaves your computer

When a chat first sends files or remembered information to a cloud model, VOOL shows a
preview: **See what leaves your computer**. It shows the complete request and where it goes.
Sensitive content and project rules can also ask for a preview. *Nothing is sent until you
choose.*

## Choose what to send

* **Send as shown** sends exactly the request you reviewed. If the request changes before it
  goes, you review it again.
* **Send only these parts** lets you pick sections.
* **Replace names and details** swaps recognized email addresses, phone numbers, account and
  card numbers, street addresses and names from your contacts for placeholders. This runs on
  this computer, and the placeholders in the answer are filled back in here. It is best
  effort: check the preview. Formats VOOL does not recognize, and pictures, may still contain
  personal details.
* **Use a local model instead** appears when a ready local model can handle the request. It
  starts again on this computer with the original task and never falls back to a cloud model.
* **Don't send** stops without sending anything.

## Set your rules

In **Settings → Privacy & Permissions**, **Before files go to cloud** chooses when previews
appear and holds each project's cloud rules. A rule can keep a source on this computer, ask
each time, or allow cloud use. You review and confirm a rule change before it applies. Once a
project has rules, a source with no matching rule stays on this computer. A document cannot
confirm or widen these rules.

## Look back and compare

**See what was sent** under an answer opens the exact request, while the chat is open, for up
to five minutes. Copies are not stored. Forget and deleting the chat remove these previews, so
an older answer may have nothing to show.

From there, **Try this with another model** runs the same prepared request on up to two other
models you have set up. Each cloud request gets its own preview, and your spending limits
apply. The comparison shows the measured time to first text, total time, tokens and billed cost
where they are known; an unknown charge stays unknown. **I prefer this answer** saves your
choice on this computer only. It does not change which model answers.

## Good to know

* An Offline chat and the **Web lookups** switch keep their own limits; these previews do not
  replace them.
* Web searches, email and other connected services have their own destinations and controls.
  These previews cover what goes to cloud models, not every kind of online activity.
* A preview does not make a harmful document safe.
