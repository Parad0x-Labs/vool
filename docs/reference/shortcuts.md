# Keyboard shortcuts

`⌘` on macOS, `Ctrl` on Windows and Linux.

| Action | Shortcut |
| --- | --- |
| New session | `⌘ N` |
| Command palette | `⌘ K` |
| Switch model | `⌘ M` |
| Toggle workspace panel | `⌘ J` |
| Stop the current run | `Esc` |
| Settings | `⌘ ,` |
