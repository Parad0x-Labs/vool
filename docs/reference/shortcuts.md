# Keyboard shortcuts

`⌘` on macOS, `Ctrl` on Linux.

| Action | Shortcut |
| --- | --- |
| Send the message | `Enter` |
| New line in the message | `Shift Enter` |
| Bring back your last message to fix and resend (empty message box) | `↑` |
| New chat | `⌘ N` |
| Command palette | `⌘ K` |
| Open the model menu | `⌘ M` |
| Show or hide the Activity panel | `⌘ J` |
| Find a chat by name in the sidebar | `⌘ F` |
| Search this chat | `⌘ Shift F` |
| Next / previous match in chat search | `Enter` / `Shift Enter` |
| Choose your pet | `⌘ /` |
| Settings | `⌘ ,` |
| Stop the current answer | `Esc` |
| Close a menu, dialog or search | `Esc` |

`Esc` stops a running answer only when nothing else is open; otherwise it closes what is open
first. In **Settings**, `⌘ F` jumps to **Search settings**.
