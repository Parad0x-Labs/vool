# Translation glossary

Generated by `python3 tools/docs/check_translations.py glossary --write` from
`tools/docs/translation_glossary.json` and the app catalogs in `core/i18n/catalogs/`.
Do not edit by hand. Glossary version: **2026-11-12.1**.

One agreed word per thing, per language, so the docs say what the app and the
Mac actually show. The rules are in [TRANSLATOR_RULES.md](TRANSLATOR_RULES.md).

## Never translated

| Term | Rule |
| --- | --- |
| VOOL | The product name. Never translated or transliterated: Latin letters in every script. |
| Parad0x Labs | The company name, spelled with a zero. Never translated. |
| OpenRouter, OpenClaw, Hermes, LoCoMo, GPT-4o, Discord, GitHub | Names of other products and services. Never translated. |
| Apple, Mac, macOS, Apple Silicon, Intel, Linux, Ubuntu, Windows, PowerShell, MacBook Pro | Platform and hardware names. Never translated; chip names such as Apple M1 stay as Apple writes them. |
| Python, PyTorch, LoRA, glibc, DMG, SHA-256, sudo, GPU, CPU | Technical names. Never translated. |

Also never translated, in any language: anything inside code blocks or `inline code`, URLs, commands, file and folder names, version numbers, port numbers and checksums. Digits stay Western digits (0-9); a language that writes a decimal comma may use it for measured values such as 82,7 %, never in a version number.

## Where the words come from

* App labels come from the app's own catalog for the language in `core/i18n/catalogs/`, looked up by key, so a page uses exactly the words the app shows. If the English text behind a key changes, the checker stops until this glossary is updated.
* macOS labels are Apple's own localized wording, read on 2026-11-12 from Apple's localized support pages: "Open a Mac app from an unknown developer" (Mac User Guide, current macOS and macOS 14), "Install and uninstall apps" and "Identify your Mac model". Spanish follows Spain, Portuguese follows Brazil, Chinese is Simplified Chinese.
* macOS has no Lithuanian interface, so Lithuanian pages keep Apple's English words. Apple's Hindi pages keep About This Mac in English, so Hindi pages do too.
* The Done and Cancel buttons of the macOS warning are not listed: Apple's localized words for them were not verified, so a translation says to close the message instead of naming a button.
* Certify is the 0.7.7 button, which the app showed in English in every language. When the English pages switch to 0.8 and name Use this model instead, translations use the catalog words for `settings.local_models.use`.
* Terms are the words these docs chose once per language; where the app already has a word for the concept, the term follows the app.
