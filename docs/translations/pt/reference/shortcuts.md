# Atalhos de teclado

`⌘` no macOS, `Ctrl` no Windows e no Linux.

| Ação | Atalho |
| --- | --- |
| Nova sessão | `⌘ N` |
| Paleta de comandos | `⌘ K` |
| Trocar de modelo | `⌘ M` |
| Mostrar ou ocultar o painel do espaço de trabalho | `⌘ J` |
| Parar a execução atual | `Esc` |
| Configurações | `⌘ ,` |
