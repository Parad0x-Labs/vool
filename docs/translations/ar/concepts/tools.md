# الأدوات

الأداة إجراء تستطيع بيئة التشغيل اتخاذه نيابة عنك — قراءة ملف، أو تشغيل
أمر، أو البحث في مجلد.

## قابلة للفحص بطبيعتها

يسجّل كل استدعاء أداة ما طُلب، وما جرى تشغيله، وما عاد. ويمكن قراءة أي تشغيل
لاحقًا دون إعادة تشغيله.

## الإذن

يتوقف تشغيل الأداة فورًا أو السؤال أولًا على الوضع الذي اخترته وعلى الإجراء نفسه.
تبدأ المحادثة الجديدة في وضع «يدوي»، حيث يسأل كل تغيير أولًا. وفي وضع «تلقائي»، يعمل إنشاء الملفات وتعديلها
والأوامر وإجراءات الشبكة دون سؤال، بينما تظل عمليات الحذف والكتابة فوق الملفات
والتثبيت وcommit وpush في Git والنشر وإرسال الرسائل والمدفوعات وتغيير
الإعدادات تتطلب السؤال. وفي كل الأوضاع، لا تعمل أدوات الملفات إلا داخل [مساحة العمل](workspaces.md)،
وتقرأ أدوات البحث والجلب الموارد العامة دون كتابة أي شيء، ولا تُقرأ الأسرار المخزّنة
أبدًا. وتشرح صفحة [الأذونات](permissions.md) الأوضاع الخمسة جميعها وما يسمح به كل زر
موافقة.

```text
tool: read_file
path: src/main.py
result: 412 lines
```
