# اكتشاف المهارات وفحوصات Eyebrow

تحتوي صفحة «المهارات والإضافات» على أربع علامات تبويب: **تصفّح** و**دليل المهارات** و**إضافاتي** و**الأمان**. تعرض «تصفّح» مهارات VOOL الخاصة أولًا، بما فيها 53 مهارة VOOL نصية فقط مضمّنة مع التطبيق، ثم إضافات الكتالوج المراجَعة، ويمكنها البحث عن مستودع GitHub عام عند مراجعة (revision) مثبّتة. ويعرض «دليل المهارات» مهارات فريق VOOL أولًا، فوق اختيارات المحرّرين والمهارات المميزة. يتجاهل البحث حالة الأحرف والفواصل الشائعة؛ وتضيّق عناصر التحكم في الفئة والترتيب القائمة. ويظهر المصدر والترخيص والمراجعة والمتطلبات قبل التنزيل.

## الاستخدام الأول

1. احفظ مفتاح Eyebrow API في علامة التبويب «الأمان»، المتاحة أيضًا ضمن الإعدادات ← مفاتيح API. ويتولى مخزن بيانات الاعتماد الحالي حفظ المفتاح. ولا يختبر الحفظ الاتصال ولا يفحص أي شيء؛ أما «اختبر الاتصال» فيتصل بـ Eyebrow صراحةً.
2. في «تصفّح»، اختر مهارة ووافق على تنزيل محتواها العام وإرسال ذلك المحتوى إلى Eyebrow. يستهلك هذا من حصة الفحص في الخدمة وفقًا لخطتك. ولا تحدث أي إعادة محاولة تلقائية.
3. اقرأ التقرير المُعاد. استجابة HTTP الناجحة وحدها ليست نتيجة نظيفة. ولا يسمح هذا الكتالوج الأولي بالتثبيت إلا مع تقرير `pass` كامل، دون أي ملاحظات ودون أي مخالفات للسياسة. ويتخلص «ارفض» من التنزيل المجهَّز دون تثبيته.
4. اقبل التثبيت بشكل منفصل. يحافظ VOOL على الترخيص، ويثبّت عبر دورة حياة الإضافات الحالية، ويتحقق من الحزمة المراجَعة بالضبط، ويمكّن المهارة. وتظل الأذونات الحالية تحكم كل إجراء قد تقترحه.

الفحص تقييم من جهة مورِّدة لبايتات محددة، وليس ضمانًا للسلامة أو التوافق أو جودة الإجابات. وإدراج مهارة في الكتالوج ليس اعتمادًا للناشر.

## الحدود

لا يأتي المحتوى إلا من مستودعات GitHub عامة عند مراجعة ثابتة من 40 حرفًا، مع ملفات مهارات وتراخيص مثبّتة بـ SHA-256. ولا يوجد في هذا الإصدار دعم للمستودعات الخاصة، ولا لاستخراج الأرشيفات، ولا لسكربتات التثبيت، ولا مستورد لإضافات تنفيذية/MCP. ولا يُرسَل إلى Eyebrow إلا ملف SKILL.md المستقل؛ أما المحادثات المحلية وملفات مساحة العمل وبيانات الاعتماد ومحتويات التراخيص فلا تُرسَل للفحص.

تبقى التنزيلات خاملة حتى المراجعة والقبول. وتربط إيصالات موثّقة محليًا التقريرَ بالمحتوى المثبّت. ويرفض التثبيت المراجعات المنتهية الصلاحية (24 ساعة)، والملفات المجهَّزة المعدّلة، والمجلدات الهدف الموجودة مسبقًا. وتتحقق بيئة التشغيل من حالة دورة الحياة والبايتات المراجَعة قبل إضافة مهارة مُدارة إلى سياق النموذج. والملفات المضافة أو الروابط الرمزية أو المحتوى المتغيّر تجعلها غير متاحة. وتُدرج الإرشادات كاملة أو يُسجَّل صراحةً حذفها لعدم كفاية ميزانية المطالبة؛ ولا تُقتطع التعليمات المفحوصة بصمت.

هذه الفحوصات لا تعزل الشيفرة الخبيثة التي تعمل بالفعل باسم مستخدم نظام التشغيل. ولا تمتد إلى الإضافات التي ثُبّتت يدويًا من قبل. ولا يمنح إيصال الفحص أي إذن تنفيذ جديد أو صلاحية على المحفظة.

## الواجهة البرمجية (API) ومعالجة الإخفاقات

يُعيد `GET /api/addons` حالة الكتالوج والحالة المحلية دون اختبار اتصال أو فحص. ويدعم `POST /api/addons` كلًّا من `save_key` و`remove_key` و`test_key` و`scan` و`install` و`reject`. وتتطلب التعديلات طلبات عبر واجهة الاسترجاع المحلية (loopback)، بصيغة JSON، ومن متصفح من الأصل نفسه؛ ولا تُقبل إلا الحقول الخاصة بكل عملية. وتُرفض عناوين URL والمسارات المصدرية التي يقدّمها المستدعي.

يستخدم العميل طلب مصدر المهارة المضمَّن في Eyebrow v1 عند `/v1/scan`، مع مصادقة bearer، وأصل HTTPS ثابت، ودون إعادة توجيه، وبحجم استجابة محدود، ودون إعادات محاولة تلقائية. ويُستخدم `/v1/version` لاختبار الاتصال الصريح. مرجع الواجهة البرمجية: https://eyebrow.cc/api/reference .

تشمل الإخفاقات المصنّفة النموذجية:

| الرمز | المعنى / الاسترداد |
| --- | --- |
| `eyebrow_key_missing` / `eyebrow_unauthorized` | احفظ المفتاح أو استبدله. |
| `eyebrow_quota` | راجع حصة الخدمة قبل إعادة المحاولة. |
| `eyebrow_timeout` / `eyebrow_unreachable` | لا إعادة محاولة تلقائية؛ وقد يستهلك الفحص الذي انتهت مهلته من الحصة. |
| `eyebrow_invalid_report` / `eyebrow_no_coverage` | الأدلة غير مكتملة؛ ولا يُمكَّن أي شيء. |
| `addon_source_changed` / `addon_changed` | البايتات المثبّتة أو المراجَعة مختلفة؛ لا تفعّلها. |
| `review_untrusted` / `review_expired` | احصل على مراجعة جديدة قبل التثبيت. |
| `addon_already_installed` | حوفظ على الملفات الموجودة. والاستبدال التلقائي غير مطبَّق. |

## القيود الحالية والتحقق

لا يوجد تحديث تلقائي، ولا مستورد كتالوج عشوائي، ولا سير عمل للإصلاح أو إعادة التثبيت في المكان لحزمة موجودة تغيّرت. ولا تتيح الواجهة استعادة المراجعة المعلّقة بعد إعادة تشغيل التطبيق. ونصوص الواجهة الجديدة تُعرض حاليًا بالإنجليزية بديلًا؛ ولا يُدّعى اكتمال الترجمات.

تختبر الاختبارات الآلية دورة الحياة الحقيقية، وتحميل المهارات، ومعالجات الواجهة البرمجية، وواجهة المتصفح المخدومة، مع تنزيلات عامة وردود Eyebrow محاكاة صراحةً. وهي تثبت سلوك بيئة التشغيل والواجهة، لا توفّر Eyebrow الفعلي ولا كفاءة النموذج. ويبقى الفحص الحقيقي بمفتاح فعلي وقبول التطبيق المُحزَّم الأصلي من فحوصات الإصدار. ولا حاجة إلى أي مفتاح أو استدعاء خدمة مدفوعة لتشغيل هذه الاختبارات.
