# تشغيل نموذج محلي

## تثبيت بيئة تشغيل

يتواصل VOOL مع خادم نماذج محلي. ويتضمن تطبيق macOS مشغّل النماذج المحلية الخاص به، لذا
يمكنك تخطي هذه الخطوة على Mac. أما على Linux وفي التثبيت من الشيفرة المصدرية، فثبّت خادمًا مثل
Ollama، وشغّله، ونزّل (pull) نموذجًا.

```bash
ollama serve
ollama pull qwen2.5-coder:7b
```

## توجيه VOOL إليه

افتح **الإعدادات ← النماذج والمزودون**. تُكتشف بيئات التشغيل المحلية العاملة تلقائيًا. اختر
نموذجًا فيتغير مؤشر الوضع إلى «محلي».

## اعتمده مرة واحدة

لا يكتب النموذج المحلي الإجابات إلا بعد اعتماده. افتح **الإعدادات ← النماذج والمزودون ← النماذج المحلية**،
وسجّل النموذج، ثم اختر **Certify**. يُجري الاعتماد فحصًا قصيرًا للأدوات على
جهازك؛ لا يُنزَّل أي شيء ولا يُتصل بأي جهة. وإلى أن يجتاز النموذج الفحص، لا يسمح له VOOL
بكتابة إجابات نهائية.

## اختيار الحجم

| حجم النموذج | الذاكرة المطلوبة | مناسب لـ |
| --- | ---: | --- |
| 3B | ~4 GB | التعديلات القصيرة، والأسئلة السريعة |
| 7–8B | ~8 GB | الاستخدام العام، ومعظم أعمال البرمجة |
| 14B | ~16 GB | الاستدلال الأطول |
| 32B+ | 32 GB أو أكثر | الأعمال الأثقل، وهو أبطأ |

{% hint style="info" %}
تقلّل الإصدارات المكمَّمة (quantised) استهلاك الذاكرة بشكل كبير. فنموذج 7B بدقة 4 بت يعمل بارتياح في نحو
5 GB.
{% endhint %}

## إذا كان بطيئًا

* اختر نموذجًا أصغر أو أكثر تكميمًا.
* أغلق التطبيقات الأخرى التي تستهلك ذاكرة كبيرة.
* قصّر السياق — فالملفات الأقل في الطلب تعني معالجة أقل.
