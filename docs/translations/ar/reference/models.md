# النماذج المدعومة

لا يأتي VOOL مع نموذج مضمّن — إذ يُنزَّل أول نموذج محلي في أول مرة تستخدمه فيها. وهو يتصل ببيئات التشغيل والمزوّدين الذين تختارهم.

## بيئات التشغيل المحلية

تُكتشف Ollama وllama.cpp وvLLM وMLX تلقائيًا. ويمكن توجيه VOOL يدويًا إلى بيئات تشغيل أخرى توفّر
نقطة نهاية متوافقة مع OpenAI على localhost.

## المزوّدون السحابيون

يُوصَل إلى النماذج السحابية بمفتاحك، ومن جهازك. واختيار أحدها يضع التطبيق في
الوضع السحابي (يعرض المؤشر اسم المزوّد) — راجع [محلي وسحابي](../concepts/local-and-cloud.md).

يُعدّ [OpenRouter](../guides/openrouter.md) الاتصال المنفرد الأوسع: مفتاح واحد، ومزوّدون
كثيرون.

## الاختيار

| العمل | خيار معقول |
| --- | --- |
| ملفات خاصة، دون شبكة | محلي، 7B أو أكبر |
| البرمجة اليومية | نموذج برمجة محلي بحجم 7–14B |
| الاستدلال الطويل | نموذج سحابي أكبر |
| التحكم في التكلفة | المحلي أولًا، والسحابي عندما يستحق ذلك |
