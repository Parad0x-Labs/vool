# اختصارات لوحة المفاتيح

`⌘` على macOS، و`Ctrl` على Windows وLinux.

| الإجراء | الاختصار |
| --- | --- |
| محادثة جديدة | `⌘ N` |
| لوحة الأوامر | `⌘ K` |
| تبديل النموذج | `⌘ M` |
| إظهار لوحة مساحة العمل أو إخفاؤها | `⌘ J` |
| إيقاف التشغيل الحالي | `Esc` |
| الإعدادات | `⌘ ,` |
