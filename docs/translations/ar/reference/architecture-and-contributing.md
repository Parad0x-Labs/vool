# البنية والمساهمة

## البنية في صفحة واحدة

VOOL بيئة تشغيل لسطح المكتب تعطي الأولوية للعمل المحلي، مع نواة مخدومة:

```text
┌──────────────────────────────────────────────┐
│ Native window / browser console              │
│  (served pages; the console you use)         │
├──────────────────────────────────────────────┤
│ Served runtime (local HTTP API)              │
│  routing → tool execution → answers          │
├───────────────┬──────────────┬───────────────┤
│ Local models  │ Cloud lanes  │ Wallet (opt)  │
│ (Ollama etc.) │ (your keys)  │ pilot lanes   │
├───────────────┴──────────────┴───────────────┤
│ Records: receipts, ledgers, fault registry   │
│ Local storage (SQLite under your profile)    │
└──────────────────────────────────────────────┘
```

المبادئ التي تفرضها الشيفرة:

* **محلي افتراضيًا؛ وسحابي بمفتاحك.** لا توجد المسارات السحابية إلا ببيانات اعتمادك
  وسقوفك.
* **جهة مرجعية واحدة لكل قرار.** لكل من الأذونات والإنفاق وخروج البيانات إلى الشبكة عقد
  مالك واحد؛ وتُصنَّف الأعطال عند الحد الذي يملكها.
* **اذكر ما فشل.** تُصنَّف النتائج غير المعروفة على أنها غير معروفة؛ وتذكر حالات الرفض ما لم
  يحدث؛ ولا يُستبدل النموذج المثبّت بصمت أبدًا.
* **كل شيء مسجّل.** تكتب استدعاءات الأدوات والموافقات والمدفوعات والتحديثات إيصالات ضمن
  ملف تعريفك.

## إعداد بيئة التطوير

```bash
git clone https://github.com/Parad0x-Labs/vool.git
cd vool
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
pytest tests -q            # the suite
```

توجد ملاحظات المنصات، والتخطيط الكامل لسلسلة الأدوات، وبوابات الإصدار في
وثائق الهندسة الخاصة بالمستودع (`docs/` في جذر المستودع؛ والتفاصيل الداخلية العميقة ليست جزءًا من موقع
الوثائق العام هذا).

## الوثائق: مصدر مرجعي واحد

تُولَّد هذه الوثائق من مصدر **واحد**: مجلد `docs/` في هذا المستودع (بتخطيط GitBook،
و`.gitbook.yaml` في جذر المستودع). ويُبنى موقع الوثائق العام منه. للعمل على الوثائق:

```bash
python3 tools/docs/build_docs.py --src . --out docs-build --base /docs
python3 tools/docs/check_docs_build.py docs-build /docs
python3 -m http.server -d docs-build 8000   # local preview
```

مرجع الأخطاء (`ERROR_BOOK.md`) وبيان تسليم الترجمة
**مُولَّدان من السجلات المرجعية الخاصة ببيئة التشغيل نفسها** — أعد توليدهما، ولا تعدّلهما يدويًا أبدًا:

```bash
python -m tools.generate_error_book
python -m tools.generate_localization_handoff
```

يُفشل اختبار مركّز عملية البناء إذا انحرفت الملفات المولَّدة عن سجلاتها المرجعية.

## المساهمة

* تغييرات صغيرة ومراجَعة؛ ويجب أن يطابق كل ادعاء في الوثائق الشيفرة كما شُحنت.
* حافظ على الرموز والمعرّفات الثابتة — فهي تعيش أطول من الإصدارات.
* لا توسّع أي صلاحية بصمت أبدًا: فالإذن الجديد أو مسار الإنفاق أو مسار الخروج إلى الشبكة تغييرٌ
  في التصميم، لا مجرد ترقيع.
* تُوثَّق قيود الإصدار التجريبي ولا تُخفى — وإذا وجدت قيدًا غير موثَّق، فذلك خطأ
  في الوثائق.
