# रसीदें

रसीद किसी रन का स्थायी रिकॉर्ड है: कौन-से टूल बुलाए गए, किन इनपुट के साथ, और हर एक ने क्या लौटाया।

## ये क्यों हैं

किसी एजेंट का अपने ही काम का सारांश एक दावा है। रसीद वह रिकॉर्ड है जिससे आप उस दावे को जाँच सकते हैं।

## इसमें क्या होता है

| फ़ील्ड | मतलब |
| --- | --- |
| `tool` | कौन-सा काम चला |
| `input` | उसे क्या दिया गया |
| `result` | उसने क्या लौटाया |
| `time` | वह कब चला |

रसीदें इसी कंप्यूटर पर VOOL के रनटाइम होम में रखी जाती हैं ([कॉन्फ़िगरेशन](../reference/configuration.md) देखें), आपके प्रोजेक्ट फ़ोल्डरों में नहीं। कोई रसीद आपकी मशीन से सिर्फ़ ऐसी बग रिपोर्ट के अंदर बाहर जाती है जिसका पूर्वावलोकन आप देखते हैं और जिसे भेजना आप चुनते हैं ([बग रिपोर्टिंग और गोपनीयता](../trust/bug-reporting.md) देखें)।
