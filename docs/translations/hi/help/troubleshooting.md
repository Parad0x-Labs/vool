# समस्या निवारण

## macOS ऐप खोलने से मना करता है

यह अपेक्षित है: ऐप अभी नोटराइज़्ड नहीं है। पहले चेकसम जाँचें, फिर
**सिस्टम सेटिंग्ज़ → गोपनीयता और सुरक्षा** खोलें और **फिर भी खोलें** पर क्लिक करें। macOS 14 पर आप इसकी जगह
VOOL पर कंट्रोल-क्लिक करके **खोलें** चुन सकते हैं।

## Windows

इस रिलीज़ में Windows के लिए कोई डाउनलोड नहीं है। Windows पर VOOL सोर्स से इंस्टॉल होता है और यह
प्रयोगात्मक है; [इंस्टॉल गाइड](../getting-started/install.md#सोर्स-से-इंस्टॉल-करें) देखें।

## कोई स्थानीय मॉडल सूची में नहीं है

1. पक्का करें कि रनटाइम चल रहा है।
2. पक्का करें कि कम से कम एक मॉडल डाउनलोड (pull) हो चुका है।
3. पक्का करें कि पोर्ट वही है जिसकी VOOL को उम्मीद है।

```bash
curl http://localhost:11434/api/tags
```

अगर इससे कुछ नहीं लौटता, तो रनटाइम चालू नहीं है।

## जवाब धीमे हैं

आम तौर पर वजह उपलब्ध मेमोरी के मुकाबले मॉडल का आकार होता है।
[स्थानीय मॉडल चलाना](../../../guides/local-models.md) देखें।

## नए सिरे से शुरू करना

VOOL बंद करें और [कॉन्फ़िगरेशन](../../../reference/configuration.md) में बताई गई कॉन्फ़िगरेशन डायरेक्टरी
हटा दें। वर्कस्पेस की फ़ाइलों को नहीं छुआ जाता।
