# स्थानीय मॉडल चलाना

## रनटाइम इंस्टॉल करें

VOOL एक स्थानीय मॉडल सर्वर से बात करता है। macOS ऐप में स्थानीय मॉडल चलाने वाला उसका अपना प्रोग्राम शामिल है, इसलिए Mac पर आप यह चरण छोड़ सकते हैं। Linux और सोर्स से किए गए इंस्टॉल पर Ollama जैसा कोई सर्वर इंस्टॉल करें, उसे शुरू करें, और एक मॉडल डाउनलोड (pull) करें।

```bash
ollama serve
ollama pull qwen2.5-coder:7b
```

## VOOL को उससे जोड़ें

**सेटिंग्स → मॉडल और प्रदाता** खोलें। चल रहे स्थानीय रनटाइम अपने आप पहचाने जाते हैं। कोई मॉडल चुनें, और मोड संकेतक स्थानीय पर बदल जाता है।

## इसे एक बार सर्टिफ़ाई करें

स्थानीय मॉडल सर्टिफ़ाई होने के बाद ही जवाब लिखता है। **सेटिंग्स → मॉडल और प्रदाता → स्थानीय मॉडल** खोलें, मॉडल रजिस्टर करें, फिर **Certify** चुनें। सर्टिफ़ाई करना आपकी मशीन पर एक छोटी टूल जाँच चलाता है; कुछ भी डाउनलोड नहीं होता और किसी से संपर्क नहीं किया जाता। जब तक कोई मॉडल पास नहीं होता, VOOL उसे अंतिम जवाब लिखने नहीं देता।

## आकार

| मॉडल का आकार | ज़रूरी मेमोरी | किसके लिए उपयुक्त |
| --- | ---: | --- |
| 3B | ~4 GB | छोटे संपादन, जल्दी के सवाल |
| 7–8B | ~8 GB | सामान्य इस्तेमाल, ज़्यादातर कोडिंग |
| 14B | ~16 GB | लंबा तर्क |
| 32B+ | 32 GB या ज़्यादा | भारी काम, धीमा |

{% hint style="info" %}
क्वांटाइज़्ड बिल्ड मेमोरी काफ़ी कम कर देते हैं। 4-बिट पर 7B मॉडल लगभग 5 GB में आराम से चलता है।
{% endhint %}

## अगर यह धीमा हो

* छोटा या ज़्यादा क्वांटाइज़्ड मॉडल चुनें।
* ज़्यादा मेमोरी लेने वाले दूसरे ऐप्लिकेशन बंद करें।
* संदर्भ छोटा करें — अनुरोध में कम फ़ाइलें, यानी प्रोसेस करने को कम।
