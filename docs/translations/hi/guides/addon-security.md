# कौशल खोजना और Eyebrow जाँच

कौशल और प्लगइन पेज पर चार टैब हैं: **ब्राउज़**, **कौशल कोडेक्स**, **मेरे ऐड-ऑन** और **सुरक्षा**। ब्राउज़ पहले VOOL के अपने कौशल दिखाता है, जिनमें ऐप के साथ आए 53 सिर्फ़-टेक्स्ट VOOL कौशल शामिल हैं, फिर समीक्षा किए गए कैटलॉग ऐड-ऑन, और किसी सार्वजनिक GitHub रिपॉज़िटरी को एक पिन किए गए रिविज़न पर खोज सकता है। कौशल कोडेक्स पहले VOOL टीम के कौशल दिखाता है, संपादक की पसंद और चुनिंदा कौशल से ऊपर। खोज बड़े-छोटे अक्षरों और आम विभाजकों को अनदेखा करती है; श्रेणी और क्रम के नियंत्रण सूची को छोटा करते हैं। स्रोत, लाइसेंस, रिविज़न और ज़रूरतें डाउनलोड से पहले दिखती हैं।

## पहली बार इस्तेमाल

1. सुरक्षा टैब में एक Eyebrow API कुंजी सहेजें; यह सेटिंग्स → API कुंजियाँ में भी उपलब्ध है। कुंजी का ज़िम्मा मौजूदा क्रेडेंशियल स्टोर के पास रहता है। सहेजना कनेक्शन की जाँच नहीं करता और कुछ भी स्कैन नहीं करता; "कनेक्शन जाँचें" साफ़ तौर पर Eyebrow से संपर्क करता है।
2. ब्राउज़ में कोई कौशल चुनें, और उसकी सार्वजनिक सामग्री डाउनलोड करने और वह सामग्री Eyebrow को भेजने की स्वीकृति दें। इससे आपके प्लान के अनुसार सेवा का स्कैन कोटा खर्च होता है। अपने-आप कोई दोबारा कोशिश नहीं होती।
3. लौटाई गई रिपोर्ट पढ़ें। सिर्फ़ एक सफल HTTP जवाब साफ़ नतीजा नहीं है। यह शुरुआती कैटलॉग इंस्टॉलेशन की अनुमति सिर्फ़ पूरी `pass` रिपोर्ट के साथ देता है, बिना किसी निष्कर्ष और बिना किसी नीति-उल्लंघन के। "अस्वीकारें" तैयार रखे गए डाउनलोड को इंस्टॉल किए बिना हटा देता है।
4. इंस्टॉलेशन को अलग से स्वीकार करें। VOOL लाइसेंस सुरक्षित रखता है, अपनी मौजूदा प्लगइन लाइफ़साइकल से इंस्टॉल करता है, समीक्षा किए गए ठीक उसी पैकेज को सत्यापित करता है और कौशल को चालू करता है। वह जो भी काम सुझा सकता है, उस हर काम पर मौजूदा अनुमतियाँ ही लागू रहती हैं।

स्कैन खास बाइट्स का एक विक्रेता का आकलन है, सुरक्षा, संगतता या जवाबों की गुणवत्ता की गारंटी नहीं। कैटलॉग में शामिल होना प्रकाशक का प्रमाणन नहीं है।

## सीमाएँ

सामग्री सिर्फ़ सार्वजनिक GitHub रिपॉज़िटरी से, एक तय 40-अक्षर वाले रिविज़न पर, SHA-256 से पिन की गई कौशल और लाइसेंस फ़ाइलों के साथ आती है। इस वर्ज़न में कोई निजी रिपॉज़िटरी, आर्काइव निकालना, इंस्टॉल स्क्रिप्ट या एक्ज़िक्यूटेबल/MCP प्लगइन इंपोर्टर नहीं है। Eyebrow को सिर्फ़ अकेली SKILL.md भेजी जाती है; स्थानीय चैट, वर्कस्पेस फ़ाइलें, क्रेडेंशियल और लाइसेंस की सामग्री स्कैन के लिए नहीं भेजी जाती।

डाउनलोड समीक्षा और स्वीकृति तक निष्क्रिय रहते हैं। स्थानीय रूप से प्रमाणित रसीदें रिपोर्ट को पिन की गई सामग्री से बाँधती हैं। इंस्टॉलेशन समय-सीमा पार कर चुकी समीक्षाएँ (24 घंटे), बदली गई तैयार फ़ाइलें और पहले से मौजूद लक्ष्य डायरेक्टरी अस्वीकार करता है। प्रबंधित कौशल को मॉडल संदर्भ में जोड़ने से पहले रनटाइम लाइफ़साइकल स्थिति और समीक्षा किए गए बाइट्स जाँचता है। जोड़ी गई फ़ाइलें, सिमलिंक या बदली गई सामग्री उसे अनुपलब्ध कर देती है। निर्देश पूरे के पूरे जोड़े जाते हैं, या प्रॉम्प्ट बजट कम होने के कारण छोड़े जाने पर यह साफ़ तौर पर दर्ज होता है; स्कैन किए गए निर्देश चुपचाप छोटे नहीं किए जाते।

ये जाँचें ऑपरेटिंग-सिस्टम उपयोगकर्ता के रूप में पहले से चल रहे दुर्भावनापूर्ण कोड को अलग नहीं करतीं। ये पहले से हाथ से इंस्टॉल किए गए प्लगइन पर लागू नहीं होतीं। स्कैन की रसीद से कोई नई निष्पादन अनुमति या वॉलेट अधिकार नहीं मिलता।

## API और विफलता का प्रबंधन

`GET /api/addons` बिना कनेक्शन जाँच या स्कैन के कैटलॉग और स्थानीय स्थिति लौटाता है। `POST /api/addons` में `save_key`, `remove_key`, `test_key`, `scan`, `install` और `reject` उपलब्ध हैं। बदलाव करने वाले अनुरोधों के लिए loopback, JSON और same-origin ब्राउज़र अनुरोध ज़रूरी हैं; सिर्फ़ हर ऑपरेशन के अपने फ़ील्ड स्वीकार किए जाते हैं। कॉलर के दिए स्रोत URL और पथ अस्वीकार किए जाते हैं।

क्लाइंट `/v1/scan` पर Eyebrow v1 का इनलाइन कौशल-स्रोत अनुरोध इस्तेमाल करता है, bearer प्रमाणीकरण, तय HTTPS ऑरिजिन, बिना रीडायरेक्ट, सीमित जवाब आकार और बिना अपने-आप दोबारा कोशिश के। स्पष्ट कनेक्शन जाँच के लिए `/v1/version` इस्तेमाल होता है। API संदर्भ: https://eyebrow.cc/api/reference ।

आम तय विफलताएँ:

| कोड | मतलब / उबरने का तरीका |
| --- | --- |
| `eyebrow_key_missing` / `eyebrow_unauthorized` | कुंजी सहेजें या बदलें। |
| `eyebrow_quota` | दोबारा कोशिश से पहले सेवा का कोटा देखें। |
| `eyebrow_timeout` / `eyebrow_unreachable` | अपने-आप दोबारा कोशिश नहीं होती; टाइम आउट हुआ स्कैन फिर भी कोटा खर्च कर सकता है। |
| `eyebrow_invalid_report` / `eyebrow_no_coverage` | प्रमाण अधूरा है; कुछ भी चालू नहीं होता। |
| `addon_source_changed` / `addon_changed` | पिन किए गए या समीक्षा किए गए बाइट्स अलग हैं; उन्हें सक्रिय न करें। |
| `review_untrusted` / `review_expired` | इंस्टॉलेशन से पहले नई समीक्षा लें। |
| `addon_already_installed` | मौजूदा फ़ाइलें सुरक्षित रखी गईं। अपने-आप बदलना लागू नहीं किया गया है। |

## मौजूदा सीमाएँ और सत्यापन

बदले हुए मौजूदा पैक के लिए कोई अपने-आप अपडेट, मनमाना कैटलॉग इंपोर्टर, या उसी जगह मरम्मत/दोबारा इंस्टॉल करने का वर्कफ़्लो नहीं है। ऐप रीस्टार्ट के बाद लंबित समीक्षा की रिकवरी UI में उपलब्ध नहीं है। नए इंटरफ़ेस टेक्स्ट के लिए अभी अंग्रेज़ी फ़ॉलबैक है; पूरे अनुवाद का दावा नहीं किया जाता।

स्वचालित परीक्षण असली लाइफ़साइकल, कौशल लोडिंग, API हैंडलर और परोसे गए ब्राउज़र UI को साफ़ तौर पर नकली बनाए गए सार्वजनिक डाउनलोड और Eyebrow जवाबों के साथ चलाते हैं। वे रनटाइम और इंटरफ़ेस का व्यवहार साबित करते हैं, Eyebrow की लाइव उपलब्धता या मॉडल की क्षमता नहीं। असली कुंजी वाला स्कैन और नेटिव पैकेज्ड ऐप की स्वीकृति अभी भी रिलीज़ जाँचें हैं। इन परीक्षणों को चलाने के लिए किसी कुंजी या पेड सेवा कॉल की ज़रूरत नहीं है।
