# OpenRouter जोड़ना

OpenRouter एक कुंजी के पीछे कई प्रदाताओं तक पहुँच देता है। VOOL में OpenRouter कुंजी जोड़ी जा सकती है।

## कुंजी जोड़ें

अपने OpenRouter खाते में एक कुंजी बनाएँ, उसे **सेटिंग्स → API कुंजियाँ** में पेस्ट करें और **कुंजी सहेजें** दबाएँ। VOOL, OpenRouter से कुंजी की एक बार जाँच करता है, फिर उसे इस कंप्यूटर पर एक एन्क्रिप्टेड फ़ाइल में रखता है ([सुरक्षा मॉडल](../trust/security.md#कुंजियाँ) देखें)।

## बिलिंग और श्रेय

{% hint style="info" %}
आपका OpenRouter खाता आपका ही रहता है। VOOL आपकी कुंजी से सीधे इसी कंप्यूटर से अनुरोध भेजता है। Parad0x न आपके प्रॉम्प्ट आगे भेजता है, न आपके इस्तेमाल का भुगतान करता है। VOOL का असली इस्तेमाल OpenRouter पर VOOL के सार्वजनिक, समेकित आँकड़ों में दिख सकता है, लेकिन अलग-अलग प्रॉम्प्ट और पहचान प्रकाशित नहीं की जातीं।
{% endhint %}

## कुंजी हटाएँ

**सेटिंग्स → API कुंजियाँ** में कुंजी हटाएँ। अगर आप चाहते हैं कि कुंजी सर्वर की ओर से भी बेकार हो जाए, तो उसे अपने OpenRouter खाते में भी रद्द करें।
