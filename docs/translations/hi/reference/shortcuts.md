# कीबोर्ड शॉर्टकट

macOS पर `⌘`, Windows और Linux पर `Ctrl`।

| काम | शॉर्टकट |
| --- | --- |
| नया सत्र | `⌘ N` |
| कमांड पैलेट | `⌘ K` |
| मॉडल बदलें | `⌘ M` |
| वर्कस्पेस पैनल दिखाएँ/छिपाएँ | `⌘ J` |
| मौजूदा रन रोकें | `Esc` |
| सेटिंग्स | `⌘ ,` |
