# कॉन्फ़िगरेशन

## स्थान

VOOL अपनी सेटिंग्स, चैट, स्मृति और रिकॉर्ड एक ही रनटाइम होम में रखता है:

| इंस्टॉल | रनटाइम होम |
| --- | --- |
| macOS ऐप | `~/Library/Application Support/VOOL/runtime` |
| Linux tarball और सोर्स से किए गए इंस्टॉल | `~/.vool_runtime` |
| Windows (प्रयोगात्मक, सोर्स से) | `%LOCALAPPDATA%\VOOL` |

VOOL शुरू करने से पहले `VOOL_HOME` सेट करने पर उसकी जगह वह फ़ोल्डर इस्तेमाल होता है। स्टार्टअप लॉग दिखाते हैं कि कौन-सा होम इस्तेमाल हो रहा है।

कुंजियाँ सेटिंग्स फ़ाइलों या लॉग में **नहीं** लिखी जातीं। वे इसी रनटाइम होम में एक अलग क्रेडेंशियल फ़ाइल में एन्क्रिप्ट करके रखी जाती हैं, जिसे सिर्फ़ आपका उपयोगकर्ता खाता पढ़ सकता है; जो कुंजियाँ VOOL ने Mac पर पहले से macOS Keychain में रखी थीं, वे वहीं रहती हैं। [सुरक्षा मॉडल](../trust/security.md#कुंजियाँ) देखें।

## सेटिंग्स

ऐप में **सेटिंग्स** के तहत सेटिंग्स बदलें। ये तय करती हैं कि VOOL क्या कर सकता है:

* **मॉडल** — सक्रिय मॉडल, जो तय करता है कि कोई टर्न स्थानीय है या क्लाउड।
* **वर्कस्पेस** — वह प्रोजेक्ट फ़ोल्डर जिसमें कोई चैट काम करती है; VOOL जिन दूसरे फ़ोल्डरों तक पहुँच सकता है, उनके लिए [वर्कस्पेस](../concepts/workspaces.md) देखें।
* **ऑपरेटिंग मोड** — यह यहाँ नहीं, संदेश बॉक्स के पास वाले मेनू में चुना जाता है। मैनुअल हर बदलाव से पहले पूछता है; ऑटो रोज़मर्रा के संपादन और कमांड चलने देता है, जबकि हटाना, ओवरराइट करना, इंस्टॉल करना, खर्च करना और सेटिंग्स बदलना अब भी पूछते हैं। [अनुमतियाँ](../concepts/permissions.md) देखें।
* **वेब ऐक्सेस और क्रिप्टो** — दोनों तब तक बंद रहते हैं जब तक आप उन्हें चालू न करें।

VOOL में प्रोडक्ट टेलीमेट्री की कोई सेटिंग नहीं है, क्योंकि यह कोई प्रोडक्ट टेलीमेट्री नहीं भेजता।

## रीसेट करना

VOOL बंद करें और रनटाइम होम को किसी दूसरी जगह हटा दें। वर्कस्पेस की फ़ाइलों को नहीं छुआ जाता; VOOL एक नई प्रोफ़ाइल के साथ फिर से शुरू होता है। आपकी सहेजी गई कुंजियाँ भी उसके साथ हट जाती हैं, इसलिए उन्हें **सेटिंग्स → API कुंजियाँ** में फिर से जोड़ें। macOS Keychain में रखी कुंजियाँ तब तक वहीं रहती हैं जब तक आप उन्हें Keychain Access में न हटाएँ।
