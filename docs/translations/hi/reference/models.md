# समर्थित मॉडल

VOOL के साथ कोई मॉडल नहीं आता। यह आपके चुने हुए रनटाइम और प्रदाताओं से जुड़ता है।

## स्थानीय रनटाइम

localhost पर OpenAI-संगत एंडपॉइंट देने वाला कोई भी रनटाइम इस्तेमाल किया जा सकता है। आम रनटाइम अपने आप पहचाने जाते हैं।

## क्लाउड प्रदाता

क्लाउड मॉडल तक आपकी कुंजी से, आपकी मशीन से पहुँचा जाता है। इनमें से कोई एक चुनने पर ऐप क्लाउड मोड में आ जाता है (संकेतक प्रदाता का नाम दिखाता है) — [स्थानीय और क्लाउड](../concepts/local-and-cloud.md) देखें।

[OpenRouter](../guides/openrouter.md) सबसे व्यापक अकेला कनेक्शन है: एक कुंजी, कई प्रदाता।

## चुनना

| काम | उचित विकल्प |
| --- | --- |
| निजी फ़ाइलें, कोई नेटवर्क नहीं | स्थानीय, 7B या बड़ा |
| रोज़ की कोडिंग | स्थानीय 7–14B कोडिंग मॉडल |
| लंबा तर्क | कोई बड़ा क्लाउड मॉडल |
| लागत पर नियंत्रण | पहले स्थानीय, क्लाउड तब जब वह फ़ायदेमंद हो |
