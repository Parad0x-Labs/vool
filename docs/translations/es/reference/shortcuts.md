# Atajos de teclado

`⌘` en macOS, `Ctrl` en Windows y Linux.

| Acción | Atajo |
| --- | --- |
| Nueva sesión | `⌘ N` |
| Paleta de comandos | `⌘ K` |
| Cambiar de modelo | `⌘ M` |
| Mostrar u ocultar el panel del espacio de trabajo | `⌘ J` |
| Detener la ejecución actual | `Esc` |
| Ajustes | `⌘ ,` |
