# Skróty klawiszowe

`⌘` w macOS, `Ctrl` w Windows i Linuksie.

| Czynność | Skrót |
| --- | --- |
| Nowa sesja | `⌘ N` |
| Paleta poleceń | `⌘ K` |
| Zmiana modelu | `⌘ M` |
| Pokazanie lub ukrycie panelu obszaru roboczego | `⌘ J` |
| Zatrzymanie bieżącego przebiegu | `Esc` |
| Ustawienia | `⌘ ,` |
