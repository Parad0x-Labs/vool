# Сочетания клавиш

`⌘` в macOS, `Ctrl` в Windows и Linux.

| Действие | Сочетание |
| --- | --- |
| Новая сессия | `⌘ N` |
| Палитра команд | `⌘ K` |
| Сменить модель | `⌘ M` |
| Показать или скрыть панель рабочего пространства | `⌘ J` |
| Остановить текущее выполнение | `Esc` |
| Настройки | `⌘ ,` |
