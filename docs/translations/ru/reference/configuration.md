# Конфигурация

## Расположение

VOOL хранит свои настройки, чаты, память и записи в одной папке — runtime home:

| Установка | Runtime home |
| --- | --- |
| Приложение для macOS | `~/Library/Application Support/VOOL/runtime` |
| Архив tar для Linux и установка из исходного кода | `~/.vool_runtime` |
| Windows (экспериментально, из исходного кода) | `%LOCALAPPDATA%\VOOL` |

Если перед запуском VOOL задать `VOOL_HOME`, вместо неё будет использоваться указанная папка. Журналы запуска
показывают, какая папка используется.

Ключи **не** записываются в файлы настроек и журналы. Они хранятся в зашифрованном виде в отдельном
файле учётных данных в этой папке runtime home, и читать его может только ваша учётная запись пользователя; ключи, которые VOOL
уже хранил в связке ключей macOS на Mac, остаются там. См.
[Модель безопасности](../trust/security.md#ключи).

## Настройки

Настройки меняются в приложении в разделе **Настройки**. Вот те, что определяют, что может делать VOOL:

* **Модель** — активная модель; от неё зависит, выполняется ли ход в режиме ЛОКАЛЬНО или ОБЛАКО.
* **Рабочее пространство** — папка проекта, в которой работает чат; о других папках, к которым VOOL может обращаться, см. [Рабочие пространства](../concepts/workspaces.md).
* **Режим работы** — выбирается в меню рядом с полем сообщения, а не здесь. «Ручной» спрашивает
  перед каждым изменением; «Авто» позволяет выполнять повседневные правки и команды, а удаление,
  перезапись, установка, траты и изменение настроек по-прежнему требуют разрешения. См.
  [Разрешения](../concepts/permissions.md).
* **Веб-доступ и криптофункции** — и то и другое выключено, пока вы их не включите.

В VOOL нет настройки продуктовой телеметрии, потому что он не отправляет продуктовую телеметрию.

## Сброс

Закройте VOOL и переместите папку runtime home в другое место. Файлы рабочего пространства не затрагиваются; VOOL запустится
заново с чистым профилем. Сохранённые ключи перемещаются вместе с папкой, поэтому добавьте их снова в
**Настройки → Ключи API**. Ключи, хранящиеся в связке ключей macOS, остаются там, пока вы не удалите их в
приложении «Связка ключей».
