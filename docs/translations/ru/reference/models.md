# Поддерживаемые модели

VOOL поставляется без модели. Он подключается к средам выполнения и провайдерам, которые выбираете вы.

## Локальные среды выполнения

Подходит любая среда выполнения, которая предоставляет OpenAI-совместимую конечную точку на localhost. Самые распространённые
обнаруживаются автоматически.

## Облачные провайдеры

К облачным моделям обращаются с вашим ключом, с вашего компьютера. Если выбрать одну из них, приложение перейдёт в
облачный режим (индикатор покажет имя провайдера) — см. [Локально и в облаке](../concepts/local-and-cloud.md).

[OpenRouter](../guides/openrouter.md) — самое широкое подключение в одном месте: один ключ, много
провайдеров.

## Выбор

| Работа | Разумный выбор |
| --- | --- |
| Личные файлы, без сети | Локальная, 7B или больше |
| Повседневное программирование | Локальная модель для программирования 7–14B |
| Длинные рассуждения | Более крупная облачная модель |
| Контроль расходов | Сначала локальная, облачная — когда оно того стоит |
