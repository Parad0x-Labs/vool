# Локально и в облаке

У VOOL два состояния. Интерфейс всегда показывает, какое из них активно.

## Локально

Всё остаётся на этом компьютере. Модель работает через локальную среду выполнения, файлы читаются
с диска, и никаких запросов к провайдеру не делается.

## Облако (имя провайдера)

Выбранный контекст отправляется напрямую выбранному вами провайдеру, с вашего компьютера,
с вашим ключом.

«Выбранный контекст» — это то, что приложение собрало для этого запроса: ваше сообщение, а также
файлы и предыдущие ходы, которые нужны запросу. Он показывается перед отправкой.

{% hint style="danger" %}
Облачный режим отправляет данные за пределы вашего компьютера. В этом и смысл облачного режима. Утверждение VOOL
касается *маршрута* — запрос идёт с вашего компьютера к вашему провайдеру, — а не того, что
ничего не передаётся.
{% endhint %}

## Что находится посередине

Ничего, чем управляет Parad0x Labs. Для трафика моделей нет ни прокси, ни шлюза, ни ретранслятора.
Ваш ключ используется приложением на вашем компьютере, чтобы обращаться к провайдеру напрямую.
