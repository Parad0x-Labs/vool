# Локально и в облаке

VOOL может отвечать двумя способами: на этом компьютере или через облачного провайдера. Заголовок чата
показывает, каким способом будет выполнен следующий запрос, — например, **АВТО** с
**Сначала локально**, когда VOOL Auto отвечает с этого компьютера.

## Локально

Модель и ваши файлы остаются на этом компьютере. Модель работает через локальную среду выполнения, файлы
читаются с диска, и никаких запросов к провайдеру не делается. Актуальные сведения, например погода или цены, поступают из общедоступных веб-сервисов, только пока включён «Веб-поиск» (после новой установки он выключен), и никогда — в режиме «Только локально».

## Облако (имя провайдера)

Выбранный контекст отправляется напрямую выбранному вами провайдеру, с вашего компьютера,
с вашим ключом.

«Выбранный контекст» — это то, что приложение собрало для этого запроса: ваше сообщение, а также
файлы и предыдущие ходы, которые нужны запросу.

{% hint style="danger" %}
Облачный режим отправляет данные за пределы вашего компьютера. В этом и смысл облачного режима. Утверждение VOOL
касается *маршрута* — запрос идёт с вашего компьютера к вашему провайдеру, — а не того, что
ничего не передаётся.
{% endhint %}

## Что находится посередине

Ничего, чем управляет Parad0x Labs. Для трафика моделей нет ни прокси, ни шлюза, ни ретранслятора.
Ваш ключ используется приложением на вашем компьютере, чтобы обращаться к провайдеру напрямую.
