# Квитанции

Квитанция — это постоянная запись запуска: какие инструменты вызывались, с какими входными данными и
что вернул каждый из них.

## Зачем они нужны

Сводка агента о собственной работе — это утверждение. Квитанция — это запись, с которой можно сверить
это утверждение.

## Что в ней есть

| Поле | Значение |
| --- | --- |
| `tool` | Какое действие выполнилось |
| `input` | Что ему было передано |
| `result` | Что оно вернуло |
| `time` | Когда оно выполнилось |

Квитанции хранятся в папке runtime home VOOL на этом компьютере (см.
[Конфигурация](../reference/configuration.md)), а не в папках ваших проектов. Квитанция покидает
ваш компьютер только в составе отчёта об ошибке, который вы просмотрели и решили отправить (см.
[Отчёты об ошибках и конфиденциальность](../trust/bug-reporting.md)).
