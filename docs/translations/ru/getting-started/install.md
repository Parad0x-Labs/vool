# Установка

Для VOOL 0.7.7-beta есть загрузки приложения для Mac с Apple Silicon, Mac с Intel и Linux x86_64 на
странице [выпуска v0.7.7-beta](https://github.com/Parad0x-Labs/vool/releases/tag/v0.7.7-beta).
Также можно установить VOOL из исходного кода с помощью скрипта начальной установки на macOS, Linux или Windows.
Подробности о подписи и обновлениях — в разделе [Статус выпуска](../../../trust/release-status.md).

## Требования

| | Минимум | С запасом |
| --- | ---: | ---: |
| Оперативная память | 8 ГБ | 16 ГБ и больше |
| Диск | 2 ГБ для приложения | 20 ГБ с локальными моделями |
| macOS | 14 Sonoma, Apple Silicon или Intel ([ограничения](#mac-с-intel)) | 14 Sonoma или новее, Apple Silicon |
| Windows | 10 (64-бит) | 11 |
| Linux | glibc 2.31 | Ubuntu 22.04 или новее |

Локальным моделям нужно заметно больше оперативной памяти, чем самому приложению. Рекомендации по размеру —
в разделе [Запуск локальной модели](../../../guides/local-models.md).

## Загрузка приложения

| Ваш компьютер | Загрузка |
| --- | --- |
| Mac с Apple Silicon (M1 и новее) | [`VOOL-0.7.7-beta-macos-arm64.dmg`](https://github.com/Parad0x-Labs/vool/releases/download/v0.7.7-beta/VOOL-0.7.7-beta-macos-arm64.dmg) |
| Mac с процессором Intel | [`VOOL-0.7.7-beta-macos-x86_64.dmg`](https://github.com/Parad0x-Labs/vool/releases/download/v0.7.7-beta/VOOL-0.7.7-beta-macos-x86_64.dmg) |
| Linux x86_64 (Ubuntu 22.04 / 24.04) | [`vool-0.7.7-beta-linux-x86_64.tar.gz`](https://github.com/Parad0x-Labs/vool/releases/download/v0.7.7-beta/vool-0.7.7-beta-linux-x86_64.tar.gz) |

Чтобы узнать, какой процессор в вашем Mac, откройте меню Apple и выберите **Об этом Mac**. «Apple M…»
означает Apple Silicon, «Intel» — Intel. Приложение для Apple Silicon не работает на Mac с Intel
и сообщает об этом при открытии.

Перед открытием проверьте SHA-256 загруженного файла (см. [Проверка загрузки](#проверка-загрузки)).

### Первое открытие на Mac

Бета-версия приложения ещё не нотариально заверена Apple, поэтому при первом открытии macOS попросит
подтверждение. Так и должно быть, и это происходит один раз.

1. Откройте DMG и перетащите **VOOL** в **Программы**.
2. Дважды нажмите VOOL. macOS сообщит, что не может проверить приложение на наличие вредоносного ПО.
   Закройте сообщение.
3. Откройте **Системные настройки → Конфиденциальность и безопасность**. Прокрутите вниз до сообщения о VOOL
   и нажмите **Все равно открыть**. Для подтверждения введите пароль.

В macOS 14 Sonoma можно вместо этого в папке «Программы» нажать на VOOL, удерживая клавишу Control, выбрать
**Открыть**, а затем ещё раз нажать **Открыть**.

### Linux

Загрузите архив tar и его файл `.sha256` со страницы выпуска, проверьте архив, затем запустите
входящий в него установщик. Ни sudo, ни системный Python не нужны.

```bash
sha256sum -c vool-0.7.7-beta-linux-x86_64.tar.gz.sha256
tar -xzf vool-0.7.7-beta-linux-x86_64.tar.gz
bash vool-0.7.7-beta-linux-x86_64/install.sh
~/.local/bin/vool
```

VOOL устанавливается в `~/.local/share/vool`, помещает команду `vool` в `~/.local/bin` и добавляет
пункт в меню приложений. Настольная версия открывает чат в вашем браузере; если закрыть браузер,
VOOL продолжит работать. Чтобы удалить VOOL, выполните `bash ~/.local/share/vool/current/uninstall.sh`.
Ваши чаты и настройки остаются в вашем профиле.

Начиная с 0.7.5 загрузка для Linux обновляется внутри VOOL. Новая версия устанавливается рядом
со старой. Если она не запускается как следует, VOOL сам возвращается к прежней.

### После установки

Прежде чем локальная модель сможет отвечать, откройте **Настройки → Модели и провайдеры → Локальные модели** и один раз нажмите для неё **Certify**. Это запускает короткую проверку на вашем компьютере.

Начиная с 0.7.5 VOOL обновляется сам: если включено «Выходить в интернет самостоятельно», он показывает уведомление и устанавливает новую версию одним нажатием. Обновление с 0.7.4 или 0.7.3 на Mac: включите «Выходить в интернет самостоятельно» (Настройки > Конфиденциальность и разрешения) и один раз нажмите «Проверить обновления». С 0.7.4 и старше на Linux или с 0.7.2 и старше на Mac: загрузите 0.7.7 и установите поверх текущей версии. Ваши чаты и настройки
хранятся в вашем профиле, вне приложения. Криптофункции по умолчанию выключены.

## Установка из исходного кода

Запустите скрипт начальной установки для вашей платформы:

```bash
curl -fsSLo bootstrap_vool.sh https://raw.githubusercontent.com/Parad0x-Labs/vool/v0.7.7-beta/installer/bootstrap_vool.sh
bash bootstrap_vool.sh --ref v0.7.7-beta
```

```powershell
Invoke-WebRequest https://raw.githubusercontent.com/Parad0x-Labs/vool/main/installer/bootstrap_vool.ps1 -OutFile bootstrap_vool.ps1
powershell -ExecutionPolicy Bypass -File .\bootstrap_vool.ps1
```

Команды для macOS / Linux фиксируют и скрипт начальной установки, и загрузку его исходного кода на `v0.7.7-beta`. Чтобы выбрать другой выпуск, измените и тег в URL скрипта, и `--ref`. Скрипт начальной установки принимает имя ветки или тег выпуска, но не хеш коммита.

Для установки из исходного кода нужен Python 3.11 или новее. Если его не найдётся, установщик попробует
его настроить. Загрузки приложения включают собственный Python.

Установщик подготавливает среду Python, проверяет оборудование, настраивает локальную
модель и запускает локальные службы. Заложите время и место на диске для первой загрузки модели.
После настройки локальные модели работают без интернета; веб-инструментам и облачным моделям нужно
подключение.

## Mac с Intel

VOOL работает на Mac с Intel и macOS 14 или новее (например, на 13-дюймовом MacBook Pro 2020 года)
из загрузки для Intel или из исходного кода. Установщик из исходного кода определяет процессор Intel и
устанавливает версии всех зависимостей для Intel. Два ограничения касаются только Intel:

* **Нет обучения локальных моделей.** PyTorch не выпускает сборки для macOS на Intel начиная с 2.3, поэтому
  установщик пропускает его, а обучение LoRA сообщает, что недоступно. Чат, память,
  инструменты и облачные модели это не затрагивает.
* **Локальные модели работают только на CPU.** У программ запуска локальных моделей нет ускорения на GPU для
  графики Intel, поэтому локальные ответы в несколько раз медленнее, чем на Apple Silicon. На Mac с 8 ГБ
  используйте для чата облачную модель; с 16 ГБ небольшая локальная модель, которую установщик ставит по умолчанию,
  работает, но медленно.

На Mac с Intel локальные модели работают на процессоре и медленные. Длинный ответ с опорой на память может не уложиться во время ожидания, поэтому пока используйте там облачную модель. Сертификация локальных моделей учитывает более медленные процессоры.

Для Mac с Intel есть отдельная загрузка, `VOOL-0.7.7-beta-macos-x86_64.dmg`. Загрузка для Apple Silicon
не работает на Intel и сообщает об этом при запуске.

## Проверка загрузки

У каждой загрузки на странице выпуска рядом указана контрольная сумма SHA-256. Проверьте файл, прежде чем
открывать его:

```bash
shasum -a 256 <downloaded-artifact>    # macOS
sha256sum <downloaded-artifact>         # Linux
```

```powershell
Get-FileHash -Algorithm SHA256 <downloaded-artifact>
```

Сравните результат с контрольной суммой, опубликованной вместе с этим выпуском. Если они различаются,
удалите файл и загрузите его заново.
