# Первый запуск

При первом запуске VOOL задаёт четыре коротких вопроса. Любой из них можно пропустить, а любой ответ
изменить позже. Пока вы отвечаете, ничего никуда не отправляется, кроме проверки облачного ключа у его
провайдера, если вы его добавите.

## Что происходит

1. **Где ему думать?** На этом компьютере с локальной моделью или онлайн с ключом от
   провайдера, которому вы платите. См. [Подключение модели](connect-a-model.md).
2. **Выберите папку.** Папка проекта, в которой работает VOOL. См.
   [Рабочие пространства](../../../concepts/workspaces.md).
3. **Что ему можно одному?** Как часто VOOL останавливается и спрашивает вас, прежде чем что-то изменить. См.
   [Инструменты](../../../concepts/tools.md).
4. **Как его звать вас?** Необязательно. Достаточно имени или прозвища, и оно остаётся на
   этом компьютере.

После этого индикатор режима показывает «Локально», «Авто» или имя облачного провайдера и отражает
выбранную сейчас модель.

**Один раз сертифицируйте локальную модель.** Прежде чем локальная модель сможет отвечать, откройте
**Настройки → Модели и провайдеры → Локальные модели** и нажмите для неё **Certify**. Это запускает короткую
проверку на вашем компьютере.

## Чего VOOL не делает при первом запуске

* Не создаёт учётную запись.
* Не требует облачного ключа. Чтобы пользоваться приложением, достаточно локальной модели.
* Не индексирует ваш диск. Он читает файлы, только когда они нужны для запроса; о папках, к которым он имеет
  доступ, см. [Рабочие пространства](../../../concepts/workspaces.md).

{% hint style="info" %}
Выбрать другую папку проекта можно в любой момент кнопкой **+ Проект** на боковой панели чата.
{% endhint %}
