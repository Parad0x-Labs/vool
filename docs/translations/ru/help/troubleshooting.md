# Решение проблем

## macOS не открывает приложение

Так и должно быть: приложение ещё не нотариально заверено. Сначала проверьте контрольную сумму, затем откройте
**Системные настройки → Конфиденциальность и безопасность** и нажмите **Все равно открыть**. В macOS 14 можно
вместо этого нажать на VOOL, удерживая клавишу Control, и выбрать **Открыть**.

## Windows

В этом выпуске нет загрузки для Windows. В Windows VOOL устанавливается из исходного кода, и эта поддержка
экспериментальная; см. [руководство по установке](../getting-started/install.md#установка-из-исходного-кода).

## Не видно ни одной локальной модели

1. Убедитесь, что среда выполнения локальных моделей установлена — в Linux сначала установите
   [Ollama](https://ollama.com), если ещё не сделали этого
   (см. [Запуск локальной модели](../guides/local-models.md#установка-среды-выполнения)).
2. Убедитесь, что среда выполнения запущена.
3. Убедитесь, что загружена хотя бы одна модель.
4. Убедитесь, что порт совпадает с тем, который ожидает VOOL.

```bash
curl http://localhost:11434/api/tags
```

Если команда ничего не вернула, среда выполнения не запущена.

## Ответы приходят медленно

Обычно дело в размере модели относительно доступной оперативной памяти. См.
[Запуск локальной модели](../guides/local-models.md).

## В ошибке показан код

У каждого сбоя есть постоянный код. На странице [Ошибки и коды ошибок](../reference/errors.md)
объясняется, как его читать, а в [Книге ошибок](../ERROR_BOOK.md) для каждого кода сказано, что
произошло, что могло уже произойти и что делать дальше.

## Начать с чистого листа

Закройте VOOL и удалите папку «runtime home», указанную в разделе
[Конфигурация](../reference/configuration.md). При этом удалятся ваши чаты, память, настройки,
сохранённые ключи и любой кошелёк, который VOOL хранит на этом компьютере, поэтому сначала сохраните
то, что вам нужно: см. [Резервное копирование и восстановление](backup-and-recovery.md). Файлы
рабочего пространства не затрагиваются.
