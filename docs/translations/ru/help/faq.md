# FAQ

## VOOL работает без интернета?

Да, с локальной моделью. Облачным моделям по определению нужно подключение к сети.

## Нужен ли мне облачный ключ?

Нет. Чтобы пользоваться приложением, достаточно локальной модели.

## Где хранится мой ключ?

В зашифрованном файле в папке runtime home VOOL на вашем компьютере; читать его может только ваша учётная
запись пользователя. Ключи, которые VOOL уже хранил в связке ключей macOS на Mac, остаются там. Ключи остаются на
вашем компьютере. См. [Модель безопасности](../trust/security.md#ключи).

## Видит ли Parad0x мои запросы?

Ни в локальном режиме, ни в облачном — облачные запросы идут с вашего компьютера к
вашему провайдеру. См. [Обработка данных](../trust/data-handling.md).

## Почему система предупреждает меня, когда я его открываю?

Приложения для macOS подписаны ad-hoc, но ещё не нотариально заверены, поэтому macOS просит подтвердить
первое открытие. Шаги описаны в разделе [Установка](../getting-started/install.md#первое-открытие-на-mac). См.
[Статус выпуска](../trust/release-status.md).

## Можно ли использовать собственную модель?

Да. Подойдёт любая среда выполнения, которая предоставляет OpenAI-совместимую локальную конечную точку. См.
[Поддерживаемые модели](../reference/models.md).

## Это бесплатно?

Приложение бесплатно на время беты. Использование облачных моделей оплачивается вашему
провайдеру, с вашего счёта.
