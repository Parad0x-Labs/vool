# Запуск локальной модели

## Установка среды выполнения

По умолчанию VOOL запускает локальные модели через Ollama; другие локальные среды выполнения с
OpenAI-совместимой конечной точкой тоже подходят. Ollama — отдельная программа, которая устанавливается отдельно,
с [ollama.com](https://ollama.com). Приложение для macOS включает собственную программу запуска локальных моделей,
поэтому на Mac этот шаг можно пропустить. В Linux и при установке из исходного кода установите Ollama, запустите
её и загрузите модель.

```bash
ollama serve
ollama pull qwen3:4b
```

По умолчанию VOOL сам выбирает для вас локальную модель — модель Qwen, подобранную под ваш компьютер. На
многих компьютерах это `qwen3:4b`; на компьютерах с 32 ГБ оперативной памяти или больше по умолчанию
используется более крупная модель Qwen.

## Подключите к ней VOOL

Откройте **Настройки → Модели и провайдеры**. Запущенные локальные среды выполнения обнаруживаются автоматически. Выберите
модель, и индикатор режима сменится на «Локально».

## Подготовьте её один раз

Локальная модель пишет ответы только после того, как VOOL её проверил. Откройте
**Настройки → Модели и провайдеры → Локальные модели** и нажмите **Использовать эту модель** рядом с моделью.
VOOL незаметно проверяет на вашем компьютере, достаточно ли хорошо модель пользуется инструментами VOOL, чтобы
отвечать за вас. Проверка может занять минуту-две; ничего не загружается, и ни с кем не устанавливается связь.
Когда проверка пройдена, у модели отображается **Готова**, и VOOL отвечает с её помощью. До этого VOOL не позволяет
ей писать окончательные ответы.

* **Не подходит:** модель недостаточно хорошо пользуется инструментами VOOL. VOOL перечисляет, что можно сделать
  вместо этого: использовать или загрузить модель, которую он подобрал для этого компьютера, или использовать облачную модель.
* **Проверка не завершилась:** убедитесь, что Ollama открыта, затем нажмите **Попробовать снова**. Медленному компьютеру
  может понадобиться вторая попытка.

Если при запуске VOOL ни одна локальная модель не готова, он проверяет до трёх моделей на этом компьютере,
начиная с той, которую вы выбрали, и использует первую, прошедшую проверку. Модель, слишком большую для этого
компьютера, он пропускает. Готовая модель всегда идёт раньше неготовой.

## Размер

| Размер модели | Нужно оперативной памяти | Для чего подходит |
| --- | ---: | --- |
| 3B | ~4 ГБ | Короткие правки, быстрые вопросы |
| 7–8B | ~8 ГБ | Повседневная работа, большая часть программирования |
| 14B | ~16 ГБ | Более длинные рассуждения |
| 32B+ | 32 ГБ и больше | Более тяжёлая работа, медленнее |

{% hint style="info" %}
Квантованные сборки существенно снижают потребность в оперативной памяти. Модель 7B с 4-битной квантизацией спокойно работает примерно в
5 ГБ.
{% endhint %}

## Если работает медленно

* Выберите модель поменьше или с более сильной квантизацией.
* Закройте другие приложения, которые занимают много оперативной памяти.
* Сократите контекст: чем меньше файлов в запросе, тем меньше нужно обработать.
