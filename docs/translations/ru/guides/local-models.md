# Запуск локальной модели

## Установка среды выполнения

VOOL обращается к локальному серверу моделей. Приложение для macOS включает собственную программу запуска локальных моделей, поэтому
на Mac этот шаг можно пропустить. В Linux и при установке из исходного кода установите сервер, например
Ollama, запустите его и загрузите модель.

```bash
ollama serve
ollama pull qwen2.5-coder:7b
```

## Подключите к ней VOOL

Откройте **Настройки → Модели и провайдеры**. Запущенные локальные среды выполнения обнаруживаются автоматически. Выберите
модель, и индикатор режима сменится на «Локально».

## Сертифицируйте её один раз

Локальная модель пишет ответы только после сертификации. Откройте **Настройки → Модели и провайдеры → Локальные модели**,
зарегистрируйте модель, затем выберите **Certify**. Сертификация запускает короткую проверку инструментов на вашем
компьютере; ничего не загружается, и ни с кем не устанавливается связь. Пока модель не пройдёт проверку, VOOL не
позволяет ей писать окончательные ответы.

## Размер

| Размер модели | Нужно оперативной памяти | Для чего подходит |
| --- | ---: | --- |
| 3B | ~4 ГБ | Короткие правки, быстрые вопросы |
| 7–8B | ~8 ГБ | Повседневная работа, большая часть программирования |
| 14B | ~16 ГБ | Более длинные рассуждения |
| 32B+ | 32 ГБ и больше | Более тяжёлая работа, медленнее |

{% hint style="info" %}
Квантованные сборки существенно снижают потребность в оперативной памяти. Модель 7B с 4-битной квантизацией спокойно работает примерно в
5 ГБ.
{% endhint %}

## Если работает медленно

* Выберите модель поменьше или с более сильной квантизацией.
* Закройте другие приложения, которые занимают много оперативной памяти.
* Сократите контекст: чем меньше файлов в запросе, тем меньше нужно обработать.
