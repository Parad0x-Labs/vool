# Поиск навыков и проверки Eyebrow

На странице «Навыки и плагины» четыре вкладки: **Обзор**, **Кодекс навыков**, **Мои дополнения** и **Безопасность**. «Обзор» сначала показывает собственные навыки VOOL, включая 53 текстовых навыка VOOL, поставляемых с приложением, затем проверенные дополнения из каталога, а также может найти публичный репозиторий GitHub на закреплённой ревизии. «Кодекс навыков» показывает сначала навыки команды VOOL, а под ними — выбор редакции и рекомендуемые навыки. Поиск не учитывает регистр и распространённые разделители; элементы выбора категории и сортировки сужают список. Источник, лицензия, ревизия и требования видны до загрузки.

## Первое использование

1. Сохраните ключ API Eyebrow на вкладке «Безопасность», которая также доступна в разделе Настройки → Ключи API. Ключом владеет существующее хранилище учётных данных. Сохранение не проверяет соединение и ничего не сканирует; к Eyebrow явно обращается кнопка Test.
2. Во вкладке «Обзор» выберите навык и одобрите загрузку его общедоступного содержимого и отправку этого содержимого в Eyebrow. На это расходуется квота сканирований сервиса согласно вашему тарифу. Автоматических повторов не бывает.
3. Прочитайте полученный отчёт. Один лишь успешный HTTP-ответ — ещё не чистый результат. Этот начальный каталог разрешает установку только при полном отчёте `pass`, без находок и без нарушений политики. «Отклонить» удаляет подготовленную загрузку, не устанавливая её.
4. Отдельно примите установку. VOOL сохраняет лицензию, устанавливает навык через свой существующий жизненный цикл плагинов, верифицирует точный проверенный пакет и включает навык. Существующие разрешения по-прежнему управляют каждым действием, которое он может предложить.

Сканирование — это оценка конкретных байтов поставщиком, а не гарантия безопасности, совместимости или качества ответов. Включение в каталог не является сертификацией издателя.

## Границы

Содержимое берётся только из публичных репозиториев GitHub на фиксированной 40-символьной ревизии, с файлами навыка и лицензии, закреплёнными по SHA-256. В этой версии нет импорта частных репозиториев, распаковки архивов, скриптов установки и импорта исполняемых плагинов или плагинов MCP. В Eyebrow отправляется только отдельный файл SKILL.md; локальные чаты, файлы рабочего пространства, учётные данные и тексты лицензий на сканирование не передаются.

Загрузки остаются неактивными до проверки и принятия. Локально аутентифицированные квитанции привязывают отчёт к закреплённому содержимому. Установка отклоняет просроченные проверки (24 часа), изменённые подготовленные файлы и уже существующие целевые каталоги. Среда выполнения проверяет состояние жизненного цикла и проверенные байты, прежде чем добавить управляемый навык в контекст модели. Добавленные файлы, символические ссылки или изменённое содержимое делают его недоступным. Инструкции вставляются целиком или явно отмечаются как пропущенные из-за нехватки бюджета запроса; просканированные инструкции не обрезаются молча.

Эти проверки не изолируют вредоносный код, который уже выполняется от имени пользователя операционной системы. Они не распространяются на ранее установленные вручную плагины. Квитанция сканирования не даёт ни новых прав на выполнение, ни полномочий кошелька.

## API и обработка сбоев

`GET /api/addons` возвращает каталог и локальный статус без проверки соединения и без сканирования. `POST /api/addons` поддерживает `save_key`, `remove_key`, `test_key`, `scan`, `install` и `reject`. Изменяющие запросы должны приходить через loopback, в формате JSON и из браузера с того же источника; принимаются только поля, относящиеся к операции. Переданные вызывающей стороной URL источников и пути отклоняются.

Клиент использует запрос Eyebrow v1 со встроенным исходным текстом навыка по адресу `/v1/scan`, с аутентификацией bearer, фиксированным источником HTTPS, без перенаправлений, с ограниченным размером ответа и без автоматических повторов. `/v1/version` используется для явной проверки соединения. Справочник API: https://eyebrow.cc/api/reference .

Типичные типизированные сбои:

| Код | Значение / что делать |
| --- | --- |
| `eyebrow_key_missing` / `eyebrow_unauthorized` | Сохраните или замените ключ. |
| `eyebrow_quota` | Прежде чем повторять, проверьте квоту сервиса. |
| `eyebrow_timeout` / `eyebrow_unreachable` | Автоматического повтора нет; сканирование, прерванное по тайм-ауту, всё равно может израсходовать квоту. |
| `eyebrow_invalid_report` / `eyebrow_no_coverage` | Свидетельства неполны; ничего не включается. |
| `addon_source_changed` / `addon_changed` | Закреплённые или проверенные байты отличаются; не активируйте их. |
| `review_untrusted` / `review_expired` | Перед установкой получите новую проверку. |
| `addon_already_installed` | Существующие файлы сохранены. Автоматическая замена не реализована. |

## Текущие ограничения и проверка

Нет автоматического обновления, импорта произвольных каталогов и процесса восстановления или переустановки на месте для уже существующего изменённого пакета. Восстановление ожидающей проверки после перезапуска приложения в интерфейсе недоступно. Новые строки интерфейса пока показываются на английском; полнота переводов не заявляется.

Автоматические тесты проверяют реальный жизненный цикл, загрузку навыков, обработчики API и отдаваемый браузерный интерфейс с явно имитированными публичными загрузками и ответами Eyebrow. Они доказывают поведение среды выполнения и интерфейса, но не доступность живого Eyebrow и не компетентность модели. Реальное сканирование с ключом и приёмка нативного упакованного приложения остаются проверками выпуска. Для запуска этих тестов не нужны ни ключ, ни вызов платного сервиса.
