# Подключение OpenRouter

OpenRouter даёт доступ ко многим провайдерам по одному ключу. VOOL поддерживает добавление
ключа OpenRouter.

## Добавление ключа

Создайте ключ в своей учётной записи OpenRouter, вставьте его в **Настройки → Ключи API** и нажмите
**Сохранить ключ**. VOOL один раз проверяет ключ у OpenRouter, а затем хранит его в зашифрованном файле на
этом компьютере (см. [Модель безопасности](../trust/security.md#ключи)).

## Оплата и атрибуция

{% hint style="info" %}
Ваша учётная запись OpenRouter остаётся вашей. VOOL отправляет запросы напрямую с этого компьютера
с вашим ключом. Parad0x не пропускает ваши запросы через себя и не платит за ваше использование. Реальное
использование VOOL может отражаться в публичной сводной статистике VOOL в OpenRouter, но отдельные запросы
и личности не публикуются.
{% endhint %}

## Удаление ключа

Удалите ключ в **Настройки → Ключи API**. Если хотите, чтобы ключ перестал действовать и на стороне сервера, отзовите его также в своей учётной записи OpenRouter.
