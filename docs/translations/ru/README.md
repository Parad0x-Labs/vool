# VOOL

VOOL — настольный ИИ-ассистент. Он устанавливается на компьютер как приложение и может
запускать модели ИИ локально на этой машине или подключаться к облачному провайдеру ИИ с вашим
собственным ключом API. Он ведёт понятный журнал каждого своего действия.

Он бесплатный и с локальными моделями работает без интернета. Есть загрузки для Mac (Apple Silicon
и Intel) и Linux x86_64; Windows поддерживается экспериментально и устанавливается из исходного кода.

В этой документации описано, как установить VOOL и подключить модель, а также как он
обращается с вашими файлами, вашей памятью и вашими ключами.

## Сравнение с другими

На 150 ранее не использованных вопросах LoCoMo на память, когда за каждого агента отвечала одна и та же модель,
а оценивал один и тот же GPT-4o, память VOOL обошла два других агента с открытым исходным кодом:

| | VOOL | OpenClaw | Hermes |
| --- | --- | --- | --- |
| Правильные ответы | **82,7 %** (124 / 150) | 71,3 % (107) | 62,7 % (94) |
| Токенов на вопрос | **9,6k** | 51,8k | 33,5k |
| Стоимость вопроса | **0,0033 $** | 0,0100 $ | 0,0046 $ |

Это в 5,4 раза меньше токенов, чем у OpenClaw, и в 3,5 раза меньше, чем у Hermes, при трети стоимости
ответа OpenClaw. Память из VOOL 0.7 набрала на тех же вопросах 123 из 150.
Все прогоны, условия и слабые места опубликованы: [бенчмарки памяти](https://github.com/Parad0x-Labs/vool/tree/main/docs/benchmarks).

## Что такое VOOL

* **Настольное приложение.** Устанавливается на ваш компьютер — это не вкладка браузера и не
  размещённый в сети сервис.
* **Работает без интернета.** Если выбрана локальная модель, VOOL не нужно подключение к интернету.
* **Локально по умолчанию.** Если выбрана локальная модель, запросы и файлы обрабатываются
  на вашем компьютере.
* **Не привязан к модели.** Можно выбрать как локальные среды выполнения, так и облачных провайдеров. Облачный
  ключ вы предоставляете сами; он остаётся на вашем компьютере.
* **Проверяемый.** Каждый вызов инструмента записывается вместе с входными данными и результатами, поэтому
  ход работы можно перечитать после.

{% hint style="warning" %}
VOOL находится в бета-версии для Mac с Apple Silicon, Mac с Intel и Linux x86_64. Приложения для Mac
ещё не нотариально заверены Apple, поэтому при первом открытии macOS попросит подтверждение; на
странице [Установка](getting-started/install.md#первое-открытие-на-mac) показано, как это сделать. Перед установкой
прочитайте [Статус выпуска](../../trust/release-status.md).
{% endhint %}

## Два режима, без недомолвок

VOOL различает ровно два состояния, и интерфейс всегда показывает, какое из них активно:

1. **Локально** — работа остаётся на этом компьютере.
2. **Облако** — выбранный контекст отправляется напрямую выбранному вами провайдеру,
   с вашего компьютера, с вашим ключом.

Третьего состояния нет, и между ними нет никакого ретранслятора, которым управляет Parad0x. Подробности —
в разделе [Обработка данных](trust/data-handling.md).
