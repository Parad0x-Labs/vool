# Статус выпуска

Эта страница — поддерживаемый авторитетный источник о статусе выпуска. Другие документы упоминают факты о выпуске
мимоходом; если они расходятся с этой страницей, верна эта страница.

## Текущая стадия

VOOL находится в стадии **бета**. Текущий выпуск —
[**v0.7.7-beta**](https://github.com/Parad0x-Labs/vool/releases/tag/v0.7.7-beta), выпуск на GitHub,
собранный из `main` на `8af687c`. В нём есть загрузки приложения для трёх платформ,
у каждой — опубликованная контрольная сумма SHA-256. Установка из исходного кода с помощью скрипта начальной установки
по-прежнему поддерживается на macOS, Linux и Windows; см. [Установка](../getting-started/install.md).

| Загрузка | Для чего |
| --- | --- |
| `VOOL-0.7.7-beta-macos-arm64.dmg` | Mac с Apple Silicon, macOS 14 или новее |
| `VOOL-0.7.7-beta-macos-x86_64.dmg` | Mac с Intel, macOS 14 или новее |
| `vool-0.7.7-beta-linux-x86_64.tar.gz` | Linux x86_64, протестировано на Ubuntu 22.04 и 24.04 |

Записи о выпусках в этом репозитории охватывают канал GitHub. Другие каналы загрузки
обслуживаются отдельно; сверяйте любую загрузку с контрольной суммой, опубликованной в выпуске на
GitHub.

| | Статус |
| --- | --- |
| Публичные загрузки | DMG для macOS на Apple Silicon, DMG для macOS на Intel, архив tar для Linux x86_64 в выпуске v0.7.7-beta на GitHub |
| Опубликованные контрольные суммы | SHA-256 для каждой загрузки, в выпуске |
| Подпись кода | Приложения для macOS подписаны ad-hoc, а не Developer ID. Подпись будет добавлена после этой беты и не является условием её выпуска |
| Нотариальное заверение macOS | Не заверено нотариально. macOS просит подтвердить первое открытие (см. ниже) |
| Windows | В этом выпуске нет загрузки для Windows; Windows устанавливается из исходного кода, и эта поддержка экспериментальная |
| Обновления | Начиная с 0.7.5 VOOL обновляется сам: если включено «Выходить в интернет самостоятельно», он показывает уведомление и устанавливает новую версию одним нажатием. Обновление с 0.7.4 или 0.7.3 на Mac: включите «Выходить в интернет самостоятельно» (Настройки > Конфиденциальность и разрешения) и один раз нажмите «Проверить обновления». В Linux или с 0.7.2, 0.7.1 или 0.7.0: загрузите 0.7.7 и установите поверх текущей версии. Ваши чаты и настройки хранятся в вашем профиле, вне приложения. См. [Обновления и миграция](../reference/updates-migration.md) |
| Стабильность API | Меняется от сборки к сборке |

## Что это значит для вас

* При первом запуске приложения для Mac macOS отказывается его открывать, потому что оно не нотариально заверено.
  На этой стадии так и должно быть, и это не признак повреждённой загрузки. Проверьте контрольную сумму,
  затем откройте **Системные настройки → Конфиденциальность и безопасность** и нажмите **Все равно открыть**. В
  macOS 14 можно вместо этого нажать на приложение, удерживая клавишу Control, и выбрать **Открыть**.
* Выберите загрузку для Mac, которая соответствует вашему чипу. Приложение для Apple Silicon не работает на
  Mac с Intel и сообщает об этом при запуске.
* Форматы конфигурации могут меняться от сборки к сборке.
* Криптофункции выключены, пока вы их не включите.

## Ограничения беты и пилота — открытым текстом

| Возможность | Состояние в этой сборке |
| --- | --- |
| Криптофункции и кошелёк | По умолчанию выключены. Когда вы их включаете, VOOL использует mainnet; тестовые сети находятся в Developer options. Каждый платёж проходит через кошелёк VOOL — с его лимитами, вашим одобрением и квитанцией. См. [Кошелёк](../guides/wallet.md). |
| Переводы в mainnet | Нативные монеты, а также USDT в Solana, Ethereum, BNB Smart Chain и Arbitrum One, отправляемые из VOOL Wallet, созданного на этом устройстве. USDC в Solana и Base — только для платёжных каналов. Подключённый аккаунт или аккаунт только для просмотра может получать средства и показывать свой баланс, но не может отправлять из VOOL. |
| Оплата через x402 | Веб-сайты, которые запрашивают оплату x402 в USDC в сети Base или Base Sepolia, можно оплачивать из вашего кошелька Crypto Pilot: одно одобрение PIN-кодом в пределах ваших лимитов. Сетевую комиссию покрывает платёжный сервис веб-сайта. В **Настройки → Крипто → Payment channels** есть переключатель для каждого способа, которым кошелёк может оплатить веб-сайт; выключенный канал отказывает ещё до того, как что-либо подписано. Реальных платежей в mainnet этим способом ещё не проводилось. Оплата через Solana pay-kit не входит в загрузки; этот канал отображается как недоступный. |
| X | Из любого чата: поиск публикаций и аккаунтов, Spaces, трендов и личных сообщений, а также поиск прошлых прогнозов по токену. Всё, что действует от имени вашего аккаунта, ждёт вашего согласия. |
| Диктовка | Недоступна в этой бета-сборке. |
| Облачный режим «всплеска» с подтверждением | Запрос подтверждения для каждого вызова в этой сборке ещё не подключён. |
| Локальные модели | Прежде чем локальная модель сможет отвечать, откройте **Настройки → Модели и провайдеры → Локальные модели** и один раз нажмите для неё **Certify**. |
| Mac с Intel | Локальные модели работают на процессоре и медленные. Сертификация учитывает более медленные процессоры, но длинный ответ с опорой на память может не уложиться во время ожидания, поэтому пока используйте там облачную модель. |
| Приватный чат | Скажите «приватный чат», «не сохраняйте это» или «без записи», и ничего из этого чата не сохраняется. Команды работают на всех 17 языках приложения. |
| Забывание | Забывание очищает память VOOL и соответствующую историю выполнения, поэтому элемент больше не вспоминается и не показывается в списках, и стирает забытые слова из локального файла памяти VOOL и его поискового индекса. VOOL хранит слова, которые вы попросили забыть, в коротком списке на вашем компьютере, чтобы и дальше отказываться их принимать. После того как вы что-то забыли в чате, VOOL не примет тот же факт обратно в этом чате; чтобы сообщить его снова, начните новый чат. |
| Отсканированные PDF | Читаются встроенным распознаванием текста Mac, поэтому только на Mac. |
| Питомец на рабочем столе | Питомец живёт в окне VOOL. Если вытащить его из окна, он не переместится на рабочий стол. |
| Кодекс навыков | «Открыть кодекс навыков» показывает навыки, перечисленные для вашей точной версии VOOL, и вы просматриваете навык перед установкой. «Опубликовать в кодексе навыков» проверяет навык, созданный вами на вашем компьютере, затем открывает сайт кодекса навыков, где навык уже заполнен; вы входите там и отправляете его, а сам VOOL ничего не отправляет. Передаётся только текст навыка, поэтому навыком с дополнительными файлами пока нельзя поделиться. |

Подпись Developer ID и нотариальное заверение для macOS, а также подписанные контрольные суммы для Linux — следующие шаги
на пути к выпуску; сегодня ни то, ни другое не заявляется.
