# Модель безопасности

## Границы

* **Ограничения папок** определяют доступ к файлам. VOOL читает и изменяет файлы в папке проекта
  чата. За её пределами VOOL может читать видимые папки в вашей домашней папке и изменять файлы только в
  Desktop, Downloads и Documents; скрытые папки, данные приложений и системы, а также собственные данные VOOL
  никогда не читаются. См. [Рабочие пространства](../concepts/workspaces.md).
* **Хранилище учётных данных** хранит ключи. Ключи не записываются в файлы конфигурации и журналы.
* **Подтверждение инструментов** ограничивает изменения. В режиме «Ручной» каждое изменение сначала запрашивает разрешение; в режиме «Авто»
  повседневные правки и команды могут выполняться автоматически, а удаление, перезапись, установка,
  траты и изменение настроек по-прежнему требуют разрешения. См. [Инструменты](../concepts/tools.md).

## Ваша локальная сеть

По умолчанию VOOL принимает подключения только с этого компьютера. Если настроить его на работу в локальной
сети, вами считается только этот компьютер. Настройки, файлы, ключи, инструменты и приватные
функции отвечают только ему.

Другое устройство в сети получает обычный чат. Оно также может читать по одной общедоступной веб-странице за
раз. Эта страница должна находиться в публичном интернете: адреса на этом компьютере или в вашей локальной
сети отклоняются, и каждое перенаправление проверяется так же. Веб-поиск, исследования,
браузер, котировки, платежи и ваши платные ключи работают только на этом компьютере.

## Мост Discord

Мост Discord отвечает только своему владельцу. Владельцем становится первый пользователь Discord,
отправивший ему команду. Чтобы выбрать владельца самостоятельно, задайте в `VOOL_DISCORD_OWNER_USER_ID` свой
идентификатор пользователя Discord; делайте так для любого канала, в котором могут писать другие люди. Всем остальным один раз
сообщается, что этот VOOL закреплён за своим владельцем, и их сообщения не обрабатываются. Даже на
сообщения владельца из Discord действуют те же ограничения, что и для другого устройства в сети.

## Ключи

VOOL хранит ключи ваших провайдеров в зашифрованном файле в своей папке runtime home на этом компьютере
(см. [Конфигурация](../reference/configuration.md)); читать этот файл может только ваша учётная запись пользователя.
Ключи, которые VOOL уже хранил в связке ключей macOS на Mac, по-прежнему читаются оттуда. Ключ используется
с вашего компьютера, чтобы обращаться к вашему провайдеру. Он не отправляется в Parad0x Labs, и на пути запроса нет
конечной точки, которой управляет Parad0x.

{% hint style="info" %}
Зашифрованный файл защищён правами доступа к файлам вашей учётной записи пользователя, а не отдельным
паролем. Держите шифрование диска включённым (FileVault на Mac), чтобы потерянный или украденный диск не
раскрыл ваши ключи.
{% endhint %}

## Плагины

Плагин работает с теми же правами доступа, что и среда выполнения. Именно это делает плагины полезными, и именно поэтому
их стоит прочитать перед установкой. См. [Навыки и плагины](../guides/skills-and-plugins.md).

## Сообщение о проблеме

Сообщайте о проблемах безопасности конфиденциально через
[GitHub Security Advisories](https://github.com/Parad0x-Labs/vool/security/advisories/new),
и никогда — в публичном issue. Укажите версию, платформу и шаги для воспроизведения.

{% hint style="warning" %}
Приложения для macOS подписаны ad-hoc и не нотариально заверены; архив tar для Linux не подписан. См.
[Статус выпуска](release-status.md).
{% endhint %}
