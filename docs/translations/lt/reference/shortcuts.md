# Spartieji klavišai

`⌘` macOS sistemoje, `Ctrl` Windows ir Linux sistemose.

| Veiksmas | Spartusis klavišas |
| --- | --- |
| Nauja sesija | `⌘ N` |
| Komandų paletė | `⌘ K` |
| Perjungti modelį | `⌘ M` |
| Rodyti / slėpti darbo srities skydelį | `⌘ J` |
| Sustabdyti dabartinį vykdymą | `Esc` |
| Nustatymai | `⌘ ,` |
