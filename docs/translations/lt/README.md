# VOOL

VOOL yra vietinė AI darbalaukio aplinka. Ji veikia jūsų kompiuteryje, pagal nutylėjimą naudoja vietinius modelius, prie debesijos tiekėjų jungiasi tik tada, kai jūs taip nurodote, ir išsaugo skaitomą įrašą apie kiekvieną atliktą veiksmą.

## Pradėkite čia

| Ko norite | Skaitykite |
| --- | --- |
| Paleisti VOOL | [Diegimas](getting-started/install.md) |

## Kas yra VOOL

* **Darbalaukio aplinka.** Diegiama kaip programa, ne naršyklės kortelė ir ne debesijos paslauga.
* **Vietinis pagal nutylėjimą.** Pasirinkus vietinį modelį, užklausos ir failai apdorojami jūsų kompiuteryje.
* **Nepriklausomas nuo modelio.** Galima rinktis ir vietines, ir debesijos paslaugas. Raktą pateikiate jūs, ir jis lieka jūsų kompiuteryje.
* **Patikrinamas.** Kiekvienas įrankio iškvietimas įrašomas su įvestimi ir rezultatu.

{% hint style="warning" %}
VOOL macOS beta versija jau išleista Apple silicon kompiuteriams. Beta diegimo programos nepasirašytos, o macOS versija nėra notarizuota — sistema pirmą kartą paleidžiant parodys įspėjimą.
{% endhint %}

## Dvi būsenos

Sąsaja visada rodo, kuri iš jų aktyvi:

1. **Vietinė** — darbas lieka šiame kompiuteryje.
2. **Debesija** — pasirinktas kontekstas siunčiamas tiesiai jūsų pasirinktam tiekėjui.
