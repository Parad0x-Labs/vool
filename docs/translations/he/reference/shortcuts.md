# קיצורי מקלדת

`⌘` ב-macOS, `Ctrl` ב-Windows וב-Linux.

| פעולה | קיצור |
| --- | --- |
| צ׳אט חדש | `⌘ N` |
| לוח פקודות | `⌘ K` |
| החלפת מודל | `⌘ M` |
| הצגה או הסתרה של חלונית סביבת העבודה | `⌘ J` |
| עצירת ההרצה הנוכחית | `Esc` |
| הגדרות | `⌘ ,` |
