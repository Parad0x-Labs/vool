# מודלים נתמכים

VOOL לא מגיע עם מודל — המודל המקומי הראשון יורד בפעם הראשונה שאתם משתמשים בו. הוא מתחבר לסביבות הרצה ולספקים שאתם בוחרים.

## סביבות הרצה מקומיות

‏Ollama, ‏llama.cpp, ‏vLLM ו-MLX מזוהות אוטומטית. אפשר להפנות ידנית לסביבות הרצה אחרות שחושפות
נקודת קצה תואמת OpenAI ב-localhost.

## ספקי ענן

מגיעים למודלי ענן עם המפתח שלכם, מהמחשב שלכם. בחירה באחד מהם מעבירה את היישום למצב ענן
(המחוון מציג את שם הספק) — ראו [מקומי וענן](../concepts/local-and-cloud.md).

[OpenRouter](../guides/openrouter.md) הוא החיבור היחיד הרחב ביותר: מפתח אחד, ספקים
רבים.
