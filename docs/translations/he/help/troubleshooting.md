# פתרון בעיות

## macOS מסרב לפתוח את היישום

זה צפוי: היישום עדיין לא עבר אישור נוטריוני של Apple. קודם בדקו את סכום הביקורת, ואז פתחו את
**הגדרות המערכת ← פרטיות ואבטחה** ולחצו על **פתיחה בכל זאת**. ב-macOS 14 אפשר במקום זאת
ללחוץ על VOOL תוך כדי הקשה על Control ולבחור **פתח**.

## Windows

אין הורדה ל-Windows בגרסה הזו. ב-Windows ההתקנה היא מקוד המקור והתמיכה
ניסיונית; ראו את [מדריך ההתקנה](../getting-started/install.md#התקנה-מקוד-המקור).

## לא מוצגים מודלים מקומיים

1. ודאו שסביבת ההרצה למודלים מקומיים מותקנת — ב-Linux, התקינו קודם את
   [Ollama](https://ollama.com) אם עוד לא עשיתם זאת
   (ראו [הרצת מודל מקומי](../guides/local-models.md#התקנת-סביבת-הרצה)).
2. ודאו שסביבת ההרצה פועלת.
3. ודאו שלפחות מודל אחד הורד (pull).
4. ודאו שהפורט תואם למה ש-VOOL מצפה לו.

```bash
curl http://localhost:11434/api/tags
```

אם הפקודה לא מחזירה כלום, סביבת ההרצה לא פועלת.

## התשובות איטיות

בדרך כלל הסיבה היא גודל המודל ביחס לזיכרון הפנוי. ראו
[הרצת מודל מקומי](../guides/local-models.md).

## שגיאה מציגה קוד

לכל כשל יש קוד קבוע. הדף [שגיאות וקודי שגיאה](../reference/errors.md) מסביר איך לקרוא אותו,
ו[ספר השגיאות](../ERROR_BOOK.md) מפרט לכל קוד מה קרה, מה אולי כבר קרה ומה לעשות הלאה.

## התחלה נקייה

צאו מ-VOOL ומחקו את תיקיית "runtime home" שמופיעה בדף [תצורה](../reference/configuration.md). פעולה
זו מוחקת את הצ׳אטים, הזיכרון, ההגדרות והמפתחות השמורים שלכם, וכל ארנק ש-VOOL שומר במחשב הזה, לכן
שמרו קודם את מה שאתם צריכים: ראו [גיבוי ושחזור](backup-and-recovery.md). קבצי סביבת העבודה לא
נפגעים.
