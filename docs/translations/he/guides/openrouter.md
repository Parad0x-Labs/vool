# חיבור OpenRouter

OpenRouter נותן גישה לספקים רבים מאחורי מפתח אחד. VOOL תומך בחיבור של חשבון
OpenRouter.

## חיבור

צרו מפתח בחשבון ה-OpenRouter שלכם, הדביקו אותו תחת **הגדרות ← מפתחות API** ולחצו על
**שמור מפתח**. VOOL בודק את המפתח מול OpenRouter פעם אחת, ואז שומר אותו בקובץ מוצפן
במחשב הזה (ראו [מודל האבטחה](../trust/security.md#מפתחות)).

## חיוב וייחוס

{% hint style="info" %}
חשבון ה-OpenRouter שלכם נשאר שלכם. VOOL שולח בקשות ישירות מהמחשב הזה עם המפתח שלכם.
Parad0x לא מעבירה את ההנחיות שלכם דרכה ולא משלמת על השימוש שלכם. שימוש אמיתי ב-VOOL עשוי
להופיע בסטטיסטיקה הציבורית המצטברת של VOOL ב-OpenRouter, אבל הנחיות בודדות וזהויות לא
מתפרסמות.
{% endhint %}

## ניתוק

הסירו את המפתח תחת **הגדרות ← מפתחות API**. אם אתם רוצים שהמפתח יפסיק לעבוד גם בצד השרת, בטלו אותו גם בחשבון ה-OpenRouter שלכם.
