# הרצת מודל מקומי

## התקנת סביבת הרצה

VOOL מדבר עם שרת מודלים מקומי. יישום ה-macOS כולל מריץ מודלים מקומי משלו, כך שב-Mac אפשר
לדלג על השלב הזה. ב-Linux ובהתקנות מקוד המקור, התקינו שרת כמו Ollama, הפעילו אותו והורידו
(pull) מודל.

```bash
ollama serve
ollama pull qwen2.5-coder:7b
```

## הפניית VOOL אל השרת

פתחו את **הגדרות ← דגמים וספקים**. סביבות הרצה מקומיות שפועלות מזוהות אוטומטית. בחרו
מודל, ומחוון המצב יציג "מקומי".

## אישור המודל פעם אחת

מודל מקומי כותב תשובות רק אחרי שהוא אושר. פתחו את **הגדרות ← דגמים וספקים ← דגמים מקומיים**,
רשמו את המודל, ואז בחרו **Certify**. האישור מריץ בדיקת כלים קצרה במחשב שלכם; שום דבר לא
מורד ושום גורם לא מקבל פנייה. עד שמודל עובר את הבדיקה, VOOL לא מאפשר לו לכתוב תשובות
סופיות.

## בחירת גודל

| גודל המודל | זיכרון RAM נדרש | מתאים עבור |
| --- | ---: | --- |
| 3B | ~4 GB | עריכות קצרות, שאלות מהירות |
| 7–8B | ~8 GB | שימוש כללי, רוב עבודת הקוד |
| 14B | ~16 GB | חשיבה ארוכה יותר |
| 32B+ | 32 GB או יותר | עבודה כבדה יותר, איטית יותר |

{% hint style="info" %}
גרסאות מכומתות חוסכות הרבה זיכרון. מודל 7B בכימות של 4 ביט רץ בנוחות בכ-5 GB.
{% endhint %}

## אם הוא איטי

* בחרו מודל קטן יותר או מכומת יותר.
* סגרו יישומים אחרים שצורכים הרבה זיכרון.
* קצרו את ההקשר — פחות קבצים בבקשה פירושם פחות עיבוד.
