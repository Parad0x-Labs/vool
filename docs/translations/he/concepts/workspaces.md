# סביבות עבודה

סביבת עבודה היא תיקיית הפרויקט שצ׳אט עובד בה. VOOL קורא ומשנה בה קבצים, ושואל קודם בכל
פעם שמצב הפעולה שלכם קובע שצריך (ראו [כלים](tools.md)).

## הוספה והסרה

בחרו תיקייה עם **בחירת תיקיית פרויקט…** בצ׳אט, או עם **+ פרויקט** בסרגל הצד של
הצ׳אט. מחיקת פרויקט גורמת ל-VOOL לשכוח את מה שלמד בו, ומחזירה את הצ׳אטים שלו אל "כללי".
הקבצים שלכם לא נפגעים.

## התיקיות האחרות שלכם

מחוץ לסביבת העבודה, כלי הקבצים של VOOL יכולים להגיע גם לתיקיית הבית שלכם, עם מגבלות קבועות:

| תיקיות | מה VOOL יכול לעשות |
| --- | --- |
| שולחן העבודה, הורדות, מסמכים | קריאה ושינוי של קבצים, עם שאלה מראש כפי שמצב הפעולה שלכם קובע |
| תמונות, סרטים (ב-Linux: וידאו), מוזיקה | קריאה בלבד: הצגת רשימה, חיפוש, פתיחה ומדידה, אף פעם לא שינוי |
| תיקיות בית גלויות אחרות שלכם, כמו `~/Projects` | קריאה בלבד |
| תיקיות מוסתרות (כמו `~/.ssh`), נתוני יישומים ומערכת (`Library`, `Applications`, `AppData`), תיקיית הנתונים של VOOL עצמו | אף פעם |

VOOL מחפש בתיקיות האלה רק כשבקשה צריכה זאת, למשל "מצא את ה-PDF של המס שלי" או
"איזה סרטון בתיקייה סרטים הוא הגדול ביותר". הוא לא מאנדקס את הכונן שלכם ברקע.

## עצות להגבלת ההיקף

* כוונו סביבת עבודה לפרויקט, לא לתיקיית הבית שלכם.
* שמרו קובצי פרטי גישה, חומרי מפתחות ומאגרי סיסמאות במנהל סיסמאות או בתיקייה מוסתרת, ולא
  מפוזרים בשולחן העבודה, בהורדות, במסמכים או בתיקיית פרויקט.
* השתמשו בפרויקט נפרד לכל עבודה, כדי שהקשר מעבודה אחת לא יגיע לאחרת.

{% hint style="warning" %}
כל מה ש-VOOL קורא, בתיקיית הפרויקט או בתיקיות הבית שלכם, עלול להיכלל במה שנשלח לספק שלכם
כשנבחר מודל ענן. הגבילו את ההיקף בכוונה.
{% endhint %}
