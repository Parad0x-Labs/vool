# קבלות

קבלה היא התיעוד העמיד של הרצה: אילו כלים נקראו, עם אילו קלטים, ומה כל אחד מהם
החזיר.

## למה הן קיימות

הסיכום של סוכן על העבודה של עצמו הוא טענה. הקבלה היא התיעוד שמולו אפשר לבדוק את הטענה
הזו.

## מה יש בקבלה

| שדה | משמעות |
| --- | --- |
| `tool` | איזו פעולה רצה |
| `input` | מה היא קיבלה |
| `result` | מה היא החזירה |
| `time` | מתי היא רצה |

הקבלות נשמרות בתיקיית "runtime home" של VOOL במחשב הזה (ראו
[תצורה](../reference/configuration.md)), ולא בתיקיות הפרויקטים שלכם. קבלה יוצאת מהמחשב
שלכם רק בתוך דוח באג שאתם רואים בתצוגה מקדימה ובוחרים לשלוח (ראו
[דיווח על באגים ופרטיות](../trust/bug-reporting.md)).
