# הפעלה ראשונה

בהפעלה הראשונה נשאלות ארבע שאלות קצרות. אפשר לדלג על כל אחת מהן ולשנות כל תשובה
מאוחר יותר. שום דבר לא נשלח לשום מקום בזמן שאתם עונים, מלבד בדיקה של מפתח ענן מול הספק
שלו, אם אתם מוסיפים מפתח כזה.

## מה קורה

1. **איפה שיחשוב?** במחשב הזה עם מודל מקומי, או באינטרנט עם מפתח של ספק שאתם
   משלמים לו. ראו [חיבור מודל](connect-a-model.md).
2. **בחרו תיקייה.** תיקיית הפרויקט ש-VOOL עובד בה. ראו
   [סביבות עבודה](../concepts/workspaces.md).
3. **מה מותר לו לעשות לבד?** כמה פעמים VOOL עוצר ושואל אתכם לפני שהוא משנה משהו. ראו
   [כלים](../concepts/tools.md).
4. **איך לקרוא לכם?** לא חובה. שם פרטי או כינוי מספיקים, והם נשארים
   במחשב הזה.

אחר כך מחוון המצב מציג "מקומי", "אוטומטי" או את שם ספק הענן, ומשקף את המודל
שנבחר כרגע.

**אשרו מודל מקומי פעם אחת.** לפני שמודל מקומי יכול לענות, פתחו את
**הגדרות ← דגמים וספקים ← דגמים מקומיים** ולחצו על **Certify** עבורו. זה מריץ בדיקה
קצרה במחשב שלכם.

## מה VOOL לא עושה בהפעלה הראשונה

* הוא לא יוצר חשבון.
* הוא לא דורש מפתח ענן. מודל מקומי מספיק כדי להשתמש ביישום.
* הוא לא מאנדקס את הכונן שלכם. הוא קורא קבצים רק כשבקשה צריכה אותם; ראו
  [סביבות עבודה](../concepts/workspaces.md) כדי לדעת לאילו תיקיות הוא יכול להגיע.

{% hint style="info" %}
אפשר לבחור תיקיית פרויקט אחרת בכל עת עם **+ פרויקט** בסרגל הצד של הצ׳אט.
{% endhint %}
