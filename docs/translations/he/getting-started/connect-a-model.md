# חיבור מודל

VOOL לא מגיע עם מודל. אתם בוחרים מודל, והבחירה קובעת אם בקשה נשארת במחשב שלכם
או יוצאת ממנו.

## מקומי

אם סביבת הרצה מקומית מותקנת ופועלת, VOOL מזהה אותה ומציג את המודלים שלה.
כשבוחרים אחד מהם, המחוון מציג "מקומי". פרטי ההגדרה בדף
[הרצת מודל מקומי](../guides/local-models.md).

## ענן

הוסיפו מפתח של ספק במסך **הגדרות ← מפתחות API**. המפתח נשמר בקובץ מוצפן במחשב
הזה (ראו [מודל האבטחה](../trust/security.md#מפתחות)), ומשמש לשליחת בקשות
**מהמחשב שלכם ישירות לספק**.

כשבוחרים מודל ענן, המחוון מציג את שם הספק, והוא מתחלף לפני ששום בקשה
נשלחת.

את השלבים הספציפיים ל-OpenRouter תמצאו בדף [חיבור OpenRouter](../guides/openrouter.md).

## החלפה

החלפת מודל מחליפה מצב. המחוון הוא הקובע: אם הוא מציג "מקומי",
הבקשה הבאה מטופלת במחשב הזה.
