# התקנה

ל-VOOL 0.7.7-beta יש הורדות של היישום למחשבי Mac עם Apple Silicon, למחשבי Mac עם Intel ול-Linux x86_64,
בדף [הגרסה v0.7.7-beta](https://github.com/Parad0x-Labs/vool/releases/tag/v0.7.7-beta).
אפשר גם להתקין מקוד המקור עם סקריפט האתחול (bootstrap) ב-macOS, ב-Linux או ב-Windows.
פרטים על חתימה ועדכונים בדף [מצב הגרסה](../trust/release-status.md).

## דרישות

| | מינימום | מומלץ |
| --- | ---: | ---: |
| זיכרון RAM | 8 GB | 16 GB או יותר |
| דיסק | 2 GB ליישום | 20 GB עם מודלים מקומיים |
| macOS | 14 Sonoma, ‏Apple Silicon או Intel ([מגבלות](#מחשבי-mac-עם-intel)) | 14 Sonoma או חדש יותר, Apple Silicon |
| Windows | 10 (64 סיביות) | 11 |
| Linux | glibc 2.31 | Ubuntu 22.04 או חדש יותר |

מודלים מקומיים צריכים הרבה יותר זיכרון מהיישום עצמו. הנחיות לבחירת גודל בדף
[הרצת מודל מקומי](../guides/local-models.md).

## הורדת היישום

| המחשב שלכם | הורדה |
| --- | --- |
| Mac עם Apple Silicon ‏(M1 ואילך) | [`VOOL-0.7.7-beta-macos-arm64.dmg`](https://github.com/Parad0x-Labs/vool/releases/download/v0.7.7-beta/VOOL-0.7.7-beta-macos-arm64.dmg) |
| Mac עם שבב Intel | [`VOOL-0.7.7-beta-macos-x86_64.dmg`](https://github.com/Parad0x-Labs/vool/releases/download/v0.7.7-beta/VOOL-0.7.7-beta-macos-x86_64.dmg) |
| Linux x86_64 ‏(Ubuntu 22.04 / 24.04) | [`vool-0.7.7-beta-linux-x86_64.tar.gz`](https://github.com/Parad0x-Labs/vool/releases/download/v0.7.7-beta/vool-0.7.7-beta-linux-x86_64.tar.gz) |

כדי לדעת איזה שבב יש ב-Mac שלכם, פתחו את תפריט Apple ובחרו **מידע על Mac זה**. אם מופיע
"Apple M…‎", זה Apple Silicon; אם מופיע "Intel", זה מעבד Intel. היישום ל-Apple Silicon לא
פועל ב-Mac עם Intel, ומודיע על כך כשפותחים אותו.

לפני שפותחים את הקובץ שהורדתם, בדקו את ה-SHA-256 שלו (ראו [אימות הורדה](#אימות-הורדה)).

### פתיחה ראשונה ב-Mac

היישום בגרסת הבטא עדיין לא עבר אישור נוטריוני של Apple, ולכן macOS מבקש מכם לאשר בפעם הראשונה
שאתם פותחים אותו. זה צפוי, וקורה רק פעם אחת.

1. פתחו את קובץ ה-DMG וגררו את **VOOL** אל **יישומים**.
2. לחצו לחיצה כפולה על VOOL. ‏macOS מודיע שאין לו אפשרות לבדוק אם היישום מכיל תוכנה זדונית.
   סגרו את ההודעה.
3. פתחו את **הגדרות המערכת ← פרטיות ואבטחה**. גללו למטה אל ההודעה לגבי VOOL
   ולחצו על **פתיחה בכל זאת**. הזינו את הסיסמה שלכם כדי לאשר.

ב-macOS 14 Sonoma אפשר במקום זאת ללחוץ על VOOL בתיקייה יישומים תוך כדי הקשה על Control, לבחור
**פתח**, ואז ללחוץ שוב על **פתח**.

### Linux

הורידו מדף הגרסה את קובץ ה-tar ואת קובץ ה-`.sha256` שלו, בדקו אותו, ואז הריצו את המתקין
שמגיע איתו. אין צורך ב-sudo או ב-Python של המערכת.

```bash
sha256sum -c vool-0.7.7-beta-linux-x86_64.tar.gz.sha256
tar -xzf vool-0.7.7-beta-linux-x86_64.tar.gz
bash vool-0.7.7-beta-linux-x86_64/install.sh
~/.local/bin/vool
```

VOOL מותקן ב-`~/.local/share/vool`, מציב את הפקודה `vool` ב-`~/.local/bin` ומוסיף רשומה
לתפריט היישומים. יישום המחשב פותח את הצ׳אט בדפדפן שלכם; סגירת הדפדפן לא עוצרת את VOOL.
כדי להסיר את VOOL, הריצו `bash ~/.local/share/vool/current/uninstall.sh`.
הצ׳אטים וההגדרות שלכם נשארים בפרופיל שלכם.

החל מגרסה 0.7.5, ההורדה ל-Linux מתעדכנת מתוך VOOL. הגרסה החדשה מותקנת לצד
הישנה. אם היא לא עולה כמו שצריך, VOOL חוזר לגרסה הקודמת מעצמו.

### אחרי ההתקנה

לפני שמודל מקומי יכול לענות, פתחו את **הגדרות ← דגמים וספקים ← דגמים מקומיים** ולחצו פעם אחת על **Certify** עבורו. זה מריץ בדיקה קצרה במחשב שלכם.

החל מגרסה 0.7.5, VOOL מעדכן את עצמו: כשהאפשרות "יציאה לאינטרנט באופן עצמאי" מופעלת, הוא מציג הודעה ומתקין גרסה חדשה בלחיצה אחת. עדכון מ-0.7.4 או מ-0.7.3 ב-Mac: הפעילו את "יציאה לאינטרנט באופן עצמאי" (הגדרות > פרטיות והרשאות) ולחצו פעם אחת על "בדיקת עדכונים". מ-0.7.4 ומטה ב-Linux, או מ-0.7.2 ומטה ב-Mac: הורידו את 0.7.7 והתקינו אותה מעל הגרסה הנוכחית שלכם. הצ׳אטים וההגדרות שלכם
שמורים בפרופיל שלכם, מחוץ ליישום. תכונות הקריפטו כבויות כברירת מחדל.

## התקנה מקוד המקור

הריצו את סקריפט האתחול של הפלטפורמה שלכם:

```bash
curl -fsSLo bootstrap_vool.sh https://raw.githubusercontent.com/Parad0x-Labs/vool/v0.7.7-beta/installer/bootstrap_vool.sh
bash bootstrap_vool.sh --ref v0.7.7-beta
```

```powershell
Invoke-WebRequest https://raw.githubusercontent.com/Parad0x-Labs/vool/main/installer/bootstrap_vool.ps1 -OutFile bootstrap_vool.ps1
powershell -ExecutionPolicy Bypass -File .\bootstrap_vool.ps1
```

הפקודות ל-macOS / Linux מקבעות ל-`v0.7.7-beta` גם את סקריפט האתחול וגם את הורדת קוד המקור שלו. כדי לבחור גרסה אחרת, שנו גם את התג בכתובת של הסקריפט וגם את `--ref`. סקריפט האתחול מקבל שם של ענף (branch) או תג של גרסה, לא hash של commit.

התקנה מקוד המקור דורשת Python 3.11 ומעלה. אם לא נמצאת גרסה כזו, המתקין מנסה
להתקין אחת. הורדות היישום כוללות Python משלהן.

המתקין מכין את סביבת ה-Python, בודק את החומרה שלכם, מגדיר את המודל המקומי
ומפעיל את השירותים המקומיים. הקצו זמן ומקום בדיסק להורדה הראשונה של המודל.
אחרי ההגדרה, המודל המקומי עונה גם בלי חיבור לאינטרנט; כלי הרשת ומודלי הענן צריכים
חיבור.

## מחשבי Mac עם Intel

VOOL פועל במחשבי Mac עם Intel ו-macOS 14 ומעלה (למשל MacBook Pro משנת 2020 עם מסך 13 אינץ׳),
מההורדה ל-Intel או מקוד המקור. מתקין קוד המקור מזהה את מעבד ה-Intel ומתקין את
גרסאות ה-Intel של כל התלויות. יש שתי מגבלות שייחודיות ל-Intel:

* **אין אימון של מודלים מקומיים.** PyTorch לא פרסמה גרסה ל-macOS על Intel מאז 2.3, ולכן
  המתקין מדלג עליה, ואימון LoRA מדווח שהוא לא זמין. הצ׳אט, הזיכרון,
  הכלים ומודלי הענן לא מושפעים.
* **מודלים מקומיים רצים רק על המעבד (CPU).** למריצי המודלים המקומיים אין האצת GPU לגרפיקה של Intel,
  ולכן תשובות מקומיות איטיות פי כמה מאשר ב-Apple Silicon. ב-Mac עם 8 GB, השתמשו במודל
  ענן לצ׳אט; עם 16 GB, המודל המקומי הקטן שהמתקין מגדיר כברירת מחדל עובד, אבל לאט.

ב-Mac עם Intel, מודלים מקומיים רצים על המעבד ואיטיים. תשובה ארוכה מהזיכרון עלולה לחרוג מהזמן המוקצב, ולכן בינתיים השתמשו שם במודל ענן. האישור של מודלים מקומיים (Certify) לוקח בחשבון מעבדים איטיים יותר.

למחשבי Mac עם Intel יש הורדה משלהם, `VOOL-0.7.7-beta-macos-x86_64.dmg`. ההורדה ל-Apple Silicon
לא פועלת על Intel, ומודיעה על כך כשמפעילים אותה.

## אימות הורדה

לכל הורדה בדף הגרסה יש לידה סכום ביקורת SHA-256. אמתו את הקובץ לפני
שאתם פותחים אותו:

```bash
shasum -a 256 <downloaded-artifact>    # macOS
sha256sum <downloaded-artifact>         # Linux
```

```powershell
Get-FileHash -Algorithm SHA256 <downloaded-artifact>
```

השוו את התוצאה לסכום הביקורת שפורסם עם אותה גרסה. אם הם שונים,
מחקו את הקובץ והורידו אותו מחדש.
