# מודל האבטחה

## גבולות

* **מגבלות התיקיות** תוחמות את הגישה לקבצים. VOOL קורא ומשנה קבצים בתיקיית הפרויקט של
  הצ׳אט. מחוץ לה, VOOL יכול לקרוא את תיקיות הבית הגלויות שלכם, ולשנות קבצים רק בתיקיות שולחן
  העבודה, הורדות ומסמכים; תיקיות מוסתרות, נתוני יישומים ומערכת והנתונים של VOOL עצמו אף פעם
  לא נקראים. ראו [סביבות עבודה](../concepts/workspaces.md).
* **מאגר פרטי הגישה** מחזיק את המפתחות. מפתחות לא נכתבים לקובצי תצורה או ליומנים.
* **אישור כלים** תוחם שינויים. במצב "ידני" כל שינוי שואל קודם; במצב "אוטומטי" עריכות ופקודות
  יומיומיות יכולות לרוץ אוטומטית, ואילו מחיקה, דריסה, התקנה, הוצאת כסף ושינוי הגדרות עדיין
  שואלים. ראו [כלים](../concepts/tools.md).

## הרשת המקומית שלכם

כברירת מחדל, VOOL מאזין רק במחשב הזה. כשאתם מגדירים אותו להאזין ברשת המקומית שלכם, רק המחשב
הזה נחשב לכם. ההגדרות, הקבצים, המפתחות, הכלים והתכונות הפרטיות עונים רק לו.

מכשיר אחר ברשת מקבל צ׳אט פשוט. הוא יכול גם לקרוא דף אינטרנט ציבורי אחד בכל פעם. הדף הזה
חייב להיות באינטרנט הציבורי: כתובות במחשב הזה או ברשת המקומית שלכם נדחות, וכל הפניה נבדקת
באותה דרך. חיפושים ברשת, מחקר, הדפדפן, הצעות מחיר, תשלומים ומפתחות בתשלום שלכם עובדים רק
במחשב הזה.

## הגשר ל-Discord

הגשר ל-Discord עונה רק לבעלים שלו. משתמש ה-Discord הראשון ששולח לו פקודה הופך לבעלים. כדי
לבחור את הבעלים בעצמכם, הגדירו את `VOOL_DISCORD_OWNER_USER_ID` למזהה המשתמש שלכם ב-Discord;
עשו זאת בכל ערוץ שאנשים אחרים יכולים לכתוב בו. כל השאר מקבלים הודעה, פעם אחת, שה-VOOL הזה
נעול לבעלים שלו, וההודעות שלהם לא מעובדות. גם הודעות ה-Discord של הבעלים מקבלות את אותן
מגבלות כמו מכשיר אחר ברשת.

## מפתחות

VOOL שומר את מפתחות הספקים שלכם בקובץ מוצפן בתיקיית "runtime home" שלו במחשב הזה (ראו
[תצורה](../reference/configuration.md)), שרק חשבון המשתמש שלכם יכול לקרוא. מפתחות ש-VOOL
כבר שמר בצרור המפתחות (Keychain) של macOS ב-Mac נשארים קריאים שם. מפתח משמש מהמחשב שלכם כדי
להגיע לספק שלכם. הוא לא נשלח ל-Parad0x Labs, ואין בנתיב הבקשה שום נקודת קצה שמופעלת על ידי
Parad0x.

{% hint style="info" %}
הקובץ המוצפן מוגן על ידי הרשאות הקבצים של חשבון המשתמש שלכם, ולא על ידי סיסמה נפרדת.
השאירו את הצפנת הדיסק מופעלת (FileVault ב-Mac), כדי שדיסק שאבד או נגנב לא יחשוף את המפתחות
שלכם.
{% endhint %}

## תוספים

תוסף רץ עם הגישה של סביבת ההרצה. זה מה שהופך תוספים לשימושיים, וזה גם מה שהופך אותם לראויים
לקריאה לפני ההתקנה. ראו [מיומנויות ותוספים](../guides/skills-and-plugins.md).

לא חתום. ראו [מצב הגרסה](release-status.md).
{% endhint %}
