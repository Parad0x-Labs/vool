# מצב הגרסה

הדף הזה הוא המקור המוסמך והמתוחזק למצב הגרסה. מסמכים אחרים מזכירים עובדות על הגרסה בדרך
אגב; כשהם לא מסכימים עם הדף הזה, הדף הזה קובע.

## השלב הנוכחי

VOOL נמצא בגרסת **בטא**. הגרסה הנוכחית היא
[**v0.7.7-beta**](https://github.com/Parad0x-Labs/vool/releases/tag/v0.7.7-beta), גרסת GitHub
שנבנתה מ-`main` ב-`8af687c`. יש בה הורדות של היישום לשלוש פלטפורמות, ולכל אחת מהן סכום
ביקורת SHA-256 שפורסם. התקנה מקוד המקור עם סקריפט האתחול עדיין נתמכת ב-macOS, ב-Linux
וב-Windows; ראו [התקנה](../getting-started/install.md).

| הורדה | עבור |
| --- | --- |
| `VOOL-0.7.7-beta-macos-arm64.dmg` | מחשבי Mac עם Apple Silicon, עם macOS 14 ומעלה |
| `VOOL-0.7.7-beta-macos-x86_64.dmg` | מחשבי Mac עם Intel, עם macOS 14 ומעלה |
| `vool-0.7.7-beta-linux-x86_64.tar.gz` | Linux x86_64, נבדק על Ubuntu 22.04 ו-24.04 |

רשומות הגרסה במאגר הזה מכסות את ערוץ GitHub. ערוצי הורדה אחרים מופעלים בנפרד; אמתו כל
הורדה מול סכום הביקורת שפורסם בגרסת GitHub.

| | מצב |
| --- | --- |
| הורדות ציבוריות | קובץ DMG ל-macOS על Apple Silicon, קובץ DMG ל-macOS על Intel וקובץ tar ל-Linux x86_64, בגרסת v0.7.7-beta ב-GitHub |
| סכומי ביקורת שפורסמו | SHA-256 לכל הורדה, בדף הגרסה |
| חתימת קוד | יישומי ה-macOS חתומים בחתימת ad-hoc, לא ב-Developer ID. החתימה תתווסף אחרי גרסת הבטא הזו, והיא לא תנאי לשחרור שלה |
| אישור נוטריוני ל-macOS | לא עבר אישור נוטריוני. macOS מבקש מכם לאשר את הפתיחה הראשונה (ראו למטה) |
| Windows | אין הורדה ל-Windows בגרסה הזו; ב-Windows ההתקנה היא מקוד המקור והתמיכה ניסיונית |
| עדכונים | החל מגרסה 0.7.5, VOOL מעדכן את עצמו: כשהאפשרות "יציאה לאינטרנט באופן עצמאי" מופעלת, הוא מציג הודעה ומתקין גרסה חדשה בלחיצה אחת. עדכון מ-0.7.4 או מ-0.7.3 ב-Mac: הפעילו את "יציאה לאינטרנט באופן עצמאי" (הגדרות > פרטיות והרשאות) ולחצו פעם אחת על "בדיקת עדכונים". ב-Linux, או מ-0.7.2, מ-0.7.1 או מ-0.7.0: הורידו את 0.7.7 והתקינו אותה מעל הגרסה הנוכחית שלכם. הצ׳אטים וההגדרות שלכם שמורים בפרופיל שלכם, מחוץ ליישום. ראו [עדכונים והעברת נתונים](../reference/updates-migration.md) |
| יציבות ה-API | משתנה בין גרסאות |

## מה זה אומר בשבילכם

* בהפעלה הראשונה של יישום Mac, macOS מסרב לפתוח אותו כי הוא לא עבר אישור נוטריוני.
  זה צפוי בשלב הזה, ולא סימן להורדה פגומה. בדקו את סכום הביקורת, ואז פתחו את
  **הגדרות המערכת ← פרטיות ואבטחה** ולחצו על **פתיחה בכל זאת**. ב-macOS 14 אפשר במקום זאת
  ללחוץ על היישום תוך כדי הקשה על Control ולבחור **פתח**.
* בחרו את ההורדה ל-Mac שמתאימה לשבב שלכם. היישום ל-Apple Silicon לא פועל ב-Mac עם Intel,
  ומודיע על כך כשמפעילים אותו.
* פורמטים של תצורה עלולים להשתנות בין גרסאות.
* תכונות הקריפטו כבויות עד שתפעילו אותן.

## מגבלות הבטא והפיילוט, במפורש

| יכולת | המצב בגרסה הזו |
| --- | --- |
| קריפטו וארנק | כבויים כברירת מחדל. כשמפעילים אותם, VOOL משתמש ברשת הראשית; רשתות הבדיקה נמצאות ב-Developer options. כל תשלום עובר דרך הארנק של VOOL, עם המגבלות שלו, האישור שלכם וקבלה. ראו [ארנק](../guides/wallet.md). |
| העברות ברשת הראשית | מטבעות מקוריים, ו-USDT ב-Solana, ב-Ethereum, ב-BNB Smart Chain וב-Arbitrum One, שנשלחים מארנק VOOL שנוצר במכשיר הזה. USDC ב-Solana וב-Base מיועד לערוצי תשלום בלבד. חשבון מחובר או חשבון לצפייה בלבד יכול לקבל תשלומים ולהציג את היתרה שלו, אבל לא יכול לשלוח מ-VOOL. |
| תשלום עם x402 | אתרים שמבקשים תשלום x402 ב-USDC ברשת Base או Base Sepolia יכולים לקבל תשלום מארנק ה-Crypto Pilot שלכם: אישור אחד עם ה-PIN שלכם, בתוך המגבלות שלכם. שירות התשלום של האתר מכסה את עמלת הרשת. תחת **הגדרות ← קריפטו ← Payment channels** יש מתג הפעלה/כיבוי לכל דרך שבה הארנק יכול לשלם לאתר; ערוץ כבוי מסרב לפני שמשהו נחתם. עוד לא בוצע בדרך הזו אף תשלום אמיתי ברשת הראשית. תשלום דרך Solana pay-kit לא כלול בהורדות; הערוץ הזה מוצג כלא שמיש. |
| X | מכל צ׳אט: חיפוש פוסטים וחשבונות, Spaces, טרנדים והודעות ישירות, ובדיקה של המלצות קודמות על טוקן. כל דבר שפועל בחשבון שלכם ממתין לאישור שלכם. |
| הכתבה | לא זמינה זמנית בגרסת הבטא הזו; היא תחזור בעדכון. |
| מצב השאלה ב"מעבר זמני לענן" (burst) | השאלה שמוצגת לכל קריאה עוד לא מחוברת בגרסה הזו. |
| מודלים מקומיים | לפני שמודל מקומי יכול לענות, פתחו את **הגדרות ← דגמים וספקים ← דגמים מקומיים** ולחצו פעם אחת על **Certify** עבורו. |
| מחשבי Mac עם Intel | מודלים מקומיים רצים על המעבד ואיטיים. האישור (Certify) לוקח בחשבון מעבדים איטיים יותר, אבל תשובה ארוכה מהזיכרון עלולה לחרוג מהזמן המוקצב, ולכן בינתיים השתמשו שם במודל ענן. |
| צ׳אט פרטי | כתבו "צ׳אט פרטי", "אל תשמור את זה" או "בלי הקלטה", ושום דבר מהצ׳אט הזה לא נשמר. הפקודות עובדות בכל 17 השפות של היישום. |
| שכחה | השכחה מנקה את הזיכרון של VOOL ואת היסטוריית ההרצה התואמת, כך שהפריט לא נשלף ולא מוצג שוב, ומוחקת את המילים שנשכחו מקובץ הזיכרון המקומי של VOOL ומאינדקס החיפוש שלו. VOOL שומר את המילים שביקשתם ממנו לשכוח ברשימה קצרה במחשב שלכם, כדי שיוכל להמשיך לסרב להן. אחרי שביקשתם לשכוח משהו בצ׳אט, VOOL לא יקבל שוב את אותה עובדה בצ׳אט הזה; פתחו צ׳אט חדש כדי לספר לו אותה שוב. |
| קובצי PDF סרוקים | נקראים עם זיהוי הטקסט המובנה של ה-Mac, ולכן רק במחשבי Mac. |
| חיית שולחן עבודה | חיית המחמד נמצאת בחלון של VOOL. גרירה שלה אל מחוץ לחלון לא מעבירה אותה לשולחן העבודה. |
| קודקס המיומנויות | "עיון בקודקס המיומנויות" מציג את המיומנויות שרשומות עבור גרסת ה-VOOL המדויקת שלכם, ואתם סוקרים מיומנות לפני שהיא מותקנת. "פרסום בקודקס המיומנויות" בודק מיומנות שיצרתם במחשב שלכם, ואז פותח את אתר קודקס המיומנויות כשהיא כבר ממולאת בו; אתם נכנסים לחשבון שם ולוחצים על Send, ו-VOOL עצמו לא שולח שום דבר. רק הטקסט של המיומנות נשלח, ולכן עדיין אי אפשר לשתף מיומנות עם קבצים נוספים. |

החתימה ב-Developer ID והאישור הנוטריוני ל-macOS, וסכומי ביקורת חתומים ל-Linux, הם הצעדים
הבאים במסלול השחרור; אף אחד מהם לא נטען היום.
