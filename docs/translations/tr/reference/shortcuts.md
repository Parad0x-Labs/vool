# Klavye kısayolları

macOS'ta `⌘`, Windows ve Linux'ta `Ctrl`.

| Eylem | Kısayol |
| --- | --- |
| Yeni oturum | `⌘ N` |
| Komut paleti | `⌘ K` |
| Model değiştir | `⌘ M` |
| Çalışma alanı panelini aç/kapat | `⌘ J` |
| Geçerli çalıştırmayı durdur | `Esc` |
| Ayarlar | `⌘ ,` |
