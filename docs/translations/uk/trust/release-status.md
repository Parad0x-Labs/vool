# Статус випуску

Ця сторінка — підтримуване авторитетне джерело щодо статусу випуску. Інші документи згадують факти про випуск
мимохідь; якщо вони розходяться з цією сторінкою, правильна ця сторінка.

## Поточна стадія

VOOL перебуває на стадії **бета**. Поточний випуск —
[**v0.7.7-beta**](https://github.com/Parad0x-Labs/vool/releases/tag/v0.7.7-beta), випуск на GitHub,
зібраний із `main` на `8af687c`. У ньому є завантаження застосунку для трьох платформ,
для кожного — опублікована контрольна сума SHA-256. Встановлення з вихідного коду за допомогою скрипта початкового встановлення
і далі підтримується на macOS, Linux і Windows; див. [Встановлення](../getting-started/install.md).

| Завантаження | Для чого |
| --- | --- |
| `VOOL-0.7.7-beta-macos-arm64.dmg` | Mac з Apple Silicon, macOS 14 або новіша |
| `VOOL-0.7.7-beta-macos-x86_64.dmg` | Mac з Intel, macOS 14 або новіша |
| `vool-0.7.7-beta-linux-x86_64.tar.gz` | Linux x86_64, протестовано на Ubuntu 22.04 і 24.04 |

Записи про випуски в цьому репозиторії охоплюють канал GitHub. Інші канали завантаження
обслуговуються окремо; звіряйте будь-яке завантаження з контрольною сумою, опублікованою у випуску на
GitHub.

| | Статус |
| --- | --- |

У Linux або з 0.7.2, 0.7.1 чи 0.7.0: завантажте 0.7.7 і встановіть поверх поточної версії. Ваші чати й налаштування зберігаються у вашому профілі, поза застосунком. Див. ## Що це означає для вас

* Під час першого запуску застосунку для Mac macOS відмовляється його відкривати, бо його не нотаризовано.
  На цій стадії так і має бути, і це не ознака пошкодженого завантаження. Перевірте контрольну суму,
  потім відкрийте **Системні параметри → Приватність і безпека** й натисніть **Все одно відкрити**. У
  macOS 14 можна натомість клацнути застосунок, утримуючи клавішу Control, і вибрати **Відкрити**.
* Виберіть завантаження для Mac, яке відповідає вашому чипу. Застосунок для Apple Silicon не працює на
  Mac з Intel і повідомляє про це під час запуску.
* Формати конфігурації можуть змінюватися від збірки до збірки.
* Криптофункції вимкнено, доки ви їх не ввімкнете.

| Перекази в mainnet | Нативні монети, а також USDT у Solana, Ethereum, BNB Smart Chain і Arbitrum One, що надсилаються з VOOL Wallet, створеного на цьому пристрої. USDC у Solana і Base — лише для платіжних каналів. Підключений обліковий запис або обліковий запис лише для перегляду може отримувати кошти й показувати свій баланс, але не може надсилати з VOOL. |
| Оплата через x402 | Вебсайти, які запитують оплату x402 в USDC у мережі Base або Base Sepolia, можна оплачувати з вашого гаманця Crypto Pilot: одне схвалення PIN-кодом у межах ваших лімітів. Мережеву комісію покриває платіжний сервіс вебсайту. У **Налаштування → Крипто → Payment channels** є перемикач для кожного способу, яким гаманець може оплатити вебсайт; вимкнений канал відмовляє ще до того, як щось підписано. Справжніх платежів у mainnet цим способом ще не здійснювали. Оплата через Solana pay-kit не входить до завантажень; цей канал показано як недоступний. |
| X | З будь-якого чату: пошук публікацій і облікових записів, Spaces, трендів і особистих повідомлень, а також пошук минулих прогнозів щодо токена. Усе, що діє від імені вашого облікового запису, чекає на вашу згоду. |
| Диктування | Недоступне в цій бета-збірці. |
| Хмарний режим «сплеску» з підтвердженням | Запит підтвердження для кожного виклику в цій збірці ще не підключено. |
| Локальні моделі | Перш ніж локальна модель зможе відповідати, відкрийте **Налаштування → Моделі і провайдери → Локальні моделі** й один раз натисніть для неї **Certify**. |
| Mac з Intel | Локальні моделі працюють на процесорі й повільні. Сертифікація враховує повільніші процесори, але довга відповідь з опорою на памʼять може не вкластися в час очікування, тому поки що використовуйте там хмарну модель. |
| Приватний чат | Скажіть «приватний чат», «не зберігайте це» або «без запису», і нічого з цього чату не зберігається. Команди працюють усіма 17 мовами застосунку. |
| Забування | Забування очищає памʼять VOOL і відповідну історію виконання, тож елемент більше не пригадується й не показується в списках, і стирає забуті слова з локального файлу памʼяті VOOL та його пошукового індексу. VOOL зберігає слова, які ви попросили забути, у короткому списку на вашому компʼютері, щоб і далі відмовлятися їх приймати. Після того як ви щось забули в чаті, VOOL не прийме той самий факт назад у цьому чаті; щоб повідомити його знову, почніть новий чат. |
| Скановані PDF | Читаються вбудованим розпізнаванням тексту Mac, тому лише на Mac. |
| Улюбленець на стільниці | Улюбленець живе у вікні VOOL. Якщо витягнути його з вікна, він не переміститься на стільницю. |
| Кодекс навичок | «Відкрити кодекс навичок» показує навички, перелічені для вашої точної версії VOOL, і ви переглядаєте навичку перед встановленням. «Опублікувати в кодексі навичок» перевіряє навичку, створену вами на вашому компʼютері, а потім відкриває сайт кодексу навичок, де навичку вже заповнено; ви входите там і надсилаєте її, а сам VOOL нічого не надсилає. Передається лише текст навички, тому навичкою з додатковими файлами поки що не можна поділитися. |

Підпис Developer ID і нотаризація для macOS, а також підписані контрольні суми для Linux — наступні кроки
на шляху до випуску; сьогодні ні те, ні інше не заявлено.
