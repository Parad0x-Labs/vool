# Модель безпеки

## Межі

* **Обмеження папок** визначають доступ до файлів. VOOL читає та змінює файли в папці проєкту
  чату. Поза нею VOOL може читати видимі папки у вашій домашній папці та змінювати файли лише в
  Desktop, Downloads і Documents; приховані папки, дані застосунків і системи, а також власні дані VOOL
  ніколи не читаються. Див. [Робочі простори](../concepts/workspaces.md).
* **Сховище облікових даних** зберігає ключі. Ключі не записуються у файли конфігурації та журнали.
* **Підтвердження інструментів** обмежує зміни. У режимі «Ручний» кожна зміна спершу потребує дозволу; у режимі «Авто»
  повсякденні правки й команди можуть виконуватися автоматично, а видалення, перезапис, встановлення,
  витрати й зміна налаштувань і далі потребують дозволу. Див. [Інструменти](../concepts/tools.md).

## Ваша локальна мережа

За замовчуванням VOOL приймає підключення лише з цього компʼютера. Якщо налаштувати його на роботу в локальній
мережі, вами вважається лише цей компʼютер. Налаштування, файли, ключі, інструменти й приватні
функції відповідають лише йому.

Інший пристрій у мережі отримує звичайний чат. Він також може читати по одній загальнодоступній вебсторінці за
раз. Ця сторінка має бути в публічному інтернеті: адреси на цьому компʼютері чи у вашій локальній
мережі відхиляються, і кожна переадресація перевіряється так само. Вебпошук, дослідження,
браузер, котирування, платежі й ваші платні ключі працюють лише на цьому компʼютері.

## Міст Discord

Міст Discord відповідає лише своєму власникові. Власником стає перший користувач Discord,
який надіслав йому команду. Щоб вибрати власника самостійно, задайте в `VOOL_DISCORD_OWNER_USER_ID` свій
ідентифікатор користувача Discord; робіть так для будь-якого каналу, у якому можуть писати інші люди. Усім іншим один раз
повідомляється, що цей VOOL закріплено за його власником, і їхні повідомлення не обробляються. Навіть на
повідомлення власника з Discord діють ті самі обмеження, що й для іншого пристрою в мережі.

## Ключі

VOOL зберігає ключі ваших провайдерів у зашифрованому файлі у своїй папці runtime home на цьому компʼютері
(див. [Конфігурація](../reference/configuration.md)); читати цей файл може лише ваш обліковий запис користувача.
Ключі, які VOOL уже зберігав у звʼязці ключів macOS на Mac, і далі читаються звідти. Ключ використовується
з вашого компʼютера, щоб звертатися до вашого провайдера. Його не надсилають до Parad0x Labs, і на шляху запиту немає
кінцевої точки, якою керує Parad0x.

{% hint style="info" %}
Зашифрований файл захищено правами доступу до файлів вашого облікового запису користувача, а не окремим
паролем. Тримайте шифрування диска ввімкненим (FileVault на Mac), щоб утрачений або викрадений диск не
розкрив ваших ключів.
{% endhint %}

## Плагіни

Плагін працює з тими самими правами доступу, що й середовище виконання. Саме це робить плагіни корисними, і саме тому
їх варто прочитати перед встановленням. Див. [Навички та плагіни](../guides/skills-and-plugins.md).

## Повідомлення про проблему

Повідомляйте про проблеми безпеки конфіденційно через
[GitHub Security Advisories](https://github.com/Parad0x-Labs/vool/security/advisories/new),
і ніколи — у публічному issue. Укажіть версію, платформу й кроки для відтворення.

{% hint style="warning" %}
Застосунки для macOS підписано ad-hoc і не нотаризовано; архів tar для Linux не підписано. Див.
[Статус випуску](release-status.md).
{% endhint %}
