# VOOL

VOOL — настільний ШІ-асистент. Він встановлюється на компʼютер як застосунок і може
запускати моделі ШІ локально на цій машині або підключатися до хмарного провайдера ШІ з вашим
власним ключем API. Він веде зрозумілий журнал кожної своєї дії.

Він безкоштовний і з локальними моделями працює без інтернету. Є завантаження для Mac (Apple Silicon
та Intel) і Linux x86_64; Windows підтримується експериментально й встановлюється з вихідного коду.

У цій документації описано, як встановити VOOL і підключити модель, а також як він
поводиться з вашими файлами, вашою памʼяттю та вашими ключами.

## Порівняння з іншими

На 150 раніше не використаних питаннях LoCoMo на памʼять, коли за кожного агента відповідала та сама модель,
а оцінював той самий GPT-4o, памʼять VOOL перевершила два інші агенти з відкритим кодом:

| | VOOL | OpenClaw | Hermes |
| --- | --- | --- | --- |
| Правильні відповіді | **82,7 %** (124 / 150) | 71,3 % (107) | 62,7 % (94) |
| Токенів на питання | **9,6k** | 51,8k | 33,5k |
| Вартість питання | **0,0033 $** | 0,0100 $ | 0,0046 $ |

Це в 5,4 раза менше токенів, ніж в OpenClaw, і в 3,5 раза менше, ніж у Hermes, за третини вартості
відповіді OpenClaw. Памʼять із VOOL 0.7 набрала на тих самих питаннях 123 зі 150.
Усі прогони, умови та слабкі місця опубліковано: [бенчмарки памʼяті](https://github.com/Parad0x-Labs/vool/tree/main/docs/benchmarks).

## Що таке VOOL

* **Настільний застосунок.** Встановлюється на ваш компʼютер — це не вкладка браузера і не
  розміщений у мережі сервіс.
* **Працює без інтернету.** Якщо вибрано локальну модель, VOOL не потребує підключення до інтернету.
* **Локально за замовчуванням.** Якщо вибрано локальну модель, запити й файли обробляються
  на вашому компʼютері.
* **Не привʼязаний до моделі.** Можна вибрати як локальні середовища виконання, так і хмарних провайдерів. Хмарний
  ключ ви надаєте самі; він залишається на вашому компʼютері.
* **Перевірюваний.** Кожен виклик інструмента записується разом із вхідними даними й результатами, тож
  перебіг роботи можна перечитати згодом.

{% hint style="warning" %}
VOOL перебуває в бета-версії для Mac з Apple Silicon, Mac з Intel і Linux x86_64. Застосунки для Mac
ще не нотаризовано Apple, тому під час першого відкриття macOS попросить підтвердження; на
сторінці [Встановлення](getting-started/install.md#перше-відкриття-на-mac) показано, як це зробити. Перед встановленням
прочитайте [Статус випуску](trust/release-status.md).
{% endhint %}

## Два режими, без недомовок

VOOL розрізняє рівно два стани, і інтерфейс завжди показує, який із них активний:

1. **Локально** — робота залишається на цьому компʼютері.
2. **Хмара** — вибраний контекст надсилається безпосередньо вибраному вами провайдеру,
   з вашого компʼютера, з вашим ключем.

Третього стану немає, і між ними немає жодного ретранслятора, яким керує Parad0x. Подробиці —
у розділі [Обробка даних](trust/data-handling.md).
