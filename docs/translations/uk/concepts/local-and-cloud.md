# Локально і в хмарі

VOOL має два стани. Інтерфейс завжди показує, який із них активний.

## Локально

Усе залишається на цьому компʼютері. Модель працює через локальне середовище виконання, файли читаються
з диска, і жодних запитів до провайдера не надсилається.

## Хмара (назва провайдера)

Вибраний контекст надсилається безпосередньо вибраному вами провайдеру, з вашого компʼютера,
з вашим ключем.

«Вибраний контекст» — це те, що застосунок зібрав для цього запиту: ваше повідомлення, а також
файли й попередні ходи, потрібні для запиту. Застосунок показує його перед надсиланням.

{% hint style="danger" %}
Хмарний режим надсилає дані за межі вашого компʼютера. У цьому й полягає суть хмарного режиму. Твердження VOOL
стосується *маршруту* — запит іде з вашого компʼютера до вашого провайдера, — а не того, що
нічого не передається.
{% endhint %}

## Що є посередині

Нічого, чим керує Parad0x Labs. Для трафіку моделей немає ні проксі, ні шлюзу, ні ретранслятора.
Ваш ключ використовує застосунок на вашому компʼютері, щоб звертатися до провайдера безпосередньо.
