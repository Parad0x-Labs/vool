# Локально і в хмарі

VOOL може відповідати двома способами: на цьому компʼютері або через хмарного провайдера. Заголовок чату
показує, яким способом буде виконано наступний запит, — наприклад, **АВТО** з
**Спочатку локально**, коли VOOL Auto відповідає з цього компʼютера.

## Локально

Модель і ваші файли залишаються на цьому компʼютері. Модель працює через локальне середовище виконання,
файли читаються з диска, і жодних запитів до провайдера не надсилається. Актуальні відомості, як-от погода чи ціни, надходять із загальнодоступних вебсервісів, лише поки ввімкнено «Веб-пошук» (після нового встановлення його вимкнено), і ніколи — в режимі «Лише локально».

## Хмара (назва провайдера)

Вибраний контекст надсилається безпосередньо вибраному вами провайдеру, з вашого компʼютера,
з вашим ключем.

«Вибраний контекст» — це те, що застосунок зібрав для цього запиту: ваше повідомлення, а також
файли й попередні ходи, потрібні для запиту.

{% hint style="danger" %}
Хмарний режим надсилає дані за межі вашого компʼютера. У цьому й полягає суть хмарного режиму. Твердження VOOL
стосується *маршруту* — запит іде з вашого компʼютера до вашого провайдера, — а не того, що
нічого не передається.
{% endhint %}

## Що є посередині

Нічого, чим керує Parad0x Labs. Для трафіку моделей немає ні проксі, ні шлюзу, ні ретранслятора.
Ваш ключ використовує застосунок на вашому компʼютері, щоб звертатися до провайдера безпосередньо.
