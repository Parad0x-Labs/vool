# Квитанції

Квитанція — це постійний запис запуску: які інструменти викликалися, з якими вхідними даними і
що повернув кожен із них.

## Навіщо вони потрібні

Підсумок агента про власну роботу — це твердження. Квитанція — це запис, з яким можна звірити
це твердження.

## Що в ній є

| Поле | Значення |
| --- | --- |
| `tool` | Яка дія виконалася |
| `input` | Що їй було передано |
| `result` | Що вона повернула |
| `time` | Коли вона виконалася |

Квитанції зберігаються в папці runtime home VOOL на цьому компʼютері (див.
[Конфігурація](../reference/configuration.md)), а не в папках ваших проєктів. Квитанція залишає
ваш компʼютер лише у складі звіту про помилку, який ви переглянули й вирішили надіслати (див.
[Звіти про помилки та приватність](../trust/bug-reporting.md)).
