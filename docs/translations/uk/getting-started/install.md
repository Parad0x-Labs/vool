# Встановлення

Для VOOL 0.7.7-beta є завантаження застосунку для Mac з Apple Silicon, Mac з Intel і Linux x86_64 на
сторінці [випуску v0.7.7-beta](https://github.com/Parad0x-Labs/vool/releases/tag/v0.7.7-beta).
Також можна встановити VOOL з вихідного коду за допомогою скрипта початкового встановлення на macOS, Linux або Windows.
Подробиці про підпис і оновлення — у розділі [Статус випуску](../../../trust/release-status.md).

## Вимоги

| | Мінімум | Із запасом |
| --- | ---: | ---: |
| Оперативна памʼять | 8 ГБ | 16 ГБ і більше |
| Диск | 2 ГБ для застосунку | 20 ГБ з локальними моделями |
| macOS | 14 Sonoma, Apple Silicon або Intel ([обмеження](#mac-з-intel)) | 14 Sonoma або новіша, Apple Silicon |
| Windows | 10 (64-біт) | 11 |
| Linux | glibc 2.31 | Ubuntu 22.04 або новіша |

Локальним моделям потрібно помітно більше оперативної памʼяті, ніж самому застосунку. Поради щодо розміру —
у розділі [Запуск локальної моделі](../../../guides/local-models.md).

## Завантаження застосунку

| Ваш компʼютер | Завантаження |
| --- | --- |
| Mac з Apple Silicon (M1 і новіші) | [`VOOL-0.7.7-beta-macos-arm64.dmg`](https://github.com/Parad0x-Labs/vool/releases/download/v0.7.7-beta/VOOL-0.7.7-beta-macos-arm64.dmg) |
| Mac із процесором Intel | [`VOOL-0.7.7-beta-macos-x86_64.dmg`](https://github.com/Parad0x-Labs/vool/releases/download/v0.7.7-beta/VOOL-0.7.7-beta-macos-x86_64.dmg) |
| Linux x86_64 (Ubuntu 22.04 / 24.04) | [`vool-0.7.7-beta-linux-x86_64.tar.gz`](https://github.com/Parad0x-Labs/vool/releases/download/v0.7.7-beta/vool-0.7.7-beta-linux-x86_64.tar.gz) |

Щоб дізнатися, який процесор у вашому Mac, відкрийте меню Apple і виберіть **Про цей компʼютер**. «Apple M…»
означає Apple Silicon, «Intel» — Intel. Застосунок для Apple Silicon не працює на Mac з Intel
і повідомляє про це під час відкриття.

Перед відкриттям перевірте SHA-256 завантаженого файлу (див. [Перевірка завантаження](#перевірка-завантаження)).

### Перше відкриття на Mac

Бета-версію застосунку ще не нотаризовано Apple, тому під час першого відкриття macOS попросить
підтвердження. Так і має бути, і це відбувається один раз.

1. Відкрийте DMG і перетягніть **VOOL** до **Програми**.
2. Двічі клацніть VOOL. macOS повідомить, що не може перевірити застосунок на наявність шкідливого ПЗ.
   Закрийте повідомлення.
3. Відкрийте **Системні параметри → Приватність і безпека**. Прокрутіть униз до повідомлення про VOOL
   і натисніть **Все одно відкрити**. Для підтвердження введіть пароль.

У macOS 14 Sonoma можна натомість у папці «Програми» клацнути VOOL, утримуючи клавішу Control, вибрати
**Відкрити**, а потім ще раз натиснути **Відкрити**.

### Linux

Завантажте архів tar і його файл `.sha256` зі сторінки випуску, перевірте архів, потім запустіть
інсталятор, що входить до нього. Ні sudo, ні системний Python не потрібні.

```bash
sha256sum -c vool-0.7.7-beta-linux-x86_64.tar.gz.sha256
tar -xzf vool-0.7.7-beta-linux-x86_64.tar.gz
bash vool-0.7.7-beta-linux-x86_64/install.sh
~/.local/bin/vool
```

VOOL встановлюється в `~/.local/share/vool`, розміщує команду `vool` у `~/.local/bin` і додає
пункт до меню застосунків. Настільна версія відкриває чат у вашому браузері; якщо закрити браузер,
VOOL продовжить працювати. Щоб видалити VOOL, виконайте `bash ~/.local/share/vool/current/uninstall.sh`.
Ваші чати й налаштування залишаються у вашому профілі.

Починаючи з 0.7.5 завантаження для Linux оновлюється всередині VOOL. Нова версія встановлюється поруч
зі старою. Якщо вона не запускається як слід, VOOL сам повертається до попередньої.

### Після встановлення

Перш ніж локальна модель зможе відповідати, відкрийте **Налаштування → Моделі і провайдери → Локальні моделі** й один раз натисніть для неї **Certify**. Це запускає коротку перевірку на вашому компʼютері.

Починаючи з 0.7.5 VOOL оновлюється сам: якщо ввімкнено «Виходити в інтернет самостійно», він показує сповіщення й встановлює нову версію одним натисканням. Оновлення з 0.7.4 або 0.7.3 на Mac: увімкніть «Виходити в інтернет самостійно» (Налаштування > Приватність і дозволи) й один раз натисніть «Перевірити оновлення». З 0.7.4 і старіших на Linux або з 0.7.2 і старіших на Mac: завантажте 0.7.7 і встановіть поверх поточної версії. Ваші чати й налаштування
зберігаються у вашому профілі, поза застосунком. Криптофункції за замовчуванням вимкнено.

## Встановлення з вихідного коду

Запустіть скрипт початкового встановлення для вашої платформи:

```bash
curl -fsSLo bootstrap_vool.sh https://raw.githubusercontent.com/Parad0x-Labs/vool/v0.7.7-beta/installer/bootstrap_vool.sh
bash bootstrap_vool.sh --ref v0.7.7-beta
```

```powershell
Invoke-WebRequest https://raw.githubusercontent.com/Parad0x-Labs/vool/main/installer/bootstrap_vool.ps1 -OutFile bootstrap_vool.ps1
powershell -ExecutionPolicy Bypass -File .\bootstrap_vool.ps1
```

Команди для macOS / Linux фіксують і скрипт початкового встановлення, і завантаження його вихідного коду на `v0.7.7-beta`. Щоб вибрати інший випуск, змініть і тег в URL скрипта, і `--ref`. Скрипт початкового встановлення приймає назву гілки або тег випуску, але не хеш коміту.

Для встановлення з вихідного коду потрібен Python 3.11 або новіший. Якщо його не знайдено, інсталятор спробує
його налаштувати. Завантаження застосунку містять власний Python.

Інсталятор готує середовище Python, перевіряє обладнання, налаштовує локальну
модель і запускає локальні служби. Закладіть час і місце на диску для першого завантаження моделі.
Після налаштування локальні моделі працюють без інтернету; вебінструментам і хмарним моделям потрібне
підключення.

## Mac з Intel

VOOL працює на Mac з Intel і macOS 14 або новішою (наприклад, на 13-дюймовому MacBook Pro 2020 року)
із завантаження для Intel або з вихідного коду. Інсталятор із вихідного коду визначає процесор Intel і
встановлює версії всіх залежностей для Intel. Два обмеження стосуються лише Intel:

* **Немає навчання локальних моделей.** PyTorch не випускає збірок для macOS на Intel починаючи з 2.3, тому
  інсталятор пропускає його, а навчання LoRA повідомляє, що воно недоступне. Чат, памʼять,
  інструменти й хмарні моделі це не зачіпає.
* **Локальні моделі працюють лише на CPU.** Програми запуску локальних моделей не мають прискорення на GPU для
  графіки Intel, тому локальні відповіді в кілька разів повільніші, ніж на Apple Silicon. На Mac з 8 ГБ
  використовуйте для чату хмарну модель; з 16 ГБ невелика локальна модель, яку інсталятор ставить за замовчуванням,
  працює, але повільно.

На Mac з Intel локальні моделі працюють на процесорі й повільні. Довга відповідь з опорою на памʼять може не вкластися в час очікування, тому поки що використовуйте там хмарну модель. Сертифікація локальних моделей враховує повільніші процесори.

Для Mac з Intel є окреме завантаження, `VOOL-0.7.7-beta-macos-x86_64.dmg`. Завантаження для Apple Silicon
не працює на Intel і повідомляє про це під час запуску.

## Перевірка завантаження

Біля кожного завантаження на сторінці випуску вказано контрольну суму SHA-256. Перевірте файл, перш ніж
відкривати його:

```bash
shasum -a 256 <downloaded-artifact>    # macOS
sha256sum <downloaded-artifact>         # Linux
```

```powershell
Get-FileHash -Algorithm SHA256 <downloaded-artifact>
```

Порівняйте результат із контрольною сумою, опублікованою разом із цим випуском. Якщо вони відрізняються,
видаліть файл і завантажте його знову.
