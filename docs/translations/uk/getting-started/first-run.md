# Перший запуск

Під час першого запуску VOOL ставить чотири короткі запитання. Будь-яке з них можна пропустити, а будь-яку
відповідь змінити пізніше. Поки ви відповідаєте, нічого нікуди не надсилається, окрім перевірки хмарного ключа в
його провайдера, якщо ви його додасте.

## Що відбувається

1. **Де йому думати?** На цьому компʼютері з локальною моделлю або онлайн із ключем від
   провайдера, якому ви платите. Див. [Підключення моделі](connect-a-model.md).
2. **Виберіть папку.** Папка проєкту, у якій працює VOOL. Див.
   [Робочі простори](../../../concepts/workspaces.md).
3. **Що йому можна самому?** Як часто VOOL зупиняється й питає вас, перш ніж щось змінити. Див.
   [Інструменти](../../../concepts/tools.md).
4. **Як його звати вас?** Необовʼязково. Достатньо імені чи прізвиська, і воно залишається на
   цьому компʼютері.

Після цього індикатор режиму показує «Локально», «Авто» або назву хмарного провайдера й відображає
вибрану зараз модель.

**Один раз сертифікуйте локальну модель.** Перш ніж локальна модель зможе відповідати, відкрийте
**Налаштування → Моделі і провайдери → Локальні моделі** й натисніть для неї **Certify**. Це запускає коротку
перевірку на вашому компʼютері.

## Чого VOOL не робить під час першого запуску

* Не створює обліковий запис.
* Не вимагає хмарного ключа. Щоб користуватися застосунком, достатньо локальної моделі.
* Не індексує ваш диск. Він читає файли, лише коли вони потрібні для запиту; про папки, до яких він має
  доступ, див. [Робочі простори](../../../concepts/workspaces.md).

{% hint style="info" %}
Вибрати іншу папку проєкту можна будь-коли кнопкою **+ Проєкт** на бічній панелі чату.
{% endhint %}
