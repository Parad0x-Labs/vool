# Комбінації клавіш

`⌘` у macOS, `Ctrl` у Windows і Linux.

| Дія | Комбінація |
| --- | --- |
| Нова сесія | `⌘ N` |
| Палітра команд | `⌘ K` |
| Змінити модель | `⌘ M` |
| Показати або сховати панель робочого простору | `⌘ J` |
| Зупинити поточне виконання | `Esc` |
| Налаштування | `⌘ ,` |
