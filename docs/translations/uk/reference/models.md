# Підтримувані моделі

VOOL постачається без моделі — першу локальну модель буде завантажено, коли ви вперше нею скористаєтеся.
Він підключається до середовищ виконання й провайдерів, які вибираєте ви.

## Локальні середовища виконання

Ollama, llama.cpp, vLLM і MLX виявляються автоматично. Інші середовища виконання, що надають
OpenAI-сумісну кінцеву точку на localhost, можна вказати вручну.

## Хмарні провайдери

До хмарних моделей звертаються з вашим ключем, з вашого компʼютера. Якщо вибрати одну з них, застосунок перейде в
хмарний режим (індикатор покаже назву провайдера) — див. [Локально і в хмарі](../concepts/local-and-cloud.md).

[OpenRouter](../guides/openrouter.md) — найширше підключення в одному місці: один ключ, багато
провайдерів.

## Вибір

| Робота | Розумний вибір |
| --- | --- |
| Особисті файли, без мережі | Локальна, 7B або більша |
| Повсякденне програмування | Локальна модель для програмування 7–14B |
| Довгі міркування | Більша хмарна модель |
| Контроль витрат | Спершу локальна, хмарна — коли воно того варте |
