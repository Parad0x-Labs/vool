# Конфігурація

## Розташування

VOOL зберігає свої налаштування, чати, памʼять і записи в одній папці — runtime home:

| Встановлення | Runtime home |
| --- | --- |
| Застосунок для macOS | `~/Library/Application Support/VOOL/runtime` |
| Архів tar для Linux і встановлення з вихідного коду | `~/.vool_runtime` |
| Windows (експериментально, з вихідного коду) | `%LOCALAPPDATA%\VOOL` |

Якщо перед запуском VOOL задати `VOOL_HOME`, замість неї використовуватиметься вказана папка. Команда `vool`
показує, яка папка використовується.

Ключі **не** записуються у файли налаштувань і журнали. Вони зберігаються в зашифрованому вигляді в окремому
файлі облікових даних у цій папці runtime home, і читати його може лише ваш обліковий запис користувача; ключі, які VOOL
уже зберігав у звʼязці ключів macOS на Mac, залишаються там. Див.
[Модель безпеки](../trust/security.md#ключі).

## Налаштування

Налаштування змінюються в застосунку в розділі **Налаштування**. Ось ті, що визначають, що може робити VOOL:

* **Модель** — активна модель; від неї залежить, у якому режимі виконується хід: ЛОКАЛЬНО чи ХМАРА.
* **Робочий простір** — папка проєкту, у якій працює чат; про інші папки, до яких VOOL може звертатися, див. [Робочі простори](../concepts/workspaces.md).
* **Режим роботи** — вибирається в меню поруч із полем повідомлення, а не тут. «Ручний» питає
  перед кожною зміною; «Авто» дозволяє виконувати повсякденні правки й команди, а видалення,
  перезапис, встановлення, витрати й зміна налаштувань і далі потребують дозволу. Див.
  [Дозволи](../concepts/permissions.md).
* **Вебдоступ і криптофункції** — і те, і те вимкнено, доки ви їх не ввімкнете.

У VOOL немає налаштування продуктової телеметрії, бо він не надсилає продуктової телеметрії.

## Скидання

Закрийте VOOL і перемістіть папку runtime home в інше місце. Файли робочого простору не зачіпаються; VOOL запуститься
знову з чистим профілем. Збережені ключі переміщуються разом із папкою, тому додайте їх знову в
**Налаштування → Ключі API**. Ключі, що зберігаються у звʼязці ключів macOS, залишаються там, доки ви не видалите їх у
програмі «Доступ до ключів».
