# Tastaturkurzbefehle

`⌘` unter macOS, `Ctrl` unter Windows und Linux.

| Aktion | Kurzbefehl |
| --- | --- |
| Neue Sitzung | `⌘ N` |
| Befehlspalette | `⌘ K` |
| Modell wechseln | `⌘ M` |
| Arbeitsbereichsleiste ein- oder ausblenden | `⌘ J` |
| Aktuellen Lauf stoppen | `Esc` |
| Einstellungen | `⌘ ,` |
