# Raccourcis clavier

`⌘` sur macOS, `Ctrl` sur Windows et Linux.

| Action | Raccourci |
| --- | --- |
| Nouvelle session | `⌘ N` |
| Palette de commandes | `⌘ K` |
| Changer de modèle | `⌘ M` |
| Afficher ou masquer le panneau de l’espace de travail | `⌘ J` |
| Arrêter l’exécution en cours | `Esc` |
| Réglages | `⌘ ,` |
