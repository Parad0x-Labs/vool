# セキュリティモデル

## 境界

* **フォルダの制限** が、ファイルへのアクセスを制限します。VOOLは、チャットのプロジェクトフォルダでファイルを読み、変更します。その外では、表示されているホームフォルダを読むことができ、ファイルを変更できるのはDesktop、Downloads、Documentsの中だけです。隠しフォルダ、アプリとシステムのデータ、VOOL自身のデータが読まれることは決してありません。[ワークスペース](../concepts/workspaces.md)を参照してください。
* **認証情報ストア** が、キーを保管します。キーが構成ファイルやログに書き込まれることはありません。
* **ツールの確認** が、変更を制限します。「手動」モードではすべての変更について先に確認し、「自動」モードでは日常的な編集やコマンドを自動で実行できますが、削除、上書き、インストール、支出、設定の変更は引き続き確認します。[ツール](../concepts/tools.md)を参照してください。

## ローカルネットワーク

VOOLは標準では、このコンピュータ上でだけ待ち受けます。ローカルネットワークで待ち受けるように設定した場合も、あなたとして扱われるのはこのコンピュータだけです。設定、ファイル、キー、ツール、プライベートな機能は、このコンピュータにだけ応答します。

ネットワーク上の別のデバイスが使えるのは、通常のチャットだけです。そのデバイスは、公開されているウェブページを一度に一つ読むこともできます。そのページは公開インターネット上になければならず、このコンピュータやローカルネットワーク上のアドレスは拒否され、リダイレクトのたびに同じように確認されます。ウェブ検索、リサーチ、ブラウザ、見積もり、支払い、有料のキーは、このコンピュータでだけ使えます。

## Discordブリッジ

Discordブリッジは、所有者にだけ応答します。最初にコマンドを送ったDiscordユーザーが所有者になります。所有者をご自身で決めるには、`VOOL_DISCORD_OWNER_USER_ID` にご自身のDiscordユーザーIDを設定してください。ほかの人が書き込めるチャンネルでは、必ずこれを行ってください。それ以外の人には、このVOOLは所有者専用にロックされていることが一度だけ伝えられ、そのメッセージは処理されません。所有者のDiscordメッセージであっても、ネットワーク上の別のデバイスと同じ制限が適用されます。

## キー

VOOLは、プロバイダのキーを、このコンピュータ上のランタイムホームにある暗号化されたファイルに保存し（[構成](../reference/configuration.md)を参照）、そのファイルはご自身のユーザーアカウントだけが読めます。Macで、VOOLがすでにmacOSのキーチェーンに保存していたキーは、引き続きそこから読めます。キーは、お使いのマシンからプロバイダに接続するために使われます。キーがParad0x Labsに送られることはなく、リクエストの経路にParad0xが運営するエンドポイントはありません。

{% hint style="info" %}
暗号化されたファイルは、別のパスワードではなく、ユーザーアカウントのファイル権限で保護されています。ディスクの暗号化（MacではFileVault）をオンにしておき、ディスクをなくしたり盗まれたりしても、キーが漏れないようにしてください。
{% endhint %}

## プラグイン

プラグインは、ランタイムと同じアクセス権で動作します。だからこそプラグインは便利で、インストールする前に読む価値があります。[スキルとプラグイン](../guides/skills-and-plugins.md)を参照してください。

## 問題を報告する

セキュリティの問題は、[GitHub Security Advisories](https://github.com/Parad0x-Labs/vool/security/advisories/new)から非公開で報告してください。公開のissueでは決して報告しないでください。バージョン、プラットフォーム、再現手順を含めてください。

{% hint style="warning" %}
macOSアプリはアドホック署名で、公証を受けていません。Linuxのtarballは署名されていません。[リリース状況](release-status.md)を参照してください。
{% endhint %}
