# バグ報告とプライバシー

## 組み込みのバグ報告機能

アプリ内のバグ報告機能（または `python -m apps.vool_cli bug-report` のCLI）を使ってください。勝手に何かを送ることは決してありません。流れは意図的に三段階になっています。

1. **下書き** — 最近のログと診断情報から、ローカルでレポートが作られ、作る過程で秘匿化されます。*「Nothing is sent yet — a local draft is created first.」*
2. **プレビュー** — 送信される **正確なバイト列** が、ペイロードのハッシュと、何が取り除かれたかを一覧にした秘匿化の概要とともに表示されます。送りたくない項目（ログ、フラグ、再現メモ、添付ファイル）は削除でき、何かを編集すると承認はリセットされます。
3. **承認** — 送信には、そのバイト列そのものに対する、あなたの明示的な承認が必要です。ペイロードが変わると、承認はもう有効ではなくなり、もう一度承認する必要があります。

承認すると、**Open on GitHub** が、公開の[vool-reports](https://github.com/Parad0x-Labs/vool-reports)リポジトリの記入済みのレポートページをブラウザで開きます。そこでもう一度読んでから、Submitを押してください。VOOL自体は何も送信せず、GitHubのトークンも必要ありません。**Copy report** と **Save a local copy** には、承認はまったく必要ありません。同じ無害化済みのバイト列が渡され、お使いのマシンからは何も出ていきません。**My reports** には、下書きと、それぞれがどのように外に出たかが一覧表示されます。

## 間違った回答を報告する

どの回答の下でも **報告** か 👎 を押すか、間違っている部分をハイライトして **報告** を押します。レポートには、その部分（または回答全体）だけが引用されます。チェックボックスにチェックを入れない限り、質問は含まれません。回答のレシートは含まれます。モデル、プロバイダ、トークン数、時間、どの手順が実行されたかで、その内容は決して含まれません。VOOLに忘れさせた回答は報告できません。

## 調査を助けるために追加されるもの

お使いのコンピュータの概要：OSのバージョン、チップ、メモリ、GPU、ローカルモデルサーバーのバージョン。また、短いヘルスチェック：ローカルモデルサーバーが応答するかどうかと、範囲で示した空きディスク容量。コンピュータの名前、ユーザー名、シリアル番号、ネットワークアドレスは決して含まれません。プレビューで、どれでも削除できます。

## 秘匿化で取り除かれるもの

下書きを目にする前に、決定論的に取り除かれます：認証情報と認証ヘッダー、ホームのパスとユーザー名、コンピュータの名前、メールアドレス、IPアドレス、PINとワンタイムコード、カードと銀行（IBAN）の番号、電話番号、ウォレットのアドレス、プロフィールに保存された個人情報、ラベル付きの秘密情報、エントロピーの高いデータの塊。さらにその上で、最後に秘密情報のスキャンが行われます。VOOLは、普通の文の中に入力された名前や個人的な事実を認識できないため、プレビューを読んでください。スタックトレースは、そのまま貼り付けるのではなく、許可リストから再構成されます。レポート内の障害の証拠には **型付きのコードだけ** が含まれ、内部のコンテキストや原因の連鎖は決して含まれません。

取り除かれた値は、それぞれマーカーに置き換えられます。メールアドレス、人、ホームフォルダ、IPアドレス、電話番号、ウォレットのアドレス、コンピュータの名前、プロフィールの詳細には、レポート全体を通じて一つの番号付きマーカーが使われます。たとえば、二つの異なるアドレスには `[EMAIL_1]` と `[EMAIL_2]` です。こうすることで、レポートは読みやすいままになります。取り除かれたキー、パスワード、PIN、カードや銀行の番号は、すべて `[SECRET_REMOVED]` と表示され、番号は決して付きません。マーカーと実際の値を結び付けるリストは、レポートの作業中だけVOOLのメモリ上に保持されるため、編集してもマーカーは同じままです。このリストは保存も送信も決してされず、レポートを削除したとき、一時間使われなかったとき、またはVOOLが再起動したときに破棄されます。

## VOOLが決して行わないこと

* いかなる種類の自動的な外部への報告もありません。
* 設定の裏で待機しているテレメトリの仕組みもありません。
* セキュリティの問題は、リポジトリの[セキュリティポリシー](https://github.com/Parad0x-Labs/vool/security/policy)にある非公開の窓口を通じて報告します。公開のissueでは決して報告しません。

## プライバシーのまとめ

* ローカルモデルを選んでいれば、プロンプトとファイルはお使いのマシン上で処理されます。
* クラウドの呼び出しには、ご自身で用意したAPIキーが使われ、そのキーはローカルに保存されます。キーがレポートに含まれることは決してありません。
* データの流れの詳細は[データの取り扱い](../trust/data-handling.md)にあります。
