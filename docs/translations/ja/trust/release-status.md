## あなたにとっての意味

* Macアプリを初めて起動すると、公証を受けていないため、macOSが開くのを拒否します。これはこの段階では想定どおりの動作で、ダウンロードが壊れているしるしではありません。チェックサムを確認してから、**システム設定 → プライバシーとセキュリティ** を開き、**このまま開く** をクリックしてください。macOS 14では、代わりにControlキーを押しながらアプリをクリックし、**開く** を選ぶこともできます。
* お使いのチップに合ったMac用のダウンロードを選んでください。Apple Silicon版のアプリはIntel搭載Macでは動作せず、起動時にその旨が表示されます。
* 構成の形式は、ビルドの間で変わることがあります。
* 暗号資産の機能は、ご自身でオンにするまでオフです。

| 機能 | このビルドでの状態 |
| --- | --- |
| 暗号資産とウォレット | 標準ではオフです。オンにすると、VOOLはメインネットを使います。テストネットワークは開発者オプションにあります。すべての支払いは、上限、あなたの承認、レシートを伴って、VOOLのウォレットを通ります。[ウォレット](../guides/wallet.md)を参照してください。 |
| メインネットでの送金 | ネイティブコインと、Solana、Ethereum、BNB Smart Chain、Arbitrum One上のUSDTを、このデバイスで作成したVOOLウォレットから送れます。SolanaとBase上のUSDCは、支払いチャネル専用です。接続したアカウントや閲覧専用のアカウントは、受け取りと残高の表示はできますが、VOOLから送金することはできません。 |
| x402による支払い | Base上またはBase Sepolia上のUSDCでx402による支払いを求めるウェブサイトには、Crypto Pilotウォレットから支払えます。PINによる一回の承認で、上限の範囲内です。ネットワーク手数料は、そのウェブサイトの支払いサービスが負担します。**設定 → 暗号資産 → Payment channels** には、ウォレットがウェブサイトに支払う方法ごとに、オン/オフのスイッチがあります。オフのチャネルは、何かが署名される前に拒否します。この方法では、メインネットでの実際の支払いはまだ一度も行われていません。Solana pay-kitによる支払いはダウンロード版に含まれておらず、そのチャネルは利用不可と表示されます。 |
| X | どのチャットからでも、ポストとアカウント、スペース、トレンド、DMを検索し、トークンについての過去のコールを調べられます。あなたのアカウントに対して何かを行う操作は、あなたのOKを待ちます。 |
| 音声入力 | このベータビルドでは利用できません。 |

| ローカルモデル | ローカルモデルが回答できるようにするには、**設定 → モデルとプロバイダ → ローカルモデル** を開き、そのモデルの **Certify** を一度押してください。 |
