# データの取り扱い

## 二つの状態

**ローカル** — モデルとファイルはこのコンピュータにとどまります。天気や価格などの最新情報は、「ウェブ検索」がオンのとき（新規インストールではオフです）だけ公開のウェブサービスから取得し、「ローカルのみ」では決して取得しません。

**クラウド** — 選択したコンテキストが、選択したプロバイダに直接送信されます。

次のリクエストがどちらの方法で実行されるかは、チャットのヘッダーに表示されます。たとえばVOOL Autoがこのコンピュータから回答するときは、**自動** と **ローカル優先** と表示されます。

## VOOLが行わないこと

* プロンプトをParad0x Labsのインフラ経由で中継しません。
* ワークスペースをアップロードしません。
* キーを、そのキーが属するプロバイダ以外のどこにも送りません。

## OpenRouterについて

OpenRouterのアカウントはご自身のものです。VOOLは、ご自身のキーを使って、このコンピュータから直接リクエストを送ります。Parad0xがプロンプトを中継したり、利用料を支払ったりすることはありません。VOOLの実際の利用は、OpenRouter上のVOOLの公開集計統計に表れることがありますが、個々のプロンプトや個人を特定する情報は公開されません。

## テレメトリ

VOOLは製品テレメトリを送信しません。バグレポートがマシンの外に出るのは、ご自身で内容をプレビューし、送信を選んだときだけです。[バグ報告とプライバシー](bug-reporting.md)を参照してください。

## プロバイダの規約が適用されます

クラウドモードでは、データはVOOLではなく **プロバイダ側の** 保存・学習に関する規約のもとでプロバイダに届きます。選択するプロバイダの規約をお読みください。
