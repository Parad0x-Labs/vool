# ウォレット

ウォレットは **オプションで、標準ではオフ** です。リクエストごとに料金がかかるAIサービスのために、VOOLが少額の暗号資産を保持できるように用意されています。VOOLを使うために、ウォレットに関することは何も必要ありません。

このページでは、現在のビルドが実際に対応している内容を説明します。ウォレットは **パイロット** 段階にあります。機能はレーンごとに追加されており、以下の各レーンで、それぞれが何をするかを正確に説明しています。

## ネットワーク環境

暗号資産の機能をオンにすると、VOOLは **メインネット** で動作します：Solana、Robinhood Chain、Base、Ethereum、BNB、Arbitrum One。通常のセットアップで、ネットワーク環境を選ぶよう求められることはありません。

* **メインネット** — 古いテストネットワークのアカウントを持ったままアップグレードしたインストールも含め、すべてのインストールの標準です。支出上限、承認、レシートはすべて、以下で説明するとおりに適用されます。
* **Test networks** — Solana Devnet、Robinhood Chain Testnet、その他のテスト用のレーン。開発者専用です。**設定 → 暗号資産 → 開発者オプション** で切り替えます。

アカウント、残高、レシートは一つの環境に属し、環境の間を移動することは決してありません。もう一方の環境のアカウントは、それぞれのネットワークに表示されたままです。もう一方の環境のネットワークに対するリクエストは拒否され、何も作成、提案、署名されません。

{% hint style="warning" %}
以前のドキュメントには、このビルドではメインネットは使えないと書かれていました。それはパイロットの前には正しかったものの、今は違います。メインネットの行がすでに存在します。今も正しいのは、もっと限られた内容です。メインネットにどのレーンが存在するかは、以下の送金と支払いのセクションを参照してください。
{% endhint %}

## どのレーンで何が動くか

* **送金で動かせるのはネイティブコイン**（たとえばSolana上のSOL、Base、Ethereum、Arbitrum One上のETH）と、**Solana、Ethereum、BNB Smart Chain、Arbitrum One上のUSDT** です。チェーンは、保存された各連絡先のアドレスと各承認の一部です。トークンの送金には、手数料としてそのチェーンのネイティブコインも必要です。見積もりには、上限の範囲内で両方の金額が表示されます。
* **SolanaとBase上のUSDCは、支払いチャネルでのみ利用できます。** 通常の送金には提供されません。ウォレットのメインの残高表示はネイティブコインを示すもので、トークンのポートフォリオ全体ではありません。
* すべての送金はプレビューされ（**見積もり**：金額、手数料の上限、受取人、ネットワーク）、まさにそのプレビューに結び付いた、あなたの明示的な承認が必要です。何かを変更すると承認は無効になり、何も署名されません。
* 名前が複数の連絡先やウォレットのアドレスに一致する場合は、どれかを選ぶよう求められます。正確なアドレスとチェーンを確認してください。アドレスが変わったり、連絡先の名前が変わったりすると、以前のレビューは無効になります。
* メインネットでは、送金できるのはこのデバイスで作成したVOOLウォレットだけです。接続した外部ウォレットや閲覧専用のアドレスは、受け取りと残高の表示ができます。そこからの送金や支払いチャネルでの支払いは、承認を求める前に拒否され、何も署名されません。
* アクティビティには、VOOLを通じて行った支払いとそのレシートが記録されます。入金の完全な履歴ではありません。このウォレットには、スワップやブリッジの操作はありません。

## 支払いの承認の流れ

1. VOOLが、正確な金額と手数料の上限を含む提案を用意します。
2. あなたが、PIN/パスワード（利用できる場合はデバイスでの確認）で承認します。
3. 支払いが署名されて送信され、レシートが記録されます。

承認が提案の間で引き継がれることはありません。PINが間違っていれば、何も署名されません。間違いが多すぎると、ウォレットはしばらくロックされます。これは意図的なもので、待ち時間が示されます。

## x402の自動支払い

x402は、一部のウェブサイトやAIサービスが使う、リクエストごとの支払いプロトコルです。**Base上のUSDCでx402による支払いを求めるウェブサイト**（開発者オプションではBase Sepolia）には、Crypto Pilotウォレットから支払えます。PINによる一回の承認で、上限の範囲内です。ネットワーク手数料は、そのウェブサイトの支払いサービスが負担します。**この方法では、メインネットでの実際の支払いはまだ一度も行われていません。** その他のテストネットワーク（Solana Devnet、Ethereum Sepolia、BNB testnet）は、開発者オプションに残っています。**設定 → 暗号資産 → Payment channels** には、ウォレットがウェブサイトに支払うすべての方法が、それぞれのオン/オフのスイッチとともに一覧表示されます。オフのチャネルは、何かが署名される前に拒否します。Solana pay-kitによる支払いはダウンロード版に含まれていないため、そのチャネルは利用不可と表示されます。**モデルマーケットプレイス：** 設定のモデルマーケットプレイスにある、呼び出しごとに支払うオプションでは、SolanaメインネットのCrypto Pilotウォレットから、USDCまたはSOLで支払えます。各呼び出しは、ウォレットの上限の範囲内であなたの承認を待ち、0.1%のVOOLの手数料を表示します。この方法は、まだ実際のチェーンではテストされていません。x402を使う有料のリソースの場合：

* 支払いは、同じウォレットの上限と承認の流れを通ります。
* 自動支払いには一回ごとの上限があり、上限を超えるリソースには **支払われません**（上限を意図して引き上げるか、明示的な提案で支払うことができます）。
* 支払いを完了できなかった場合、結果は **不明** と報告されます。再試行の前に、その状態を確認してください。VOOLが、やみくもに重複した支払いを促すことはありません。

## DNAのサービス手数料

モデルマーケットプレイスの、呼び出しごとに支払うx402のルートでは、プロバイダへの支払いが受け付けられるごとに **0.1%（10ベーシスポイント）** のサービス手数料がかかり、支払いとも、ネットワーク手数料とも分けて表示されます。それ以外で、この手数料が発生することはありません。通常の送金、ウォレットの作成、ローカルでの推論、ご自身のAPIキー（BYOK）による呼び出しには、サービス手数料は **一切かかりません**。発生した手数料は経済的に回収されます（後のネイティブの支払いとともに、一回の承認のもとで、回収のコストが限られている場合にだけ）。予期しない別の請求として回収されることは決してありません。

## 復元

* 作成時に、**リカバリフレーズが一度だけ表示されます**。
* パイロットのウォレットのバックアップキーも、同じようにセットアップ中に一度だけ渡され、後からエクスポートすることはできません。保存しなかった場合は、セットアップをキャンセルし、そのアドレスに資金を送らないでください。
* Crypto Pilotより前に作られた古いVOOLウォレットは、別のウォレットアプリにインポートするために、秘密鍵を一度だけエクスポートできます。エクスポートは、Mac自体のサインイン（Touch IDまたはMacのパスワード）でのみ開き、ウォレットのPINでは決して開きません。鍵は保存されずに一度だけ表示されます。
* ウォレットをなくしましたか？作成時に書き留めたフレーズから復元してください。このウォレットに正確に合わない復元の証明は、何かが書き込まれる前に拒否されます。
