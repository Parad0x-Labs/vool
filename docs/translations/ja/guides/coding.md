# VOOLでコーディングする

## ワークスペースをリポジトリに設定する

[ワークスペース](../concepts/workspaces.md)をプロジェクトのルートに向けます。VOOLはツリー全体を読み込むのではなく、必要なファイルを読みます。

## コードの言葉で質問する

ファイルやシンボルの名前を挙げると、ランタイムにとっての出発点になります。

> `src/auth/` でセッションのタイムアウトが設定されている場所を見つけて、期限が切れたときに何が起きるかを説明してください。

## 適用する前にレビューする

「手動」モードでは、すべての編集について先に確認します。「自動」モードでは、日常的な編集やコマンドは自動で実行でき、アクティビティの記録に表示されますが、削除と上書きは引き続き確認します。大きな変更の前にはコミットしておくと、差分が読みやすく、元に戻すのも簡単です。

## ローカルかクラウドか

コーディングはどちらのモードでも使えます。7Bのローカルのコーディングモデルで日々の編集のほとんどに対応でき、より長い推論には大きなクラウドモデルが向いています。送信する前に、どちらが有効かはモデル表示でわかります。ローカルモデルなら `LOCAL`、クラウドモデルなら `CLOUD`、VOOLが選ぶときは標準で `AUTO`（`VOOL Auto`、`Local first`）と表示されます。
