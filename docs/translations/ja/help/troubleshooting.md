# トラブルシューティング

## macOSがアプリを開かない

想定どおりの動作です。アプリはまだ公証を受けていません。まずチェックサムを確認してから、**システム設定 → プライバシーとセキュリティ** を開き、**このまま開く** をクリックします。macOS 14では、代わりにControlキーを押しながらVOOLをクリックし、**開く** を選ぶこともできます。

## Windows

このリリースにWindows用のダウンロードはありません。Windowsではソースからインストールし、試験的な対応です。[インストールガイド](../getting-started/install.md#ソースからインストールする)を参照してください。

## ローカルモデルが一覧に表示されない

1. ランタイムが動作していることを確認します。
2. 少なくとも一つのモデルがダウンロード（pull）済みであることを確認します。
3. ポートがVOOLの想定と一致していることを確認します。

```bash
curl http://localhost:11434/api/tags
```

何も返ってこない場合、ランタイムは起動していません。

## 応答が遅い

多くの場合、使えるメモリに対してモデルが大きすぎることが原因です。[ローカルモデルを実行する](../guides/local-models.md)を参照してください。

## エラーにコードが表示される

どの失敗にも固定のコードがあります。[エラーとエラーコード](../reference/errors.md)ではコードの読み方を説明し、[エラーブック](../ERROR_BOOK.md)ではコードごとに、何が起きたか、すでに何が起きた可能性があるか、次に何をすべきかを説明しています。

## まっさらな状態からやり直す

VOOLを終了し、[構成](../reference/configuration.md)に記載されている「runtime home」フォルダを削除してください。これにより、チャット、メモリー、設定、保存したキー、そしてVOOLがこのコンピュータに保管しているウォレットがすべて削除されます。先に必要なものを保存してください（[バックアップと復元](backup-and-recovery.md)を参照）。ワークスペースのファイルには手を加えません。
