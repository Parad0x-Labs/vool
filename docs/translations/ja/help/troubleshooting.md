# トラブルシューティング

## macOSがアプリを開かない

想定どおりの動作です。アプリはまだ公証を受けていません。まずチェックサムを確認してから、
**システム設定 → プライバシーとセキュリティ** を開き、**このまま開く** をクリックします。macOS 14では、
代わりにControlキーを押しながらVOOLをクリックし、**開く** を選ぶこともできます。

## Windows

このリリースにWindows用のダウンロードはありません。Windowsではソースからインストールし、
試験的な対応です。[インストールガイド](../getting-started/install.md#ソースからインストールする)を参照してください。

## ローカルモデルが一覧に表示されない

1. ランタイムが動作していることを確認します。
2. 少なくとも一つのモデルがダウンロード（pull）済みであることを確認します。
3. ポートがVOOLの想定と一致していることを確認します。

```bash
curl http://localhost:11434/api/tags
```

何も返ってこない場合、ランタイムは起動していません。

## 応答が遅い

多くの場合、使えるメモリに対してモデルが大きすぎることが原因です。
[ローカルモデルを実行する](../../../guides/local-models.md)を参照してください。

## まっさらな状態からやり直す

VOOLを終了し、[設定](../../../reference/configuration.md)に記載されている設定ディレクトリを
削除してください。ワークスペースのファイルには手を加えません。
