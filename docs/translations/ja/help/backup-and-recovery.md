# バックアップと復元

VOOLが保存しているものはすべて、お使いのコンピュータ上の一つのプロファイルフォルダにあります（場所は[構成](../reference/configuration.md)を参照）。アプリをアップデートしたり再インストールしたりしても、このフォルダには決して手を加えません。VOOLには、データのクラウドコピーも、プロファイル全体をワンステップでバックアップする機能もありません。大切なものを保存して取り戻す方法は、次のとおりです。

## チャット

| したいこと | 使うもの | 得られるもの |
| --- | --- | --- |
| 読んだり共有したりするためのコピー | チャットのヘッダーにある **エクスポート** | チャット全体を、テキストまたはMarkdownで。添付ファイルは名前だけが記載されます。 |
| VOOLに戻すためのコピー | 設定、バックアップと復元、**チャットを書き出す** | 一つのチャットを、このコンピュータが署名した `.voolsession` ファイルとして。 |
| そのファイルからチャットを戻す | 設定、バックアップと復元、**チャットを読み込む** | そのチャットが、ほかのチャットの隣に追加されます。 |
| ほかのAIアプリのチャット | 設定、バックアップと復元、**ほかのAIアプリのチャットを持ってくる** | それらのチャットを、名前とメッセージとともに。 |

**チャットを書き出す** は、チャットのメッセージ、レシート、証拠の参照を含みますが、VOOLの内部の推論、設定、メモリー、キーは決して含みません。ファイルがこのコンピュータから出ていくときは、パスフレーズで保護してください。パスフレーズのないエクスポートでは、先に確認が求められます。何かが書き込まれる前に、書き込まれる内容がプレビューで正確に表示されます。

**チャットを読み込む** は、何かが追加される前に、ファイルの中身と、誰が署名したかを表示します。VOOLが知らない鍵で署名されたファイルは、あなたが受け入れない限り拒否され、そのチャットは信頼されていないものとして印が付いたままになります。インポートによって、既存のチャットが変更されることは決してありません。同じチャットがすでにある場合、コピーは新しいチャットとして追加されます。

**ほかのAIアプリのチャットを持ってくる** は、このコンピュータ上のアプリか、データのエクスポートファイルを読み込みます。取り込むチャットを、チェックを入れて選びます。お使いのコンピュータからは何も出ていかず、ほかのアプリのファイルが変更されることも決してありません。VOOLはこれらのチャットを履歴として保存します。そこから学習したり、そこに書かれていることに従ったりはしません。

## メモリー

設定、メモリーとパーソナライズ、**プロフィールを書き出す** は、VOOLがあなたについて覚えていることを、`vool-memory-` と日付を名前にしたファイルとして保存します。キーやパスワードが含まれることは決してありません。読んで保管するためのコピーで、VOOLにはこれをインポートする機能はありません。

## モデルプロバイダのキー

プロバイダのキーは、どのエクスポートにも含まれません。新しいコンピュータでは、設定でもう一度追加してください。

## ウォレット

* **ネットワーク用に作成したVOOLウォレット** は、セットアップ中に一度だけ、秘密鍵のバックアップを表示します。そのとき以外には表示されません。オフラインで保管してください。それを持っている人は誰でも、ウォレットを操作できます。ウォレットのPINやパスワードを忘れた場合は、設定、暗号資産のウォレットにある **Forgot PIN or password?** で、そのバックアップを使ってアクセスを取り戻し、新しいPINやパスワードを選びます。
* **旧ポケット** は、作成時に一度だけ表示されたリカバリフレーズで保管されます。設定、暗号資産、他のアカウントにある **Restore from phrase…** で、フレーズから元に戻せます。また、**Export private key** で秘密鍵をPhantomやMetaMaskにエクスポートすることもでき、これはTouch IDまたはMacのパスワードでのみ開きます。
* 閲覧するだけのウォレットや、別のアプリから接続したウォレットは、VOOLに鍵を保存していません。ここでバックアップするものはありません。

全体像は[ウォレット](../guides/wallet.md)を参照してください。

## アップデートが失敗した場合

どの段階で失敗したアップデートでも、アプリは元のままです。データを新しいバージョンに移す処理が失敗した場合、データは元の状態に戻され、VOOLは以前のバージョンで起動します。[アップデートと移行](../reference/updates-migration.md)を参照してください。
