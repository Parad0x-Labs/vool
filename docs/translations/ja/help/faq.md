# よくある質問

## VOOLはオフラインで動作しますか？

はい、ローカルモデルを使えば、チャットとファイルについては動作します。クラウドモデルには、その性質上、ネットワーク接続が必要です。天気や価格などの最新情報は、「ウェブ検索」がオンのとき（新規インストールではオフです）だけ公開のウェブサービスから取得し、「ローカルのみ」では決して取得しません。

## クラウドのキーは必要ですか？

いいえ。アプリを使うには、ローカルモデルだけで十分です。

## キーはどこに保存されますか？

お使いのコンピュータ上の、VOOLのランタイムホームにある暗号化されたファイルに保存され、ご自身のユーザーアカウントだけが読めます。Macで、VOOLがすでにmacOSのキーチェーンに保存していたキーは、そのまま残ります。キーがお使いのマシンから出ることはありません。[セキュリティモデル](../trust/security.md#キー)を参照してください。

## Parad0xにプロンプトを見られますか？

ローカルモードでは見られません。クラウドモードでも見られません。クラウドのリクエストは、お使いのマシンからプロバイダへ送られます。[データの取り扱い](../trust/data-handling.md)を参照してください。

## 開くときにシステムが警告するのはなぜですか？

macOSアプリはアドホック署名ですが、まだ公証を受けていないため、初めて開くときにmacOSが確認を求めます。手順は[インストール](../getting-started/install.md#macで初めて開くとき)にあります。[リリース状況](../trust/release-status.md)も参照してください。

## 自分のモデルを使えますか？

はい。OpenAI互換のローカルエンドポイントを公開しているランタイムなら、どれでも使えます。[対応モデル](../reference/models.md)を参照してください。

## 無料ですか？

アプリケーションは、ベータ期間中は無料です。クラウドモデルの利用料は、プロバイダからご自身のアカウントに請求されます。
