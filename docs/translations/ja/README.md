# VOOL

VOOLはデスクトップAIアシスタントです。アプリケーションとしてお使いのコンピュータにインストールされ、
AIモデルをそのマシン上でローカルに実行することも、ご自身のAPIキーでクラウドのAIプロバイダに接続することもできます。実行したすべての操作について、読める記録を残します。

無料で、ローカルモデルならオフラインで動作します。Mac（Apple SiliconとIntel）とLinux x86_64向けのダウンロードがあり、Windowsは試験的な対応で、ソースからインストールします。

このドキュメントでは、VOOLのインストール、モデルの接続、そしてVOOLがファイル、メモリー、キーをどう扱うかという基本的な考え方を説明します。

## 他のエージェントとの比較

一度も使われていないLoCoMoのメモリー問題150問で、どのエージェントにも同じモデルが回答し、同じGPT-4oが採点した結果、VOOLのメモリーは他の二つのオープンソースエージェントを上回りました。

| | VOOL | OpenClaw | Hermes |
| --- | --- | --- | --- |
| 正答率 | **82.7%**（124 / 150） | 71.3%（107） | 62.7%（94） |
| 質問あたりのトークン数 | **9.6k** | 51.8k | 33.5k |
| 質問あたりのコスト | **$0.0033** | $0.0100 | $0.0046 |

使用トークン数はOpenClawより5.4倍、Hermesより3.5倍少なく、回答あたりのコストはOpenClawの三分の一です。
VOOL 0.7に搭載されていたメモリーは、同じ問題で150問中123問の正解でした。すべての実行結果、条件、弱点を公開しています：[メモリーのベンチマーク](https://github.com/Parad0x-Labs/vool/tree/main/docs/benchmarks)。

## VOOLとは

* **デスクトップアプリケーション。** お使いのコンピュータにインストールされます。ブラウザのタブでも、ホスティングされたサービスでもありません。
* **オフラインで動作。** ローカルモデルを選んでいれば、VOOLはインターネット接続を必要としません。
* **標準はローカル。** ローカルモデルを選んでいれば、プロンプトとファイルはお使いのマシン上で処理されます。
* **モデルを選ばない。** ローカルランタイムもクラウドプロバイダも選択できます。クラウドのキーはご自身で用意し、そのキーはお使いのマシンに保存されます。
* **検証できる。** すべてのツール呼び出しが入力と結果とともに記録されるため、実行内容をあとから読み返せます。

{% hint style="warning" %}
VOOLはApple Silicon搭載Mac、Intel搭載Mac、Linux x86_64向けのベータ版です。MacアプリはまだAppleの公証を受けていないため、初めて開くときにmacOSが確認を求めます。手順は[インストール](getting-started/install.md#macで初めて開くとき)のページにあります。インストールの前に[リリース状況](../../trust/release-status.md)をご確認ください。
{% endhint %}

## 二つのモード、はっきりと

VOOLが区別する状態はちょうど二つで、どちらが有効かは常にインターフェイスに表示されます。

1. **ローカル** — 作業はこのコンピュータの中にとどまります。
2. **クラウド** — 選択したコンテキストが、お使いのマシンから、ご自身のキーを使って、選択したプロバイダに直接送信されます。

三つ目の状態はなく、Parad0xが運営する中継サーバーが間に入ることもありません。詳しくは[データの取り扱い](trust/data-handling.md)をご覧ください。
