# モデルを接続する

VOOLにモデルは付属していません。標準ではVOOLがローカルモデルを選び、ほかのモデルを選ぶこともできます。その選択によって、リクエストがお使いのマシンにとどまるか外に出るかが決まります。

## ローカル

ローカルランタイムがインストールされて動作していれば、VOOLがそれを検出し、モデルを一覧表示します。いずれかを選ぶと、表示が「ローカル」になります。セットアップの詳細は[ローカルモデルを実行する](../guides/local-models.md)にあります。

## クラウド

**設定 → APIキー** でプロバイダのキーを追加します。キーはこのコンピュータ上の暗号化されたファイルに保存され（[セキュリティモデル](../trust/security.md#キー)を参照）、**お使いのマシンからプロバイダへ直接** リクエストを送るために使われます。

クラウドモデルを選ぶと、表示にプロバイダの名前が出ます。表示は、リクエストが送られる前に切り替わります。

OpenRouterに固有の手順は[OpenRouterを接続する](../guides/openrouter.md)をご覧ください。

## 切り替え

モデルを切り替えると、モードも切り替わります。表示が基準です。「ローカル」と表示されていれば、次のリクエストはこのコンピュータ上で処理されます。
