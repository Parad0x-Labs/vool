# 初回起動

初回起動時には、短い質問が四つ表示されます。どれもスキップでき、あとからすべての回答を変更できます。回答している間、どこにも何も送信されません。ただし、クラウドのキーを追加した場合は、そのキーをプロバイダで確認する通信だけが行われます。

## 起動時の流れ

1. **どこで考えますか？** ローカルモデルを使ってこのコンピュータ上で、またはお支払いいただいているプロバイダのキーを使ってオンラインで。[モデルを接続する](connect-a-model.md)を参照してください。
2. **フォルダを選ぶ。** VOOLが作業するプロジェクトフォルダです。[ワークスペース](../concepts/workspaces.md)を参照してください。
3. **何を1人で行えますか？** VOOLが何かを変更する前に、どのくらいの頻度で止まって確認するか。[ツール](../concepts/tools.md)を参照してください。
4. **何と呼びますか？** 任意です。名前やニックネームで十分で、この情報はこのコンピュータから出ません。

その後、モード表示には「ローカル」「自動」またはクラウドプロバイダの名前が表示され、現在選択されているモデルが反映されます。

**ローカルモデルを一度だけ認定する。** ローカルモデルが回答できるようにするには、**設定 → モデルとプロバイダ → ローカルモデル** を開き、そのモデルの **Certify** を押してください。お使いのマシンで短いチェックが実行されます。

## 初回起動時にVOOLが行わないこと

* アカウントは作成しません。
* クラウドのキーは必須ではありません。アプリを使うにはローカルモデルだけで十分です。
* ドライブのインデックスは作成しません。ファイルを読むのはリクエストで必要になったときだけです。アクセスできるフォルダについては[ワークスペース](../concepts/workspaces.md)を参照してください。

{% hint style="info" %}
チャットのサイドバーにある **+ プロジェクト** から、いつでも別のプロジェクトフォルダを選べます。
{% endhint %}
