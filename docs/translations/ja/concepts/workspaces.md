# ワークスペース

ワークスペースとは、チャットが作業するプロジェクトフォルダのことです。VOOLはそこでファイルを読み、変更します。その際、動作モードが求める場合には、必ず先に確認します（[ツール](tools.md)を参照）。

## 追加と削除

フォルダを選ぶには、チャットの **プロジェクトフォルダーを選択…** か、チャットのサイドバーにある **+ プロジェクト** を使います。プロジェクトを削除すると、VOOLはそのプロジェクトで学んだことを忘れ、そのチャットは「全般」に戻ります。ファイルには手を加えません。

## その他のフォルダ

ワークスペースの外でも、VOOLのファイルツールは、決められた制限のもとでホームフォルダにアクセスできます。

| フォルダ | VOOLにできること |
| --- | --- |
| Desktop、Downloads、Documents | 読み取りと、ファイルの変更。変更の前には、動作モードに従って確認します |
| Pictures、Movies（LinuxではVideos）、Music | 読み取りのみ：一覧表示、検索、開く、サイズの計測。変更は一切しません |
| その他の表示されているホームフォルダ（`~/Projects` など） | 読み取りのみ |
| 隠しフォルダ（`~/.ssh` など）、アプリとシステムのデータ（`Library`、`Applications`、`AppData`）、VOOL自身のデータフォルダ | 一切アクセスしません |

VOOLがこれらのフォルダを見るのは、リクエストで必要になったときだけです。たとえば「税金のPDFを探して」や「Moviesの中でいちばん大きい動画はどれ」といったリクエストです。バックグラウンドでドライブのインデックスを作成することはありません。

## 範囲を決めるためのヒント

* ワークスペースは、ホームディレクトリではなくプロジェクトに向けてください。
* 認証情報のファイル、鍵の素材、パスワードの保存データは、パスワードマネージャーか隠しフォルダに保管し、Desktop、Downloads、Documentsやプロジェクトフォルダにそのまま置かないでください。
* 作業ごとに別のプロジェクトを使い、ある作業のコンテキストが別の作業に届かないようにしてください。

{% hint style="warning" %}
クラウドモデルを選択しているときは、VOOLが読んだものは、プロジェクトフォルダのものもホームフォルダのものも、プロバイダに送信される内容に含まれる可能性があります。範囲は意図して決めてください。
{% endhint %}
