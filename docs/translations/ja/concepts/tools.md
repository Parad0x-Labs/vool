# ツール

ツールとは、ランタイムがあなたに代わって実行できる操作のことです。ファイルを読む、コマンドを実行する、フォルダを検索する、などです。

## 設計から検証可能

すべてのツール呼び出しは、何が要求され、何が実行され、何が返ってきたかを記録します。実行内容は、再実行しなくても、あとから読み返せます。

## 権限

ツールがすぐに実行されるか、先に確認するかは、選んだモードと操作の内容によって決まります。新しいチャットは「手動」で始まり、すべての変更について先に確認します。「自動」では、ファイルの作成と編集、コマンド、ネットワーク操作は確認なしで実行されますが、削除、上書き、インストール、Gitのコミットとプッシュ、デプロイ、メッセージの送信、支払い、設定の変更は引き続き確認します。どのモードでも、ファイルツールは[ワークスペース](workspaces.md)の中でだけ動作し、検索ツールと取得ツールは何も書き込まずに公開されているリソースを読み、保存された秘密情報が読まれることは決してありません。[権限](permissions.md)では、五つのモードすべてと、各承認ボタンで何が許可されるかを説明しています。

```text
tool: read_file
path: src/main.py
result: 412 lines
```
