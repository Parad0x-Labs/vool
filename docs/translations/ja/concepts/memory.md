# メモリー

メモリーは、VOOLがセッションをまたいで事実を引き継ぐ仕組みです。お使いのマシン上の、VOOLのデータホームに、読める形式のファイルとして保存されます。

## どのくらいよく覚えているか

LoCoMoの長い会話のベンチマークから、一度も使われていない150問で、VOOL 0.7に搭載されていたメモリーは123問に正解しました（82.0%）。同じ問題での直接比較では、三つすべてに同じモデルが回答し、VOOLは124問（82.7%）、OpenClawは107問（71.3%）、Hermesは94問（62.7%）に正解しました。しかもVOOLが質問あたりに送ったトークン数は3.5〜5.4倍少なくなりました。すべての実行結果を公開しています：[メモリーのベンチマーク](https://github.com/Parad0x-Labs/vool/tree/main/docs/benchmarks)。

## 特性

* **ディスク上に、見える形で。** メモリーは読めるファイルです。`MEMORY.md` が読むための窓口で、その背後にある事実は、隣にあるエントリーファイルに保存されています。
* **ローカル。** メモリーはサーバーと同期されません。
* **VOOLホームごとに一つのストア。** メモリーはワークスペースごとに分かれていません。インストール全体で一つに保たれるため、プロジェクトごとに分離する境界にはなりません。

## 管理する

`MEMORY.md` にご自身で追加したメモは保持されます。VOOLが記録した事実は、ファイルを削除するのではなく、VOOLの忘却操作で消去します。忘却は、エントリーのストアとミラーを一度に書き換え、両方を読み直してテキストが消えたことを確認します。`MEMORY.md` だけを削除しても消去にはなりません。エントリーファイルに事実が残っていて、ミラーはそこから再構築されます。

クラウドモードでは、関連するメモリーが、ほかのコンテキストと同じ条件で、プロバイダに送られるコンテキストの一部になることがあります。[ローカルとクラウド](local-and-cloud.md)を参照してください。

チャットで忘れさせると、ランタイムデータベースにあるそのチャットの実行履歴からも、その言葉が消去されます。対象は、ターンの記録、チェックポイント、試行、タスクの計画、確定した回答（回答の消去処理が一掃するコピーを含む）、知識の候補、コンテキストのレポート、通知、そのチャットが生成した調査成果物、そしてそれらを引用したピン留めメッセージです。ほかの記録が依存している記録は、隣に保存されているダイジェストとともに、忘れた言葉を空白にした状態で残ります。それ以外は削除されます。忘却が届いた時点でまだ実行中だったターンは、その言葉を書き戻すことができません。そのイベントは空白にされ、ターンが終わると、その記録がもう一度消去されます。その後、データベースの先行書き込みログが統合され、古いコピーが `-wal` ファイルに残らないようにします。別のチャットの記録には手を付けません。まだ送信されていないキュー内のメッセージは保持され、その場合、忘却は完全には適用できなかったと伝えます。どの消去手順も知らないテーブルは返答の中で名前が示され、再試行しても消えないことが伝えられます。

言葉は大文字と小文字を区別せずに比較され、別の文字体系で書かれた数字も同じ数字として扱われます（全角の「１２」は12です）。忘れさせた数字は、それ自体が独立した数字として書かれている場所でだけ一致します。一緒に続けて書かれた文字や数字に他の数字が含まれていてはならず、`.`、`,`、`:`、`/`、`-`、`_` をまたいで別の数字に続いていてもいけません。「12」を忘れさせると「code 12」「12kg」「B12」は消去されますが、「room 312」「3.12」「12.5」「12:30」「2026-10-12」は消去されず、「200」を忘れさせても「1,200」は消去されません。実行履歴では、ランタイムが数えたり計測したりした単なる数値（`elapsed_ms` や `step_count` の値など）は一致の対象になりません。

メモリーを読み取る処理は、永続的な忘却オーソリティも確認します。新しいメモリーホームは、書き込みを受け付ける前にこれを作成します。古いセマンティックストアがその場でアップグレードされるのは、過去の消去が記録されていない場合だけで、保持されているメモリーは引き続き利用できます。既存のオーソリティが読めない場合、永続化された証跡があるのにオーソリティがない場合、または忘却のバリアが記録されている場合、読み取る処理は影響を受けるメモリーを提供しません。オーソリティのファイルを削除しても、忘れた内容を元に戻すことはできません。

保留中の消去ジャーナルは、復旧のためにトークンを保持します。範囲を限定した恒久的な取り消しが存在するようになると、完了処理によってジャーナルの冗長なトークンが消去されますが、操作の識別情報とステータスは残ります。取り消しのオーソリティは残ります。
