# レシート

レシートは、実行の永続的な記録です。どのツールが、どんな入力で呼び出され、それぞれが何を返したかが記録されます。

## なぜあるのか

エージェントが自分の作業についてまとめた要約は、主張にすぎません。レシートは、その主張を照らし合わせて確かめられる記録です。

## 中身

| 項目 | 意味 |
| --- | --- |
| `tool` | 実行された操作 |
| `input` | 与えられた入力 |
| `result` | 返された結果 |
| `time` | 実行された時刻 |

レシートは、プロジェクトフォルダではなく、このコンピュータ上のVOOLのランタイムホームに保存されます（[構成](../reference/configuration.md)を参照）。レシートがお使いのマシンの外に出るのは、ご自身でプレビューして送信を選んだバグレポートの中に含まれる場合だけです（[バグ報告とプライバシー](../trust/bug-reporting.md)を参照）。
