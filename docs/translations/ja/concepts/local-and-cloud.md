# ローカルとクラウド

VOOLは二つの方法で回答できます。このコンピュータ上で回答するか、クラウドプロバイダを通じて回答するかです。次のリクエストがどちらの方法で実行されるかは、チャットのヘッダーに表示されます。たとえばVOOL Autoがこのコンピュータから回答するときは、**自動** と **ローカル優先** と表示されます。

## ローカル

モデルとファイルはこのコンピュータにとどまります。モデルはローカルランタイム上で動作し、ファイルはディスクから読み込まれ、プロバイダへのリクエストは一切行われません。天気や価格などの最新情報は、「ウェブ検索」がオンのとき（新規インストールではオフです）だけ公開のウェブサービスから取得し、「ローカルのみ」では決して取得しません。

## クラウド（プロバイダ名）

選択したコンテキストが、お使いのマシンから、ご自身のキーを使って、選択したプロバイダに直接送信されます。

「選択したコンテキスト」とは、アプリがそのリクエストのためにまとめたもの、つまりプロンプトと、そのリクエストに必要なファイルや以前のやり取りのことです。

{% hint style="danger" %}
クラウドモードでは、データがお使いのマシンの外に送信されます。それがクラウドモードの目的です。VOOLが約束しているのは *経路* についてであり（リクエストはお使いのコンピュータからプロバイダへ送られます）、何も送信されないということではありません。
{% endhint %}

## 間にあるもの

Parad0x Labsが運営するものは何もありません。モデルの通信には、プロキシもゲートウェイも中継もありません。キーは、お使いのマシン上のアプリがプロバイダと直接やり取りするために使われます。

詳しくは[データの取り扱い](../trust/data-handling.md)をご覧ください。
