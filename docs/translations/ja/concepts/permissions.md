# 権限

VOOLは、何かが実行される前に、何を実行してよいかを判断します。モデルは操作を求めることができますが、それが実際に行われるかどうかは、選んだモードとあなたの回答で決まります。読み取りは変更とは別に扱われ、秘密情報、支払い、セキュリティ設定は、どのモードでも保護されています。

## モード

モードは、メッセージ欄の横にあるメニューで選びます。新しいチャットは **手動** で始まります。

| モード | 確認なしで実行 | 先に確認 | 実行しない |
| --- | --- | --- | --- |
| 手動 | ファイルの読み取りと一覧表示、安全なコマンド、公開されている読み取り専用のウェブ検索 | すべての変更：ファイルの編集、コマンド、ネットワーク操作、設定、Git、デプロイ、メッセージ | 保存された秘密情報の読み取り |
| 編集レビュー | 手動と同じ | 手動と同じ。編集はまとまりごとに、適用する前にレビューできる変更として表示されます | 保存された秘密情報の読み取り |
| プラン | ファイルの読み取りと一覧表示、安全なコマンド | なし：読み取って計画を提案するだけです | すべての変更、すべてのネットワーク操作 |
| 自動 | ファイルの読み取り・作成・編集、コマンド、ネットワークとブラウザの操作、モデルプロバイダ | 削除、既存ファイルの上書き、依存関係のインストール、プロバイダ設定の変更、Gitのコミット・プッシュ・マージ・リセット、デプロイ、メッセージの送信、支払い、設定の変更 | 保存された秘密情報の読み取り、セキュリティ設定の変更、VOOLが影響を特定できない操作 |
| 権限バイパス | 四つの保護対象の種類を除くすべて | 支払い | 保存された秘密情報の読み取り、セキュリティ設定の変更、VOOLが影響を特定できない操作 |

モード、スキル、プラグインは、提示される内容を狭めることしかできません。モードが許可していない操作を、それらのどれかが許可することはありません。

## 権限リクエストに答える

操作にあなたの判断が必要になると、メッセージ欄の上に **許可が必要です** のバーが開きます。バーには、その操作が正確に示されます。実行されるコマンドライン、または変更されるファイル、その変更を元に戻せるかどうか、そして編集内容のプレビューです。あなたが答えるまで何も実行されず、VOOLが再起動しても、リクエストはあなたを待ち続けます。時間切れになったリクエストは期限切れと表示され、承認できません。

バーには、その操作に合う選択肢だけが表示されます。

| ボタン | 許可される内容 |
| --- | --- |
| 一回だけ許可 | この一つの操作そのもの。 |
| このタスクで許可 | このタスクの間、同じモードで、同じ操作をもう一度。ファイルの編集ではない操作に対して表示されます。 |
| このリクエストの計画済み変更 *N* 件すべてを許可 | このリクエストがすでに計画しているファイルの変更、つまり「詳細を確認」に一覧表示された正確なファイルだけで、それ以外は含みません。 |
| このチャットでワークスペース編集を許可 | このチャットのワークスペース内での読み取り、新しいファイル、編集。八時間、またはVOOLが再起動するかチャットが削除されるまで有効です。 |
| このプロジェクトで許可 | プロジェクトのフォルダ内での読み取りとファイルの書き込み。この許可はプロジェクトに残り、再起動の後も、新しいチャットでも有効です。 |
| 詳細を確認 | 判断する前に、リクエストの全体を表示します。 |
| 拒否 | 操作は実行されません。 |

何を許可しても、削除、移動、上書き、コマンド、ネットワーク操作、秘密情報、支払いは、モード自体がそれらを許可していない限り、毎回別に確認されます。

## 権限バイパス

バイパスは、あなたが選んだ範囲と時間のあいだ、利用できるツールを個別の確認なしで実行します。

* **範囲：** 現在のタスクのみ、このチャットセッション、またはこのプロジェクト。
* **継続時間：** 15分または30分、1、2、4、8時間、15〜1440分の任意の長さ、または *自分でオフにするまで*（このチャットのみ）。

時間を指定したバイパスは、どのチャットでも使えます。*自分でオフにするまで* を使うには、チャットがプロジェクトフォルダに結び付けられている必要があり、そのフォルダは、ホームフォルダ全体、ディスクの最上位、VOOL自身のデータを保存しているフォルダであってはいけません。バイパスがオンの間は、バナーにその範囲と終了時刻が表示され、その **×** を押すとすぐにオフになり、チャットは「手動」に戻ります。チャットを削除すると、そのバイパスも終了します。バイパスがワークスペースの外へのアクセスを許可することは決してなく、モデルが自分の権限を広げることもできません。支払いは引き続き確認され、秘密情報とセキュリティ設定には手が届かないままです。

## 支払いと支出

操作を承認しても、支払いを承認したことには決してなりません。支払いは、どのモードでも、ウォレット独自の提案と承認を経て、その上限のもとで行われます。有料のモデル呼び出しは、プロバイダに接続する前に、支出上限と価格ガードで止められます。[ウォレット](../guides/wallet.md)と[支出の上限と価格ガード](../guides/spending-limits.md)を参照してください。

## 操作が拒否されたとき

拒否された操作は何も変更しておらず、メッセージには何がなぜ拒否されたのかが示されます。表示される可能性のあるコードは、[`permission_denied`](../ERROR_BOOK.md#permission-denied)、許可されたフォルダの外での変更に対する[`confinement_refusal`](../ERROR_BOOK.md#confinement-refusal)、このモードで提供されていないツールに対する[`tool_unavailable`](../ERROR_BOOK.md#tool-unavailable)です。[エラーとエラーコード](../reference/errors.md)を参照してください。
