# 対応モデル

VOOLにモデルは付属していません。ご自身で選んだランタイムやプロバイダに接続します。

## ローカルランタイム

localhostでOpenAI互換のエンドポイントを公開しているランタイムなら、どれでも使えます。よく使われるものは自動で検出されます。

## クラウドプロバイダ

クラウドモデルには、ご自身のキーを使って、お使いのマシンから接続します。いずれかを選ぶと、アプリはクラウドモードになります（表示にはプロバイダの名前が出ます）。[ローカルとクラウド](../concepts/local-and-cloud.md)を参照してください。

[OpenRouter](../guides/openrouter.md)は、一つの接続で最も幅広く使えます。一つのキーで、多くのプロバイダを利用できます。

## 選び方

| 作業 | 妥当な選択 |
| --- | --- |
| 非公開のファイル、ネットワークなし | ローカル、7B以上 |
| 日常的なコーディング | ローカルの7–14Bのコーディングモデル |
| 長い推論 | 大きめのクラウドモデル |
| コストの管理 | まずローカル、価値があるときはクラウド |
