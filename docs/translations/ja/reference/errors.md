# エラーとエラーコード

何かが失敗すると、VOOLは、何が起きたか、すでに何が起きた可能性があるか、次に何をすべきかを、わかりやすい言葉で伝えます。どの失敗にも、変わらないコードがあります。コードは、エラーの下にある技術的な詳細、コマンドライン（`wallet_export_refused: …`）、APIのレスポンスで確認できます。このページでは、エラーの読み方を説明します。[エラーブック](../ERROR_BOOK.md)では、すべてのコードを説明しています。

## エラーを読む

もう一度試す前に、次の三つを確認してください。

1. **何が起きたか。** メッセージです。内部のパスや秘密情報が含まれることは決してありません。
2. **すでに何が起きた可能性があるか。** ほとんどの拒否は、何かが送信されたり変更されたりする前に止まり、メッセージにもそう書かれます。リクエストが送られた後のタイムアウトのように、操作が完了したかどうかを知ることができない失敗もあります。その場合、メッセージは結果が不明であると伝え、再試行の前に確認するよう求めます。支払いが誤って二重に送られることは決してありません。同じ支払いを二度目に送ろうとすると、[`wallet_duplicate_payment`](../ERROR_BOOK.md#wallet-duplicate-payment)で拒否されます。
3. **次に何をすべきか。** 一つの具体的な手順です。

意味を持つのはコードです。403や429のようなHTTPステータスは、リクエストが途中でどうなったかを示すだけで、異なる二つの拒否が同じステータスになることもあります。ステータスではなく、コードを読んでください。

## コードとエラーブック

コードの名前が変わることも、別の意味で再利用されることも決してありません。[エラーブック](../ERROR_BOOK.md)はアプリ自身のエラーカタログから生成されているため、そこにあるコード、メッセージ、次の手順は、アプリが表示するものとまったく同じです。各コードには専用のセクションがあります。表示されたとおりのコードでページを検索するか、ブックのアドレス、`#`、アンダースコアをハイフンにしたコードをつなげて、セクションにリンクしてください。たとえば[`wallet_broadcast_failed`](../ERROR_BOOK.md#wallet-broadcast-failed)です。

よく目にする可能性が高いコードは次のとおりです。

| コード | タイトル | すでに起きた可能性があること |
| --- | --- | --- |
| [`permission_denied`](../ERROR_BOOK.md#permission-denied) | 権限が拒否されました | 何も変更されていません。 |
| [`provider_unavailable`](../ERROR_BOOK.md#provider-unavailable) | プロバイダに接続できません | 何も送信されていません。 |
| [`provider_exhausted`](../ERROR_BOOK.md#provider-exhausted) | プロバイダの上限に達しました | リクエストはプロバイダに届いています。 |
| [`timeout`](../ERROR_BOOK.md#timeout) | タイムアウト | 不明：再試行の前に確認してください。 |
| [`cancelled`](../ERROR_BOOK.md#cancelled) | キャンセル済み | 不明：一部はすでに実行されている可能性があります。 |
| [`credential_failure`](../ERROR_BOOK.md#credential-failure) | 保存された資格情報を読み込めませんでした | 何も送信も変更もされていません。 |
| [`unknown`](../ERROR_BOOK.md#unknown) | 予期しないエラー | 不明：再試行の前に確認してください。 |
| [`wallet_quote_mismatch`](../ERROR_BOOK.md#wallet-quote-mismatch) | 承認がプレビューと一致しなくなりました | 何も署名も送信もされていません。 |
| [`wallet_broadcast_failed`](../ERROR_BOOK.md#wallet-broadcast-failed) | 支払いをブロードキャストできませんでした | 不明：再試行の前に、支払いの状態を確認してください。 |
| [`wallet_duplicate_payment`](../ERROR_BOOK.md#wallet-duplicate-payment) | 支払いはすでに提案済みまたは送信済みです | 新たには何も送信されていません。以前の支払いが記録されています。 |

## エラーとその他の結果

VOOLはこれらを区別しており、その言葉づかいも区別しています。

* **エラー。** 何かが失敗しました。コードとメッセージが、何が起きたか、何をすべきかを伝えます。
* **あなたの対応待ち。** 権限リクエストまたは支払いの承認が開いています。何も実行されておらず、あなたが答えるまで何も実行されません。[権限](../concepts/permissions.md)を参照してください。
* **支出上限または価格ガードによる停止。** 拒否はプロバイダに接続する前に行われ、メッセージがプロバイダに問い合わせたかのように示すことは決してありません。[支出の上限と価格ガード](../guides/spending-limits.md)を参照してください。
* **キャンセル済み。** あなたかVOOLが、完了する前に止めました。一部はすでに実行されている可能性があるため、もう一度始める前に、何が変わったかを確認してください。
* **ここではできません。** このビルドまたはこのマシンではそれを実行できず、メッセージは何ならできるかを示します。たとえば、VOOLが端から端まで確認できない方式の支払いオファーや、インストールされていないオプションの追加機能です。
* **結果不明。** 操作が完了したかどうかわかりません。たとえば、ブロードキャストが確認されなかった支払いです。まず、その状態を確認してください。VOOLが、やみくもにもう一度支払うことは決してありません。

## 独自のコードを持つエラー

VOOLの一部の機能は、失敗が起きた画面で独自の短いコードを使って失敗を説明し、それらはエラーブックには載っていません。添付ファイル（たとえば大きすぎるファイルや、貼り付けたファイルに見つかった認証情報）、アプリのアップデート、プロジェクトフォルダ、モデルの選択、支出上限、連絡先、プラグインとスキル、音声入力、保存されたデータ、バグレポートです。これらのメッセージも同じように、何が起きたか、何をすべきかを伝えます。[チャットと添付ファイル](../concepts/chats-and-attachments.md)、[アップデートと移行](updates-migration.md)、[バグ報告とプライバシー](../trust/bug-reporting.md)を参照してください。

## 見覚えのないコード

エラーブックに載っていないコードは、このバージョンのVOOLから出たものではありません。どのバージョンで表示されたかを確認し、そのバージョンの[エラーブック](../ERROR_BOOK.md)を検索してください。このバージョンから出たものであれば、コードを書かれているとおりに、そしてレスポンスに参照番号（`fault-` と十二文字）が含まれていればそれも添えて報告してください。VOOLが分類できない失敗は[`unknown`](../ERROR_BOOK.md#unknown)として表示され、推測した原因が示されることは決してありません。[バグ報告とプライバシー](../trust/bug-reporting.md)を参照してください。

## 特定の症状のトラブルシューティング

インストール、モデル、プラットフォームの問題については[トラブルシューティング](../help/troubleshooting.md)を、チャット、メモリー、ウォレットを取り戻すには[バックアップと復元](../help/backup-and-recovery.md)を参照してください。
