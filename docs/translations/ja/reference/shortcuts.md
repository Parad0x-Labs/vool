# キーボードショートカット

macOSでは `⌘`、WindowsとLinuxでは `Ctrl` です。

| 操作 | ショートカット |
| --- | --- |
| 新しいセッション | `⌘ N` |
| コマンドパレット | `⌘ K` |
| モデルを切り替える | `⌘ M` |
| ワークスペースパネルの表示を切り替える | `⌘ J` |
| 現在の実行を停止する | `Esc` |
| 設定 | `⌘ ,` |
