# 键盘快捷键

macOS 上为 `⌘`，Windows 和 Linux 上为 `Ctrl`。

| 操作 | 快捷键 |
| --- | --- |
| 新建会话 | `⌘ N` |
| 命令面板 | `⌘ K` |
| 切换模型 | `⌘ M` |
| 显示或隐藏工作区面板 | `⌘ J` |
| 停止当前运行 | `Esc` |
| 设置 | `⌘ ,` |
