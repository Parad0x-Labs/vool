# 支持的模型

VOOL 不附带模型——第一个本地模型会在你第一次使用它时下载。它连接你选择的运行时和提供方。

## 本地运行时

Ollama、llama.cpp、vLLM 和 MLX 会被自动检测到。其他在 localhost 上提供 OpenAI 兼容端点的运行时可以手动指定。

## 云端提供方

云端模型通过你的密钥、从你的电脑访问。选择其中一个会让应用进入云端模式（指示会显示提供方的名称）——见[本地与云端](../concepts/local-and-cloud.md)。

[OpenRouter](../guides/openrouter.md) 是覆盖面最广的单一连接：一个密钥，众多提供方。

## 如何选择

| 工作 | 合理的选择 |
| --- | --- |
| 私密文件，不联网 | 本地，7B 或更大 |
| 日常编程 | 本地 7–14B 编程模型 |
| 长推理 | 更大的云端模型 |
| 控制成本 | 先用本地，值得时再用云端 |
