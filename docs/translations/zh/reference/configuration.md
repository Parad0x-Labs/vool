# 配置

## 位置

VOOL 把它的设置、聊天、记忆和记录保存在一个运行时主目录（runtime home）中：

| 安装方式 | 运行时主目录 |
| --- | --- |
| macOS 应用 | `~/Library/Application Support/VOOL/runtime` |
| Linux tar 包和源码安装 | `~/.vool_runtime` |
| Windows（实验性，从源码安装） | `%LOCALAPPDATA%\VOOL` |

在启动 VOOL 之前设置 `VOOL_HOME`，就会改用那个文件夹。启动日志会打印正在使用的主目录。

密钥 **不会** 被写入设置文件或日志。它们加密保存在这个运行时主目录中一个单独的凭据文件里，只有你的用户账户可以读取；在 Mac 上，VOOL 之前已经保存在 macOS 钥匙串中的密钥会继续留在那里。见[安全模型](../trust/security.md#密钥)。

## 设置

在应用中的 **设置** 下更改设置。决定 VOOL 可以做什么的设置有：

* **模型** — 当前使用的模型，它决定一轮对话是本地还是云端。
* **工作区** — 聊天工作所在的项目文件夹；关于 VOOL 还能访问的其他文件夹，见[工作区](../concepts/workspaces.md)。
* **操作模式** — 在消息框旁边的菜单中选择，而不是在这里。“手动”在每次更改之前都会询问；“自动”允许日常编辑和命令直接运行，而删除、覆盖、安装、花费和更改设置仍会询问。见[权限](../concepts/permissions.md)。
* **网络访问和加密货币** — 两者都保持关闭，直到你开启它们。

VOOL 没有产品遥测设置，因为它根本不发送产品遥测。

## 重置

退出 VOOL，并把运行时主目录移到别处。工作区文件不受影响；VOOL 会以全新的用户资料目录重新启动。你保存的密钥也会随之移走，所以请在 **设置 → API 密钥** 中重新添加。保存在 macOS 钥匙串中的密钥会一直留在那里，直到你在“钥匙串访问”中删除它们。
