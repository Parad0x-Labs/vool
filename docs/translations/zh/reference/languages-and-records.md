# 语言、无障碍与记录

## 界面语言

VOOL 的界面提供多种语言。选择语言只关乎呈现：权限决定、支出权限和错误代码 **在设计上与语言无关**——翻译后的错误消息绝不会放宽或收紧英文权威所作的决定。

## 无障碍

* 主要流程都有键盘快捷键（见[键盘快捷键](shortcuts.md)）。
* 文档和应用界面提供浅色和深色外观，跟随你的系统偏好，也可以手动切换。
* 错误以文字说明，而不只靠颜色；破坏性操作总是需要明确确认，而不是一次误点就生效。

## 活动

活动视图是 VOOL 所做一切的完整历史：带有输入和结果的工具调用、你批准或拒绝的批准请求，以及带有回执的付款。被某项保护拦下的一轮会显示这次拦截和对应的保护——拒绝是一条被记录的事件，而不是一片空白。

## 回执

涉及金钱和支出的操作会写入 **回执**：提出了什么、批准了什么、发送了什么，以及结算了什么。未知的结果会被记录为未知——绝不会被描述成成功或失败。正是这一点让 *“check its status before retrying”* 变得可以执行：回执会告诉你这笔付款实际处于哪种状态。

## 模型验证状态

VOOL 会区分模型 **说了** 什么和运行时 **证明了** 什么：

* 工具结果会连同其执行记录一起记录；回答中关于文件、付款或数据的说法会与这些记录绑定，没有依据的说法会被扣下不显示。
* 回执带有验证状态；在本版本中某个通道是实验性的或无法验证时，状态会如实说明，而不是暗示已经得到证明。

概念见[回执](../concepts/receipts.md)，失败如何分类见[错误](errors.md)。
