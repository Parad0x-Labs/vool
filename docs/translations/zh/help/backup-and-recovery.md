# 备份与恢复

VOOL 保存的一切都在你的电脑上，位于一个用户资料目录中（位置见[配置](../reference/configuration.md)）。更新或重新安装应用绝不会动到它。VOOL 没有你数据的云端副本，也没有一步备份整个用户资料目录的功能。下面是保存和找回重要内容的方法。

## 聊天

| 你想要 | 使用 | 你得到的 |
| --- | --- | --- |
| 一份用来阅读或分享的副本 | 聊天标题栏中的 **导出** | 整个聊天的文本或 Markdown 版本。附件只列出名称。 |
| 一份可以带回 VOOL 的副本 | 设置、备份与恢复、**导出对话** | 一个聊天，保存为由这台电脑签名的 `.voolsession` 文件。 |
| 从那个文件取回聊天 | 设置、备份与恢复、**导入对话** | 该聊天，添加在你的其他聊天旁边。 |
| 你在其他 AI 应用中的聊天 | 设置、备份与恢复、**从其他 AI 应用带入你的聊天** | 这些聊天，包括它们的名称和消息。 |

**导出对话** 会包含聊天的消息、回执和证据引用，绝不包含 VOOL 的内部推理、你的设置、记忆或密钥。当文件要离开这台电脑时，请用密码短语保护它：没有密码短语的导出会先请你确认。在写入任何内容之前，预览会准确显示将要写入的内容。

**导入对话** 会在添加任何内容之前，显示文件包含什么以及由谁签名。由 VOOL 不认识的密钥签名的文件会被拒绝，除非你接受它，而且该聊天会一直被标记为不受信任。导入绝不会更改你已有的聊天：如果同一个聊天已经在这里，副本会作为一个新聊天加入。

**从其他 AI 应用带入你的聊天** 会读取这台电脑上的某个应用或一个数据导出文件。你勾选要带入的聊天。没有任何内容会离开你的电脑，另一个应用的文件也绝不会被更改。VOOL 把这些聊天作为历史保存：它不会从中学习，也不会遵循其中写的任何内容。

## 记忆

设置、记忆与个性化、**导出个人资料** 会把 VOOL 记住的关于你的内容保存为一个名为 `vool-memory-` 加日期的文件。它绝不包含密钥或密码。它是一份用来阅读和保存的副本：VOOL 没有导入它的功能。

## 模型提供方的密钥

提供方密钥不在任何导出中。在新电脑上，请在设置中重新添加。

## 钱包

* **为某个网络创建的 VOOL 钱包** 会在设置过程中显示一次私钥备份，而且只在那时显示。请离线保存它：任何拿到它的人都能控制这个钱包。如果你忘记了钱包的 PIN 或密码，设置、加密货币中钱包上的 **Forgot PIN or password?** 会用这份备份恢复访问，然后你可以选择新的 PIN 或密码。
* **旧口袋** 由它的恢复短语保管，该短语在创建时只显示过一次。设置、加密货币、其他账户中的 **Restore from phrase…** 可以用短语把它找回来。它还可以用 **Export private key** 把私钥导出到 Phantom 或 MetaMask，这只能用 Touch ID 或你的 Mac 密码打开。
* 你只观察的钱包，或从其他应用连接的钱包，不在 VOOL 中保存任何密钥：这里没有需要备份的东西。

完整情况见[钱包](../guides/wallet.md)。

## 如果更新失败

在任何步骤失败的更新都会让应用保持原样。如果把数据迁移到新版本时失败，你的数据会恢复原样，VOOL 会在之前的版本上启动。见[更新与迁移](../reference/updates-migration.md)。
