# 常见问题

## VOOL 能离线工作吗？

能，使用本地模型时，你的聊天和文件可以离线。云端模型本质上就需要网络连接。天气、价格等实时信息只有在“网络查询”开启时（全新安装时它是关闭的）才会从公共网络服务获取，在“仅本地”下则绝不会获取。

## 我需要云端密钥吗？

不需要。只用本地模型就能使用这款应用。

## 我的密钥存放在哪里？

存放在你电脑上 VOOL 运行时主目录中的一个加密文件里，只有你的用户账户可以读取。在 Mac 上，VOOL 之前已经保存在 macOS 钥匙串中的密钥会继续留在那里。密钥始终留在你的电脑上。见[安全模型](../trust/security.md#密钥)。

## Parad0x 能看到我的提示词吗？

本地模式下看不到，云端模式下也看不到——云端请求从你的电脑发往你的提供方。见[数据处理](../trust/data-handling.md)。

## 为什么打开它时系统会发出警告？

macOS 应用是 ad-hoc 签名的，但尚未经过公证，所以 macOS 会在首次打开时请你确认。操作步骤见[安装](../getting-started/install.md#在-mac-上首次打开)。另见[发布状态](../trust/release-status.md)。

## 我能使用自己的模型吗？

能。任何提供 OpenAI 兼容本地端点的运行时都可以。见[支持的模型](../reference/models.md)。

## 它免费吗？

测试期间，这款应用是免费的。云端模型的用量由你的提供方向你的账户计费。
