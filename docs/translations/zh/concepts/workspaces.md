# 工作区

工作区是一个聊天工作所在的项目文件夹。VOOL 会在其中读取和更改文件，只要你的操作模式要求，它就会先询问你（见[工具](tools.md)）。

## 添加和移除

要选择一个文件夹，请使用聊天中的 **选择项目文件夹…**，或聊天侧边栏中的 **+ 项目**。删除一个项目会让 VOOL 忘记它在其中学到的内容，并把它的聊天移回“常规”。你的文件不受影响。

## 你的其他文件夹

在工作区之外，VOOL 的文件工具也可以访问你的个人文件夹，但有固定的限制：

| 文件夹 | VOOL 能做什么 |
| --- | --- |
| Desktop、Downloads、Documents | 读取和更改文件，并按你的操作模式的要求先询问 |
| Pictures、Movies（Linux 上为 Videos）、Music | 只读：列出、查找、打开和测量，绝不更改 |
| 你的其他可见个人文件夹，例如 `~/Projects` | 只读 |
| 隐藏文件夹（例如 `~/.ssh`）、应用和系统数据（`Library`、`Applications`、`AppData`）、VOOL 自己的数据文件夹 | 绝不访问 |

VOOL 只在请求需要时才查看这些文件夹，例如“找到我的报税 PDF”或“Movies 里哪个视频最大”。它不会在后台为你的磁盘建立索引。

## 范围建议

* 让工作区指向一个项目，而不是你的主目录。
* 把凭据文件、密钥材料和密码库放在密码管理器或隐藏文件夹中，不要散放在 Desktop、Downloads、Documents 或项目文件夹里。
* 每项工作使用单独的项目，这样一项工作的上下文不会进入另一项工作。

{% hint style="warning" %}
选择云端模型时，VOOL 读取的任何内容，无论是在项目文件夹中还是在你的个人文件夹中，都可能被包含在发送给提供方的内容里。请有意识地划定范围。
{% endhint %}
