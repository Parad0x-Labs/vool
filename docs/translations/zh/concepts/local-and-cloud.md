# 本地与云端

VOOL 有两种状态。界面上始终显示当前处于哪一种。

## 本地

一切都留在这台电脑上。模型在本地运行时上运行，文件从磁盘读取，不会向任何提供方发出请求。

## 云端（提供方名称）

所选上下文从你的电脑出发、使用你的密钥，直接发送给你选择的提供方。

“所选上下文”是指应用为这次请求组装的内容：你的提示词，加上这次请求需要的文件和之前的对话轮次。发送之前会显示出来。

{% hint style="danger" %}
云端模式会把数据发送到你的电脑之外。这正是云端模式的意义所在。VOOL 的承诺针对的是 *路径* ——请求从你的电脑发往你的提供方——而不是说什么都不会传输。
{% endhint %}

## 中间有什么

没有任何由 Parad0x Labs 运营的东西。模型流量不经过任何代理、网关或中转。你的密钥由你电脑上的应用使用，直接与提供方通信。

完整详情见[数据处理](../trust/data-handling.md)。
