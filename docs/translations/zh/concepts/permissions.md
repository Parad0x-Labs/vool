# 权限

VOOL 在任何操作运行之前就决定什么可以运行。模型可以请求一个操作；由你选择的模式和你的回答决定它是否发生。读取与更改被区别对待，机密、付款和安全设置在每种模式下都受到保护。

## 模式

在消息框旁边的菜单中选择模式。新聊天从 **手动** 开始。

| 模式 | 无需询问即运行 | 先询问 | 绝不 |
| --- | --- | --- | --- |
| 手动 | 读取和列出文件、安全命令，以及公开的只读网络查询 | 任何更改：文件编辑、命令、网络操作、设置、Git、部署和消息 | 读取已存储的机密 |
| 审查编辑 | 与手动相同 | 与手动相同。每批编辑在应用之前都会显示为可审查的更改 | 读取已存储的机密 |
| 计划 | 读取和列出文件，以及安全命令 | 无：它只读取并提出计划 | 任何更改、任何网络操作 |
| 自动 | 读取、创建和编辑文件，命令，网络和浏览器操作，以及模型提供方 | 删除、覆盖现有文件、安装依赖、更改提供方设置、Git 提交、推送、合并和重置、部署、发送消息、付款以及更改设置 | 读取已存储的机密、更改安全设置，以及 VOOL 无法识别其效果的任何操作 |
| 权限旁路 | 除四类受保护操作之外的一切 | 付款 | 读取已存储的机密、更改安全设置，以及 VOOL 无法识别其效果的任何操作 |

模式、技能或插件只能缩小可提供的范围。它们都不能授予模式不允许的操作。

## 回应权限请求

当某个操作需要你处理时，消息框上方会打开一个 **需要权限** 栏。它会点明确切的操作：将要运行的命令行，或将要更改的文件、更改能否撤销，以及编辑内容的预览。在你回答之前什么都不会运行，即使 VOOL 重启，请求也会一直等你。超时的请求会显示为已过期，无法再批准。

该栏只提供适合该操作的选项：

| 按钮 | 允许什么 |
| --- | --- |
| 仅允许一次 | 仅此一个确切的操作。 |
| 为此任务允许 | 在此任务期间、在同一模式下再次执行同一个确切操作。用于不是文件编辑的操作。 |
| 允许此请求的全部 *N* 项计划中的变更 | 此请求已经计划好的文件更改，即“审查详情”中列出的确切文件，不含其他任何内容。 |
| 在此对话中允许工作区编辑 | 在此聊天的工作区内读取、新建文件和编辑，持续八小时，或直到 VOOL 重启或该聊天被删除。 |
| 在此项目中允许 | 在项目文件夹内读取和写入文件。这一许可会一直保留在该项目上，重启之后和新聊天中也有效。 |
| 审查详情 | 在你做决定之前显示完整的请求。 |
| 拒绝 | 该操作不会运行。 |

无论你允许了什么，删除、移动、覆盖、命令、网络操作、机密和付款每次仍会单独询问，除非模式本身允许它们。

## 权限旁路

旁路会在你选择的范围和时间内运行可用工具，而不逐一询问：

* **范围：** 仅当前任务、此聊天会话，或此项目。
* **时长：** 15 或 30 分钟，1、2、4 或 8 小时，15 到 1440 分钟之间的自定义时长，或 *直到我关闭它*（仅限此对话）。

限时旁路在任何聊天中都可用。*直到我关闭它* 要求该聊天关联到一个项目文件夹，而且该文件夹不能是你的整个个人文件夹、磁盘的顶层，或存放 VOOL 自身数据的文件夹。旁路开启期间，横幅会显示它的范围和结束时间，点它的 **×** 会立即关闭旁路；聊天会回到“手动”。删除聊天也会结束它的旁路。旁路绝不授予工作区之外的访问权限，也不能让模型扩大自己的权限。付款仍会询问，机密和安全设置依然无法触及。

## 付款与支出

批准一个操作绝不等于批准一笔付款。在每种模式下，付款都要经过钱包自己的提案和批准，并受其限额约束。付费模型调用在联系提供方之前，就会受到你的支出上限和价格保护的约束。见[钱包](../guides/wallet.md)和[花费限额与价格保护](../guides/spending-limits.md)。

## 操作被拒绝时

被拒绝的操作没有更改任何内容，消息会说明拒绝了什么以及原因。你可能看到的代码有 [`permission_denied`](../ERROR_BOOK.md#permission-denied)、针对允许范围之外文件夹中更改的 [`confinement_refusal`](../ERROR_BOOK.md#confinement-refusal)，以及针对此模式不提供的工具的 [`tool_unavailable`](../ERROR_BOOK.md#tool-unavailable)。见[错误和错误代码](../reference/errors.md)。
