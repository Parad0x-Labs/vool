# 回执

回执是一次运行的持久记录：调用了哪些工具、输入是什么、每个工具返回了什么。

## 为什么需要回执

智能体对自己工作的总结只是一种说法。回执是你可以用来核对这种说法的记录。

## 回执里有什么

| 字段 | 含义 |
| --- | --- |
| `tool` | 运行了哪个操作 |
| `input` | 给了它什么 |
| `result` | 它返回了什么 |
| `time` | 它何时运行 |

回执保存在这台电脑上 VOOL 的运行时主目录中（见[配置](../reference/configuration.md)），而不是你的项目文件夹中。回执只有在你预览并选择发送的错误报告中才会离开你的电脑（见[错误报告与隐私](../trust/bug-reporting.md)）。
