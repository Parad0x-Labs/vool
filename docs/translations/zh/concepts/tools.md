# 工具

工具是运行时可以代你执行的操作——读取文件、运行命令、搜索文件夹。

## 天生可检查

每次工具调用都会记录请求了什么、运行了什么、返回了什么。事后无需重新运行，就可以回看一次运行。

## 权限

工具是立即运行还是先询问，取决于你选择的模式和具体操作。新聊天从“手动”开始，任何更改都会先询问。在“自动”下，创建和编辑文件、命令和网络操作会直接运行，而删除、覆盖、安装、Git 提交和推送、部署、发送消息、付款以及更改设置仍会询问。在任何模式下，文件工具都只在[工作区](workspaces.md)内工作，搜索和获取工具只读取公开资源而不写入任何内容，已存储的机密绝不会被读取。[权限](permissions.md)介绍了全部五种模式，以及每个批准按钮允许什么。

```text
tool: read_file
path: src/main.py
result: 412 lines
```

另见[回执](receipts.md)。
