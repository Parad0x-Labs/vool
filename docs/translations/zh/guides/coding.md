# 用 VOOL 编程

## 把工作区设为代码仓库

让[工作区](../concepts/workspaces.md)指向项目根目录。VOOL 会读取它需要的文件，而不是加载整个目录树。

## 用代码的语言提问

点出一个文件或符号，能给运行时一个起点：

> 找到 `src/auth/` 中设置会话超时的位置，并解释超时到期时会发生什么。

## 应用之前先审查

在“手动”模式下，每次编辑都会先询问。在“自动”模式下，日常编辑和命令可以自动运行并显示在活动记录中，而删除和覆盖仍会询问。在大改动之前先提交，这样差异既易于阅读，也易于撤销。

## 本地还是云端

两种模式都可以编程。一个 7B 的本地编程模型就能处理大部分日常编辑；更大的云端模型适合更长的推理。在你发送之前，模型指示会告诉你当前是哪一种：本地模型显示 `LOCAL`，云端模型显示 `CLOUD`，由 VOOL 选择时默认显示 `AUTO`（`VOOL Auto`、`Local first`）。
