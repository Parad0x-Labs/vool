# 发现技能与 Eyebrow 检查

“技能与插件”页面有四个标签页：**浏览**、**技能宝典**、**我的附加组件** 和 **安全**。“浏览”会先列出 VOOL 自己的技能，包括随应用打包的 53 个纯文本 VOOL 技能，然后是经过审查的目录附加组件，还可以按固定的修订版本查询公开的 GitHub 仓库。“技能宝典”把 VOOL 团队的技能列在最前面，排在编辑精选和推荐技能之上。搜索忽略大小写和常见分隔符；类别和排序控件可以缩小列表范围。下载之前就能看到来源、许可证、修订版本和要求。

## 首次使用

1. 在“安全”标签页中保存一个 Eyebrow API 密钥，该标签页也可以在 设置 → API 密钥 下找到。现有的凭据存储负责保管该密钥。保存不会测试连接，也不会扫描任何内容；“测试连接”会明确地联系 Eyebrow。
2. 在“浏览”中选择一个技能，并批准下载它的公开内容以及把这些内容发送给 Eyebrow。这会按照你的套餐消耗该服务的扫描额度。不会自动重试。
3. 阅读返回的报告。仅仅是 HTTP 响应成功，并不代表结果干净。这个初始目录只在报告为完整的 `pass`、没有任何发现项且没有违反策略时才允许安装。“拒绝”会丢弃已暂存的下载而不安装它。
4. 单独接受安装。VOOL 会保留许可证，通过其现有的插件生命周期进行安装，验证经过审查的确切包，然后启用该技能。它可能建议的每个操作仍然受现有权限的约束。

扫描是供应商对特定字节的评估，并不保证安全性、兼容性或回答质量。被收录进目录也不代表对发布者的认证。

## 边界

内容只来自固定在 40 个字符修订版本上的公开 GitHub 仓库，技能文件和许可证文件均以 SHA-256 固定。此版本没有私有仓库、压缩包解压、安装脚本，也没有可执行文件/MCP 插件导入器。只有独立的 SKILL.md 会发送给 Eyebrow；本地聊天、工作区文件、凭据和许可证内容都不会被提交扫描。

下载的内容在审查和接受之前保持惰性。本地认证的回执会把报告绑定到固定的内容上。安装会拒绝已过期的审查（24 小时）、被修改过的暂存文件，以及已存在的目标目录。在把受管理的技能加入模型上下文之前，运行时会检查生命周期状态和经过审查的字节。新增的文件、符号链接或被更改的内容都会使其不可用。指导内容要么被完整插入，要么因提示词预算不足而被明确记录为已省略；扫描过的指令不会被悄悄截断。

这些检查无法隔离已经以操作系统用户身份运行的恶意代码。它们也不覆盖之前手动安装的插件。扫描回执不会授予任何新的执行权限或钱包权限。

## API 与失败处理

`GET /api/addons` 返回目录和本地状态，不进行连接测试或扫描。`POST /api/addons` 支持 `save_key`、`remove_key`、`test_key`、`scan`、`install` 和 `reject`。变更操作要求回环地址、JSON 和同源浏览器请求；只接受特定于该操作的字段。调用方提供的来源 URL 和路径会被拒绝。

客户端在 `/v1/scan` 使用 Eyebrow v1 的内联技能来源请求，采用 bearer 认证、固定的 HTTPS 源、不跟随重定向、限定响应大小，且不自动重试。明确的连接测试使用 `/v1/version`。API 参考：https://eyebrow.cc/api/reference

典型的类型化失败包括：

| 代码 | 含义 / 恢复 |
| --- | --- |
| `eyebrow_key_missing` / `eyebrow_unauthorized` | 保存或替换密钥。 |
| `eyebrow_quota` | 重试之前先查看服务额度。 |
| `eyebrow_timeout` / `eyebrow_unreachable` | 不会自动重试；超时的扫描可能仍会消耗额度。 |
| `eyebrow_invalid_report` / `eyebrow_no_coverage` | 证据不完整；不会启用任何内容。 |
| `addon_source_changed` / `addon_changed` | 固定的或经过审查的字节不同；不要激活它们。 |
| `review_untrusted` / `review_expired` | 安装前先获取新的审查。 |
| `addon_already_installed` | 已保留现有文件。尚未实现自动替换。 |

## 当前限制与验证

对于已存在且被更改过的包，没有自动更新、任意目录导入器，也没有原地修复/重新安装的流程。应用重启后恢复待处理审查的功能没有在界面中提供。新的界面文字目前以英文作为后备；不声称已有完整的翻译。

自动化测试在明确模拟公开下载和 Eyebrow 回复的情况下，运行真实的生命周期、技能加载、API 处理程序和所提供的浏览器界面。它们证明的是运行时和界面的行为，而不是 Eyebrow 的实际可用性或模型的能力。真实的、使用密钥的扫描以及原生打包应用的验收仍然是发布检查项。运行这些测试不需要任何密钥或付费服务调用。
