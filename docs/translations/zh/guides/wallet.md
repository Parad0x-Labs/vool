# 钱包

钱包是 **可选的，默认关闭**。它的存在是为了让 VOOL 能为按请求收费的 AI 服务持有少量加密货币。使用 VOOL 并不需要钱包的任何部分。

本页介绍当前版本实际支持的内容。钱包处于 **试点** 阶段：功能按通道逐一添加，下面每个通道都会确切说明它能做什么。

## 网络环境

开启加密货币后，VOOL 在 **主网** 上运行：Solana、Robinhood Chain、Base、Ethereum、BNB 和 Arbitrum One。正常设置过程中绝不会要求你选择网络环境。

* **主网** — 每个安装的默认环境，包括带着旧测试网络账户升级上来的安装。下文描述的每项支出上限、批准和回执都适用。
* **Test networks** — Solana Devnet、Robinhood Chain Testnet 以及其他测试通道。仅供开发者使用：在 **设置 → 加密货币 → 开发者选项** 中切换。

账户、余额和回执属于某一个环境，绝不会在环境之间转移；另一个环境中的账户会继续列在各自的网络下。针对另一个环境中网络的请求会被拒绝，不会创建、提出或签署任何内容。

{% hint style="warning" %}
早先的文档说本版本不可能使用主网。在试点之前确实如此，现在已不再成立：主网条目现在已经存在。仍然成立的情况范围更窄——具体哪些通道存在于主网上，请看下面的转账和付款部分。
{% endhint %}

## 哪个通道能转移什么

* **转账可转移原生币**（例如 Solana 上的 SOL，Base、Ethereum 或 Arbitrum One 上的 ETH），以及 **Solana、Ethereum、BNB Smart Chain 和 Arbitrum One 上的 USDT**。链是每个已保存联系人地址和每次批准的一部分。代币转账还需要该链的原生币来支付手续费；报价会在你的限额内同时显示这两个金额。
* **Solana 和 Base 上的 USDC 仅可用于支付通道。** 普通发送不提供它。钱包的主余额显示的是原生币，而不是完整的代币投资组合。
* 每笔转账都会先预览（一份 **报价**：金额、手续费上限、收款方、网络），并需要你明确批准，且这份批准与该预览完全绑定。任何内容一旦更改，批准即告作废——不会签署任何内容。
* 如果一个名称匹配多个联系人或钱包地址，会请你选择。请核对确切的地址和链。地址被更改或联系人被重命名，都会使之前的审查失效。
* 在主网上，只有在这台设备上创建的 VOOL 钱包才能发送。你连接的外部钱包或仅观察地址可以接收并显示余额；从它们发起的发送或支付通道付款，会在请求任何批准之前就被拒绝，也不会签署任何内容。
* 活动会记录通过 VOOL 进行的付款及其回执。它不是完整的收款历史。此钱包不提供兑换或跨链桥操作。

## 付款如何批准

1. VOOL 准备一份提案，列明确切金额和手续费上限。
2. 你用 PIN/密码（或在可用时用设备在场验证）批准它。
3. 付款被签署并发送，并记录一份回执。

批准不能在提案之间转移。错误的 PIN 不会签署任何内容。错误尝试次数过多会让钱包锁定一段时间——这是有意为之，并会注明需要等待多久。

## x402 自动付款

x402 是一些网站和 AI 服务使用的按请求付款协议。**要求用 Base 上的 USDC 进行 x402 付款的网站**（在开发者选项中也可以是 Base Sepolia）可以从你的 Crypto Pilot 钱包付款：用你的 PIN 批准一次，且在你的限额之内。网站的支付服务会承担网络手续费。**目前还没有用这种方式进行过真实的主网付款。** 其他测试网络（Solana Devnet、Ethereum Sepolia 和 BNB testnet）仍在开发者选项中。**设置 → 加密货币 → Payment channels** 列出了钱包向网站付款的每一种方式，每种都有自己的开关；关闭的通道会在签署任何内容之前就拒绝。通过 Solana pay-kit 付款不包含在下载版中，因此该通道显示为不可用。**模型市场：** 设置中模型市场里的按次付费选项可以从 Solana 主网 Crypto Pilot 钱包用 USDC 或 SOL 付款。每次调用都会在你的钱包限额内等待你的批准，并显示 0.1% 的 VOOL 费用。这条路径尚未在真实的链上测试过。当付费资源使用 x402 时：

* 付款经过同样的钱包上限和批准流程。
* 自动付款按每笔付款设上限；超过上限的资源 **不会被付款**（你可以有意地提高上限，或通过明确的提案付款）。
* 如果付款未能完成，结果会报告为 **未知**——重试之前请先检查其状态；VOOL 不会引导你盲目地重复付款。

## DNA 服务费

模型市场的按次付费 x402 路线会对每笔被接受的提供方付款收取 **0.1%（10 个基点）** 的服务费，与付款本身和网络手续费分开显示。其他任何操作都不会产生这项费用：普通发送、创建钱包、本地推理以及使用你自己的 API 密钥（BYOK）的调用都 **不收取** 服务费。累计的费用会以经济的方式收取（随后来的一笔原生付款一起、在一次批准之下，并且只在收取成本有限时才收取）——绝不会作为一笔意外的单独扣费。

## 恢复

* **恢复短语只显示一次**，在创建时显示。
* 试点钱包的备份密钥同样只在设置过程中给出一次，之后无法再导出。如果你没有保存它，请取消设置，不要向该地址发送资金。
* 在 Crypto Pilot 之前创建的较旧 VOOL 钱包，可以把私钥导出一次，以导入另一个钱包应用。导出只能用你 Mac 自己的登录方式（Touch ID 或你的 Mac 密码）打开，绝不能用钱包 PIN 打开，而且密钥只显示一次，不会被保存。
* 丢失了钱包？用你在创建时写下的短语恢复。与这个钱包不完全吻合的恢复证明会在任何写入之前被拒绝。
