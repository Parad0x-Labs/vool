# 运行本地模型

## 安装运行时

VOOL 与本地模型服务器通信。macOS 应用自带本地模型运行器，所以在 Mac 上可以跳过这一步。在 Linux 和源码安装中，请安装 Ollama 之类的服务器，启动它，并拉取一个模型。

```bash
ollama serve
ollama pull qwen2.5-coder:7b
```

## 让 VOOL 指向它

打开 **设置 → 模型与提供方**。正在运行的本地运行时会被自动检测到。选择一个模型后，模式指示会变为“本地”。

## 认证一次

本地模型只有在通过认证后才会写出回答。打开 **设置 → 模型与提供方 → 本地模型**，注册该模型，然后选择 **Certify**。认证会在你的电脑上运行一项简短的工具检查；不会下载任何内容，也不会联系任何人。在模型通过之前，VOOL 不会让它写出最终回答。

## 模型大小

| 模型大小 | 所需内存 | 适合 |
| --- | ---: | --- |
| 3B | 约 4 GB | 简短编辑、快速提问 |
| 7–8B | 约 8 GB | 一般使用、大多数编程 |
| 14B | 约 16 GB | 更长的推理 |
| 32B+ | 32 GB 或更多 | 更重的工作，速度较慢 |

{% hint style="info" %}
量化版本可以大幅降低内存占用。4 位量化的 7B 模型大约 5 GB 就能流畅运行。
{% endhint %}

## 如果速度慢

* 选择更小或量化程度更高的模型。
* 关闭其他占用大量内存的应用程序。
* 缩短上下文——请求中的文件越少，需要处理的内容就越少。
