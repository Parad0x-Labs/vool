# 运行本地模型

## 安装运行时

VOOL 默认使用 Ollama 运行本地模型；其他提供 OpenAI 兼容端点的本地运行时也可以使用。Ollama 是一个单独的程序，需要从 [ollama.com](https://ollama.com) 单独安装。macOS 应用自带本地模型运行器，所以在 Mac 上可以跳过这一步。在 Linux 和源码安装中，请安装 Ollama，启动它，并拉取一个模型。

```bash
ollama serve
ollama pull qwen3:4b
```

VOOL 默认会为你选择本地模型——一个与你的电脑相匹配大小的 Qwen 模型。在许多电脑上，这个模型是 `qwen3:4b`；在内存为 32 GB 或更多的电脑上，默认是一个更大的 Qwen 模型。

## 让 VOOL 指向它

打开 **设置 → 模型与提供方**。正在运行的本地运行时会被自动检测到。选择一个模型后，模式指示会变为“本地”。

## 让它准备好，一次即可

本地模型只有在 VOOL 检查过之后才会写出回答。打开 **设置 → 模型与提供方 → 本地模型**，然后按该模型旁边的 **使用此模型**。VOOL 会在你的电脑上悄悄检查，该模型能否足够好地使用 VOOL 的工具来为你回答。检查可能需要一两分钟；不会下载任何内容，也不会联系任何人。通过后，该模型会显示 **已就绪**，VOOL 就用它来回答。在此之前，VOOL 不会让它写出最终回答。

* **不太合适：** 该模型不能足够好地使用 VOOL 的工具。VOOL 会列出你可以改做的事：使用或下载它为这台电脑选择的模型，或者使用云端模型。
* **检查未完成：** 请确认 Ollama 已打开，然后按 **重试**。较慢的电脑可能需要再试一次。

如果 VOOL 启动时没有已就绪的本地模型，它会检查这台电脑上最多三个模型，先检查你选择的那个，并使用第一个通过的模型。对这台电脑来说太大的模型会被跳过。已就绪的模型总是排在未就绪的模型之前。

## 模型大小

| 模型大小 | 所需内存 | 适合 |
| --- | ---: | --- |
| 3B | 约 4 GB | 简短编辑、快速提问 |
| 7–8B | 约 8 GB | 一般使用、大多数编程 |
| 14B | 约 16 GB | 更长的推理 |
| 32B+ | 32 GB 或更多 | 更重的工作，速度较慢 |

{% hint style="info" %}
量化版本可以大幅降低内存占用。4 位量化的 7B 模型大约 5 GB 就能流畅运行。
{% endhint %}

## 如果速度慢

* 选择更小或量化程度更高的模型。
* 关闭其他占用大量内存的应用程序。
* 缩短上下文——请求中的文件越少，需要处理的内容就越少。
