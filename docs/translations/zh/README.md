# VOOL

VOOL 是本地优先的 AI 桌面运行时。它在你的电脑上运行，默认使用本地模型，只有在你指定时才连接云端服务商，并保留每次工具调用的可读记录。

## 从这里开始

| 你想做什么 | 阅读 |
| --- | --- |
| 让 VOOL 跑起来 | [安装](getting-started/install.md) |

## VOOL 是什么

* **桌面运行时。** 它作为应用程序安装，不是浏览器标签页，也不是托管服务。
* **默认本地。** 选择本地模型时，提示词和文件都在你的机器上处理。
* **模型无关。** 本地运行时和云端服务商都可选。云端密钥由你提供，并保存在你的机器上。
* **可检查。** 每次工具调用都会记录输入和结果，事后可以回读。

{% hint style="warning" %}
VOOL macOS 测试版已面向 Apple 芯片发布。测试版安装包未签名，macOS 版本未经过公证 — 系统在首次启动时会发出警告。
{% endhint %}

## 两种状态

界面始终显示当前处于哪一种：

1. **本地** — 工作留在这台电脑上。
2. **云端** — 所选上下文直接发送给你选择的服务商。

两者之间没有由 Parad0x 运营的中继。
