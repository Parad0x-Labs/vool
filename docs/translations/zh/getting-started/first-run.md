# 首次运行

首次启动时会问四个简短的问题。每个问题都可以跳过，所有答案以后都可以修改。你回答期间不会向任何地方发送任何内容，唯一的例外是：如果你添加了云端密钥，会向其提供方验证这个密钥。

## 会发生什么

1. **它应该在哪里思考？** 用本地模型在这台电脑上思考，或用你付费的提供方的密钥在线思考。见[连接模型](connect-a-model.md)。
2. **选择一个文件夹。** VOOL 工作所在的项目文件夹。见[工作区](../concepts/workspaces.md)。
3. **它可以独自做什么？** VOOL 在更改任何内容之前多久停下来问你一次。见[工具](../concepts/tools.md)。
4. **该怎么称呼你？** 可选。名字或昵称就够了，而且它只保存在这台电脑上。

之后，模式指示会显示“本地”“自动”或云端提供方的名称，并反映当前选择的模型。

**为本地模型认证一次。** 在本地模型能够回答之前，请打开**设置 → 模型与提供方 → 本地模型**，为该模型按一下 **Certify**。这会在你的电脑上运行一项简短的检查。

## VOOL 在首次运行时不会做的事

* 不会创建账户。
* 不要求云端密钥。只用本地模型就能使用这款应用。
* 不会为你的磁盘建立索引。它只在请求需要时才读取文件；它能访问哪些文件夹，见[工作区](../concepts/workspaces.md)。

{% hint style="info" %}
你可以随时通过聊天侧边栏中的 **+ 项目** 选择另一个项目文件夹。
{% endhint %}
