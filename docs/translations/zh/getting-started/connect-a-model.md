# 连接模型

VOOL 不附带模型。它默认选择一个本地模型，你也可以选择别的；这个选择决定了请求是留在你的电脑上还是离开它。

## 本地

如果已安装并正在运行本地运行时，VOOL 会检测到它并列出其中的模型。选择其中一个后，指示会显示“本地”。配置详情见[运行本地模型](../guides/local-models.md)。

## 云端

在 **设置 → API 密钥** 中添加提供方密钥。密钥保存在这台电脑上的一个加密文件中（见[安全模型](../trust/security.md#密钥)），用于 **从你的电脑直接向提供方** 发送请求。

选择云端模型后，指示会显示提供方的名称，而且会在发出任何请求之前就切换过来。

OpenRouter 的具体流程见[连接 OpenRouter](../guides/openrouter.md)。

## 切换

切换模型就会切换模式。以指示为准：如果它显示“本地”，下一个请求就在这台电脑上处理。
