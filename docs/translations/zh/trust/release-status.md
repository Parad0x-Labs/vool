# 发布状态

本页是持续维护的发布状态权威说明。其他文档会顺带提到发布方面的事实；当它们与本页不一致时，以本页为准。

## 当前阶段

VOOL 处于 **测试版** 阶段。当前版本是 [**v0.7.7-beta**](https://github.com/Parad0x-Labs/vool/releases/tag/v0.7.7-beta)，这是一个从 `main` 的 `8af687c` 构建的 GitHub 发布版。它提供三个平台的应用下载，每个都附有公布的 SHA-256 校验和。使用引导脚本从源码安装在 macOS、Linux 和 Windows 上仍然受支持；见[安装](../getting-started/install.md)。

| 下载 | 适用于 |
| --- | --- |
| `VOOL-0.7.7-beta-macos-arm64.dmg` | Apple Silicon Mac，macOS 14 或更新版本 |
| `VOOL-0.7.7-beta-macos-x86_64.dmg` | Intel Mac，macOS 14 或更新版本 |
| `vool-0.7.7-beta-linux-x86_64.tar.gz` | Linux x86_64，已在 Ubuntu 22.04 和 24.04 上测试 |

本仓库的发布记录涵盖 GitHub 渠道。其他下载渠道是单独运营的；任何下载都请对照 GitHub 发布版上公布的校验和进行核对。

## 这对你意味着什么

* 首次启动 Mac 应用时，由于它未经公证，macOS 会拒绝打开它。在现阶段这是预期行为，并不说明下载的文件已损坏。请先核对校验和，然后打开 **系统设置 → 隐私与安全**，点按 **仍要打开**。在 macOS 14 上，你也可以按住 Control 键点按该应用，然后选取 **打开**。
* 请选择与你的芯片相符的 Mac 版下载。Apple Silicon 版应用无法在 Intel Mac 上运行，启动时会提示这一点。
* 配置格式可能会在不同版本之间变化。
* 加密货币功能在你开启之前一直关闭。

## 测试版和试点阶段的限制，明确列出

| 功能 | 在本版本中的状态 |
| --- | --- |
| 加密货币和钱包 | 默认关闭。开启后，VOOL 使用主网；测试网络在开发者选项中。每笔付款都经过 VOOL 的钱包，并受其限额约束、需要你的批准，并有回执。见[钱包](../guides/wallet.md)。 |
| 主网转账 | 原生币，以及 Solana、Ethereum、BNB Smart Chain 和 Arbitrum One 上的 USDT，从在这台设备上创建的 VOOL 钱包发送。Solana 和 Base 上的 USDC 仅用于支付通道。已连接的账户或仅观察账户可以接收并显示余额，但无法从 VOOL 发送。 |
| 用 x402 付款 | 要求用 Base 或 Base Sepolia 上的 USDC 进行 x402 付款的网站，可以从你的 Crypto Pilot 钱包付款：用你的 PIN 批准一次，且在你的限额之内。网站的支付服务会承担网络手续费。**设置 → 加密货币 → Payment channels** 为钱包向网站付款的每一种方式都提供一个开关；关闭的通道会在签署任何内容之前就拒绝。目前还没有用这种方式进行过真实的主网付款。通过 Solana pay-kit 付款不包含在下载版中；该通道显示为不可用。 |
| X | 在任何聊天中：搜索帖子和账户、Spaces、趋势和私信，并查询某个代币过去的喊单。任何会对你的账户执行操作的内容都会等你同意。 |
| 听写 | 在本测试版中不可用。 |
| 云端“突发”提问模式 | 本版本中尚未接入按次调用的提示。 |
| 本地模型 | 在本地模型能够回答之前，请打开 **设置 → 模型与提供方 → 本地模型**，为该模型按一次 **Certify**。 |
| Intel Mac | 本地模型在处理器上运行，速度较慢。认证已考虑到较慢的处理器，但较长的记忆类回答可能会超时，因此目前请在这些 Mac 上使用云端模型。 |
| 私密聊天 | 说“private chat”“don't record this”或“off the record”，该聊天中的任何内容都不会被保存。这些命令在应用的全部 17 种语言中都有效。 |
| 忘记 | 忘记会清除 VOOL 的记忆和对应的运行历史，这样该项就不会再被回想起或列出，并且会从 VOOL 的本地记忆文件及其搜索索引中删除被遗忘的词。VOOL 会把你要求它忘记的词保存在你电脑上的一个简短列表中，以便它能一直拒绝它们。在一个聊天中忘记某件事之后，VOOL 不会在那个聊天中再次接收同一个事实；要再次告诉它，请开始一个新聊天。 |
| 扫描的 PDF | 使用 Mac 内置的文字识别读取，因此仅限 Mac。 |
| 桌面宠物 | 宠物生活在 VOOL 窗口中。把它拖出窗口并不会把它移到桌面上。 |
| 技能宝典 | “浏览技能宝典”会显示为你的确切 VOOL 版本列出的技能，技能安装之前由你审查。“发布到技能宝典”会检查你在自己电脑上制作的技能，然后打开已填好该技能的技能宝典网站；你在那里登录并按 Send，VOOL 本身不发送任何内容。只有技能的文本会被一并发送，所以带有额外文件的技能暂时还无法分享。 |

macOS 的 Developer ID 签名和公证，以及 Linux 的签名校验和，是发布路线上的下一步；目前都不声称已经具备。
