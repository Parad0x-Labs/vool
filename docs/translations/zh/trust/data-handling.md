# 数据处理

## 两种状态

**本地** — 一切都留在这台电脑上。

**云端** — 所选上下文直接发送给所选的提供方。

在你发送任何内容之前，界面上的指示就会显示当前处于哪种状态。

## VOOL 不会做的事

* 不会通过 Parad0x Labs 的基础设施转发你的提示词。
* 不会上传你的工作区。
* 不会把你的密钥发送给它所属提供方以外的任何地方。

## 关于 OpenRouter

你的 OpenRouter 账户仍然属于你。VOOL 使用你的密钥，直接从这台电脑发送请求。
Parad0x 不会转发你的提示词，也不会替你支付用量。真实的 VOOL 用量可能会出现在 VOOL 公开的
OpenRouter 汇总统计中，但不会公开单个提示词或身份信息。

## 遥测

VOOL 不发送任何产品遥测。错误报告只有在你预览并选择发送后才会离开你的电脑；见[错误报告与隐私](bug-reporting.md)。

## 适用你的提供方的条款

在云端模式下，你的数据按照 **提供方自己的** 保留和训练条款到达提供方，而不是按照 VOOL 的条款。请阅读你所选提供方的条款。
