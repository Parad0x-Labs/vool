# 错误报告与隐私

## 内置的错误报告工具

使用应用内的错误报告工具（或 `python -m apps.vool_cli bug-report` 命令行工具）。它绝不会自行发送任何内容——整个流程特意分为三个阶段：

1. **草稿** — 在本地根据最近的日志和诊断信息生成一份报告，并在生成过程中进行脱敏。*“Nothing is sent yet — a local draft is created first.”*
2. **预览** — 你会看到将要发送的 **确切字节**，以及载荷哈希和一份列出已删除内容的脱敏摘要。你不想发送的字段（日志、标记、复现说明、附件）可以删除；任何编辑都会重置批准。
3. **批准** — 发送需要你明确批准这些确切的字节。如果载荷发生变化，批准就不再有效，你必须重新批准。

批准之后，**Open on GitHub** 会在你的浏览器中打开公开的 [vool-reports](https://github.com/Parad0x-Labs/vool-reports) 仓库中一个已填好的报告页面。在那里再读一遍，然后按 Submit。VOOL 本身不发送任何内容，也不需要 GitHub 令牌。**Copy report** 和 **Save a local copy** 完全不需要批准：它们交给你同样经过清理的字节，不会有任何内容离开你的电脑。**My reports** 会列出你的草稿，以及每一份是如何离开的。

## 报告错误的回答

在任何回答下方按 **报告** 或 👎，或者选中错误的部分再按 **报告**。报告只引用那一部分（或整个回答）。除非你勾选该复选框，否则不会包含你的问题。回答的回执会被包含：模型、提供方、token 数、时间，以及运行了哪些步骤，但绝不包含它们的内容。你让 VOOL 遗忘的回答无法被报告。

## 为帮助调查而添加的内容

你电脑的概况：操作系统版本、芯片、内存、GPU，以及本地模型服务器的版本。还有一项简短的健康检查：本地模型服务器是否响应，以及以范围表示的可用磁盘空间。绝不包含你电脑的名称、你的用户名、序列号或网络地址。你可以在预览中删除其中任何一项。

## 脱敏会删除什么

在你看到草稿之前，就会以确定的方式删除：凭据和认证标头、主目录路径和用户名、你电脑的名称、电子邮件、IP 地址、PIN 和一次性验证码、银行卡和银行（IBAN）号码、电话号码、钱包地址、你个人资料中保存的个人信息、带标签的机密以及高熵数据块——最后还会叠加一轮机密扫描。VOOL 无法识别普通句子中输入的名字或私人信息，所以请阅读预览。堆栈跟踪是根据允许列表重建的，而不是原样粘贴。报告中的故障证据 **只包含类型化代码**——绝不包含内部上下文或原因链。

每个被删除的值都会被替换为一个标记。电子邮件、人、主目录文件夹、IP 地址、电话号码、钱包地址、你电脑的名称或你个人资料中的某项信息，在整份报告中都保持同一个编号标记，例如两个不同的地址分别为 `[EMAIL_1]` 和 `[EMAIL_2]`，这样报告读起来依然清楚。每个被删除的密钥、密码、PIN、银行卡或银行号码都显示为 `[SECRET_REMOVED]`，绝不编号。把标记与真实值对应起来的列表只在你处理报告期间保存在 VOOL 的内存中，因此编辑时标记保持不变。它绝不会被保存或发送，并会在你删除报告、闲置一小时后或 VOOL 重启时被丢弃。

## VOOL 绝不会做的事

* 不进行任何形式的自动对外报告。
* 没有藏在某个设置后面待命的遥测管道。
* 安全问题通过仓库[安全策略](https://github.com/Parad0x-Labs/vool/security/policy)中的私密渠道报告——绝不通过公开的 issue。

## 隐私摘要

* 选择本地模型时，提示词和文件都在你的电脑上处理。
* 云端调用使用你提供的、保存在本地的 API 密钥；密钥绝不会随报告一起发送。
* 完整的数据流详情见[数据处理](../trust/data-handling.md)。
