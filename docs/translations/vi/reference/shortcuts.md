# Phím tắt

`⌘` trên macOS, `Ctrl` trên Windows và Linux.

| Thao tác | Phím tắt |
| --- | --- |
| Phiên mới | `⌘ N` |
| Bảng lệnh | `⌘ K` |
| Đổi mô hình | `⌘ M` |
| Bật/tắt bảng không gian làm việc | `⌘ J` |
| Dừng lần chạy hiện tại | `Esc` |
| Cài đặt | `⌘ ,` |
