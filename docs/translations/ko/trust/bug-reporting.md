# 버그 보고와 개인정보

## 내장 버그 보고 도구

앱 안의 버그 보고 도구(또는 `python -m apps.vool_cli bug-report` CLI)를 사용하세요. 이 도구는
스스로 아무것도 보내지 않으며, 흐름은 일부러 세 단계로 되어 있습니다.

1. **초안** — 최근 로그와 진단 정보로 보고서를 로컬에서 만들며, 만드는 동안 개인정보를 가립니다.
   *'아직 아무것도 보내지 않았습니다. 먼저 로컬 초안을 만듭니다.'*
2. **미리보기** — 전송될 **정확한 바이트**를 페이로드 해시, 그리고 무엇을 제거했는지 나열한 가림
   요약과 함께 봅니다. 보내고 싶지 않은 필드(로그, 플래그, 재현 메모, 첨부 파일)는 제거할 수
   있으며, 무엇이든 편집하면 승인이 초기화됩니다.
3. **승인** — 보내려면 그 정확한 바이트에 대한 나의 명시적인 승인이 필요합니다. 페이로드가
   바뀌면 승인은 더 이상 유효하지 않으며 다시 승인해야 합니다.

승인한 뒤 **Open on GitHub**를 누르면 공개 [vool-reports](https://github.com/Parad0x-Labs/vool-reports)
저장소의, 내용이 채워진 보고서 페이지가 브라우저에서 열립니다. 그곳에서 한 번 더 읽고 Submit을
누르세요. VOOL 자체는 아무것도 보내지 않으며, GitHub 토큰도 필요하지 않습니다. **Copy report**와
**Save a local copy**는 승인이 전혀 필요하지 않습니다. 같은 정리된 바이트를 건네줄 뿐이며 아무것도
내 컴퓨터 밖으로 나가지 않습니다. **My reports**는 내 초안과 각 초안이 어떻게 나갔는지 보여
줍니다.

## 잘못된 답변 신고하기

답변 아래의 **신고** 또는 👎를 누르거나, 잘못된 부분을 강조 표시하고 **신고**를 누르세요.
보고서에는 그 부분(또는 답변 전체)만 인용됩니다. 내 질문은 확인란을 선택하지 않으면 빠집니다.
답변의 영수증이 포함됩니다. 모델, 공급자, 토큰, 시간, 그리고 어떤 단계가 실행되었는지가 들어가며,
그 단계의 내용은 절대 들어가지 않습니다. VOOL에 잊으라고 한 답변은 신고할 수 없습니다.

## 조사를 돕기 위해 추가되는 정보

내 컴퓨터의 구성: OS 버전, 칩, 메모리, GPU, 로컬 모델 서버 버전. 그리고 짧은 상태 점검: 로컬 모델
서버가 응답하는지, 그리고 범위로 표시한 남은 디스크 공간. 컴퓨터 이름, 사용자 이름, 일련번호,
네트워크 주소는 절대 들어가지 않습니다. 미리보기에서 이 중 무엇이든 제거할 수 있습니다.

## 가림 처리로 제거되는 것

초안을 보기도 전에, 결정론적으로 제거됩니다. 자격 증명과 인증 헤더, 홈 경로와 사용자 이름, 컴퓨터
이름, 이메일, IP 주소, PIN과 일회용 코드, 카드 및 은행(IBAN) 번호, 전화번호, 지갑 주소, 프로필에
저장된 개인 정보, 이름표가 붙은 비밀 정보, 엔트로피가 높은 데이터 덩어리이며, 그 위에 마지막
비밀 정보 검사 단계가 한 겹 더 있습니다. VOOL은 일반 문장에 입력된 이름이나 사적인 사실은 알아보지
못하므로, 미리보기를 읽어 보세요. 스택 추적은 원문 그대로 붙이지 않고 허용 목록을 바탕으로 다시
구성합니다. 보고서의 결함 증거에는 **유형이 정해진 코드만** 들어가며, 내부 컨텍스트나 원인 사슬은
절대 들어가지 않습니다.

제거된 값은 각각 표시로 바뀝니다. 이메일, 사람, 홈 폴더, IP 주소, 전화번호, 지갑 주소, 컴퓨터
이름, 프로필의 정보는 보고서 전체에서 같은 번호의 표시 하나를 유지합니다. 예를 들어 서로 다른 두
주소는 `[EMAIL_1]`과 `[EMAIL_2]`가 되므로, 보고서를 여전히 분명하게 읽을 수 있습니다. 제거된 키,
암호, PIN, 카드 번호, 은행 번호는 모두 번호 없이 `[SECRET_REMOVED]`로 표시됩니다. 표시와 실제 값을
연결하는 목록은 내가 보고서를 작업하는 동안 VOOL의 작업 메모리(RAM)에만 있으므로, 편집해도 같은
표시가 유지됩니다. 이 목록은 절대 저장되거나 전송되지 않으며, 보고서를 삭제할 때, 한 시간 동안
쓰지 않을 때, 또는 VOOL이 다시 시작될 때 잊힙니다.

## VOOL이 절대 하지 않는 일

* 어떤 종류든 자동으로 외부에 보고하지 않습니다.
* 설정 뒤에서 대기하는 텔레메트리 파이프라인은 없습니다.
* 보안 문제는 저장소의 [보안 정책](https://github.com/Parad0x-Labs/vool/security/policy)에 있는
  비공개 채널로 보고하며, 공개 이슈로는 절대 보고하지 않습니다.

## 개인정보 요약

* 로컬 모델을 선택하면 프롬프트와 파일이 내 컴퓨터에서 처리됩니다.
* 클라우드 호출은 내가 제공해 로컬에 저장된 API 키를 사용하며, 키는 보고서에 절대 실리지
  않습니다.
* 데이터 흐름의 자세한 내용은 [데이터 처리](../trust/data-handling.md)에 있습니다.
