# 데이터 처리

## 두 가지 상태

**로컬** — 모델과 파일은 이 컴퓨터에 머뭅니다. 날씨나 가격 같은 실시간 정보는 '웹 검색'이 켜져 있을 때만(새로 설치하면 꺼져 있습니다) 공개 웹 서비스에서 가져오며, '로컬 전용'에서는 절대 가져오지 않습니다.

**클라우드** — 선택한 컨텍스트가 선택한 공급자에게 바로 전송됩니다.

다음 요청이 어느 방식으로 실행되는지는 채팅 헤더에 표시됩니다. 예를 들어 VOOL Auto가 이 컴퓨터에서 답할 때는 **자동**과 **로컬 우선**이 표시됩니다.

## VOOL이 하지 않는 일

* 프롬프트를 Parad0x Labs 인프라를 거쳐 전달하지 않습니다.
* 작업 공간을 업로드하지 않습니다.
* 키를 그 키가 속한 공급자 외에는 어디에도 보내지 않습니다.

## OpenRouter의 경우

OpenRouter 계정은 계속 내 것입니다. VOOL은 내 키를 사용해 이 컴퓨터에서 바로
요청을 보냅니다. Parad0x는 프롬프트를 중계하지도, 사용 요금을 대신 내지도 않습니다. 실제 VOOL
사용량은 OpenRouter에서 공개되는 VOOL의 집계 통계에 나타날 수 있지만, 개별 프롬프트와
신원은 공개되지 않습니다.

## 텔레메트리

VOOL은 제품 텔레메트리를 보내지 않습니다. 버그 보고서는 직접 미리 보고
보내기를 선택했을 때만 내 컴퓨터 밖으로 나갑니다. [버그 보고와 개인정보](bug-reporting.md)를 참고하세요.

## 공급자의 약관이 적용됩니다

클라우드 모드에서는 데이터가 VOOL이 아니라 **공급자의** 보관 및 학습 약관에 따라
공급자에게 전달됩니다. 선택하는 공급자의 약관을 읽어 보세요.
