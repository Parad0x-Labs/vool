# 보안 모델

## 경계

* **폴더 제한**이 파일 접근 범위를 정합니다. VOOL은 채팅의 프로젝트 폴더에서 파일을 읽고 바꿉니다.
  그 밖에서는 보이는 홈 폴더를 읽을 수 있고, 파일 변경은 데스크탑, 다운로드, 문서에서만 할 수
  있습니다. 숨김 폴더, 앱 및 시스템 데이터, VOOL 자체의 데이터는 절대 읽지 않습니다.
  [작업 공간](../concepts/workspaces.md)을 참고하세요.
* **자격 증명 저장소**가 키를 보관합니다. 키는 구성 파일이나 로그에 기록되지 않습니다.
* **도구 확인**이 변경 범위를 정합니다. 수동 모드에서는 모든 변경 전에 먼저 묻고, 자동 모드에서는
  일상적인 편집과 명령이 자동으로 실행될 수 있지만 삭제, 덮어쓰기, 설치, 지출, 설정 변경은 여전히
  묻습니다. [도구](../concepts/tools.md)를 참고하세요.

## 내 로컬 네트워크

VOOL은 기본적으로 이 컴퓨터에서 오는 연결만 받습니다. 로컬 네트워크에서도 연결을 받도록
설정하면, 이 컴퓨터만 나로 취급됩니다. 설정, 파일, 키, 도구, 비공개 기능은 이 컴퓨터에만
응답합니다.

네트워크의 다른 기기는 일반 채팅만 할 수 있습니다. 한 번에 공개 웹 페이지 하나를 읽을 수도
있습니다. 그 페이지는 공개 인터넷에 있어야 합니다. 이 컴퓨터나 로컬 네트워크의 주소는 거부되며,
리디렉션도 하나하나 같은 방식으로 확인됩니다. 웹 검색, 리서치, 브라우저, 견적, 결제, 내 유료
키는 이 컴퓨터에서만 작동합니다.

## Discord 브리지

Discord 브리지는 소유자에게만 응답합니다. 브리지에 처음 명령을 보낸 Discord 사용자가 소유자가
됩니다. 소유자를 직접 정하려면 `VOOL_DISCORD_OWNER_USER_ID`를 내 Discord 사용자 ID로 설정하세요.
다른 사람이 글을 쓸 수 있는 채널이라면 어디서든 이렇게 하세요. 다른 모든 사람에게는 이 VOOL이
소유자 전용으로 잠겨 있다고 한 번 알리며, 그들의 메시지는 처리하지 않습니다. 소유자의 Discord
메시지에도 네트워크의 다른 기기와 같은 제한이 적용됩니다.

## 키

VOOL은 공급자 키를 이 컴퓨터에 있는 런타임 홈의 암호화된 파일에 보관하며
([구성](../reference/configuration.md) 참고), 이 파일은 내 사용자 계정만 읽을 수 있습니다. Mac에서
VOOL이 이미 macOS 키체인에 보관하던 키는 계속 그곳에서 읽을 수 있습니다. 키는 내 컴퓨터에서 내
공급자에 접속하는 데 사용됩니다. 키는 Parad0x Labs로 보내지지 않으며, 요청 경로에 Parad0x가
운영하는 엔드포인트는 없습니다.

{% hint style="info" %}
암호화된 파일은 별도의 암호가 아니라 내 사용자 계정의 파일 권한으로 보호됩니다. 디스크를
잃어버리거나 도난당해도 키가 노출되지 않도록 디스크 암호화(Mac에서는 FileVault)를 켜 두세요.
{% endhint %}

## 플러그인

플러그인은 런타임과 같은 접근 권한으로 실행됩니다. 그 점이 플러그인을 유용하게 만들고, 설치하기
전에 읽어 볼 가치가 있게 만듭니다. [스킬과 플러그인](../guides/skills-and-plugins.md)을
참고하세요.

## 문제 보고

보안 문제는
[GitHub Security Advisories](https://github.com/Parad0x-Labs/vool/security/advisories/new)를
통해 비공개로 보고하고, 공개 이슈로는 절대 보고하지 마세요. 버전, 플랫폼, 재현 단계를
포함하세요.

{% hint style="warning" %}
macOS 앱은 ad-hoc 서명만 되어 있고 Apple 공증을 받지 않았으며, Linux tarball은 서명되지
않았습니다. [릴리스 상태](release-status.md)를 참고하세요.
{% endhint %}
