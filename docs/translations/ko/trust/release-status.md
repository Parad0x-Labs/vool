# 릴리스 상태

이 페이지는 관리되는 릴리스 상태의 기준 문서입니다. 다른 문서들도 지나가며 릴리스 사실을
언급하지만, 이 페이지와 다를 때는 이 페이지가 우선합니다.

## 현재 단계

VOOL은 **베타** 단계입니다. 현재 릴리스는
[**v0.7.7-beta**](https://github.com/Parad0x-Labs/vool/releases/tag/v0.7.7-beta)로, `main`의
`8af687c`에서 빌드된 GitHub 릴리스입니다. 세 플랫폼용 앱 다운로드가 있으며, 각각 SHA-256
체크섬이 게시되어 있습니다. 부트스트랩 스크립트로 소스에서 설치하는 방법도 macOS, Linux,
Windows에서 계속 지원됩니다. [설치](../getting-started/install.md)를 참고하세요.

| 다운로드 | 대상 |
| --- | --- |
| `VOOL-0.7.7-beta-macos-arm64.dmg` | Apple Silicon Mac, macOS 14 이상 |
| `VOOL-0.7.7-beta-macos-x86_64.dmg` | Intel Mac, macOS 14 이상 |
| `vool-0.7.7-beta-linux-x86_64.tar.gz` | Linux x86_64, Ubuntu 22.04와 24.04에서 테스트됨 |

이 저장소의 릴리스 기록은 GitHub 채널을 다룹니다. 다른 다운로드 채널은 별도로 운영되므로, 어떤
다운로드든 GitHub 릴리스에 게시된 체크섬과 대조해 확인하세요.

| | 상태 |
| --- | --- |
| 공개 다운로드 | v0.7.7-beta GitHub 릴리스의 macOS Apple Silicon DMG, macOS Intel DMG, Linux x86_64 tarball |
| 게시된 체크섬 | 모든 다운로드의 SHA-256, 릴리스에 게시 |
| 코드 서명 | macOS 앱은 Developer ID가 아니라 ad-hoc 서명입니다. 서명은 이 베타 이후에 추가되며, 이 베타의 조건이 아닙니다 |
| macOS 공증 | Apple 공증을 받지 않았습니다. 처음 열 때 macOS가 확인을 요청합니다(아래 참고) |
| Windows | 이번 릴리스에는 Windows용 다운로드가 없습니다. Windows는 소스에서 설치하며 실험적입니다 |
| 업데이트 | 0.7.5부터 VOOL은 스스로 업데이트합니다. '스스로 온라인 연결'이 켜져 있으면 알림을 표시하고 한 번 눌러 새 버전을 설치합니다. Mac에서 0.7.4나 0.7.3에서 업데이트하는 경우: '스스로 온라인 연결'(설정 > 개인정보와 권한)을 켜고 '업데이트 확인'을 한 번 누르세요. Linux에서, 또는 0.7.2, 0.7.1, 0.7.0에서 업데이트하는 경우: 0.7.7을 내려받아 현재 버전 위에 설치하세요. 채팅과 설정은 앱 바깥의 프로필에 저장됩니다. [업데이트와 마이그레이션](../reference/updates-migration.md)을 참고하세요 |
| API 안정성 | 빌드마다 바뀜 |

## 이것이 의미하는 것

* Mac 앱을 처음 실행하면 Apple 공증을 받지 않았기 때문에 macOS가 열기를 거부합니다. 이 단계에서는
  예상된 동작이며, 다운로드가 손상되었다는 뜻이 아닙니다. 체크섬을 확인한 다음
  **시스템 설정 → 개인정보 보호 및 보안**을 열고 **그래도 열기**를 클릭하세요. macOS 14에서는
  대신 앱을 Control-클릭하고 **열기**를 선택해도 됩니다.
* 내 칩에 맞는 Mac 다운로드를 고르세요. Apple Silicon 앱은 Intel Mac에서 실행되지 않으며, 실행할
  때 그렇다고 알려 줍니다.
* 구성 형식은 빌드마다 바뀔 수 있습니다.
* 암호화폐 기능은 내가 켜기 전까지 꺼져 있습니다.

## 베타와 파일럿의 제한 사항, 명시적으로

| 기능 | 이 빌드에서의 상태 |
| --- | --- |
| 암호화폐와 지갑 | 기본적으로 꺼져 있습니다. 켜면 VOOL은 Mainnet을 사용하며, 테스트넷은 개발자 옵션에 있습니다. 모든 결제는 VOOL의 지갑을 거치며, 지갑의 한도, 나의 승인, 영수증이 따릅니다. [지갑](../guides/wallet.md)을 참고하세요. |
| Mainnet 송금 | 네이티브 코인, 그리고 Solana, Ethereum, BNB Smart Chain, Arbitrum One의 USDT를, 이 기기에서 만든 VOOL 지갑에서 보냅니다. Solana와 Base의 USDC는 결제 채널 전용입니다. 연결된 계정이나 보기 전용 계정은 받을 수 있고 잔액을 보여 줄 수 있지만 VOOL에서 보낼 수는 없습니다. |
| x402로 결제 | Base 또는 Base Sepolia에서 USDC로 x402 결제를 요구하는 웹사이트는 내 Crypto Pilot 지갑에서 결제할 수 있습니다. 내 한도 안에서 PIN으로 한 번 승인하면 됩니다. 네트워크 수수료는 웹사이트의 결제 서비스가 부담합니다. **설정 → 암호화폐 → Payment channels**에는 지갑이 웹사이트에 결제할 수 있는 방법마다 켜기/끄기 스위치가 있으며, 꺼진 채널은 무엇이든 서명되기 전에 거부합니다. 이 방식으로 실제 Mainnet 결제가 이루어진 적은 아직 없습니다. Solana pay-kit을 통한 결제는 다운로드에 포함되어 있지 않으며, 그 채널은 사용할 수 없음으로 표시됩니다. |
| X | 어느 채팅에서든 게시물과 계정, Spaces, 트렌드, DM을 검색하고, 토큰에 대한 과거 콜을 조회할 수 있습니다. 내 계정으로 무언가를 하는 동작은 나의 확인을 기다립니다. |
| 받아쓰기 | 이 베타 빌드에서는 일시적으로 사용할 수 없으며, 업데이트에서 돌아옵니다. |
| 클라우드 '버스트' 질문 모드 | 이 빌드에서는 호출마다 묻는 확인 창이 아직 연결되지 않았습니다. |
| 로컬 모델 | 로컬 모델이 답변하려면 먼저 **설정 → 모델과 공급자 → 로컬 모델**을 열고 해당 모델의 **Certify**를 한 번 누르세요. |
| Intel Mac | 로컬 모델이 프로세서에서 실행되어 느립니다. 인증은 느린 프로세서를 감안하지만 메모리를 쓰는 긴 답변은 시간 초과될 수 있으니, 당분간은 그곳에서 클라우드 모델을 사용하세요. |
| 비공개 채팅 | 'private chat', 'don't record this', 'off the record'라고 말하면 그 채팅에서는 아무것도 저장되지 않습니다. 이 명령은 앱의 17개 언어 모두에서 작동합니다. |
| 잊기 | 잊기는 VOOL의 메모리와 그에 해당하는 실행 기록을 지워 그 항목이 다시 떠오르거나 나열되지 않게 하고, 잊은 단어를 VOOL의 로컬 메모리 파일과 검색 색인에서 지웁니다. VOOL은 잊으라고 한 단어를 내 컴퓨터의 짧은 목록에 보관해 계속 거부할 수 있게 합니다. 채팅에서 무언가를 잊게 한 뒤에는, VOOL은 그 채팅에서 같은 사실을 다시 받아들이지 않습니다. 다시 알려 주려면 새 채팅을 시작하세요. |
| 스캔한 PDF | Mac 내장 텍스트 인식으로 읽으므로 Mac에서만 됩니다. |
| 바탕화면 애완동물 | 애완동물은 VOOL 창 안에 삽니다. 창 밖으로 끌어내도 바탕화면으로 옮겨지지 않습니다. |
| 스킬 코덱스 | 스킬 코덱스 탐색은 내 VOOL 버전에 정확히 맞게 등록된 스킬을 보여 주며, 스킬은 설치 전에 내가 검토합니다. 스킬 코덱스에 게시는 내 컴퓨터에서 만든 스킬을 확인한 다음, 그 스킬이 채워진 스킬 코덱스 웹사이트를 엽니다. 그곳에서 로그인하고 Send를 누르면 되며, VOOL 자체는 아무것도 보내지 않습니다. 스킬의 텍스트만 함께 가므로, 추가 파일이 있는 스킬은 아직 공유할 수 없습니다. |

macOS용 Developer ID 서명과 공증, Linux용 서명된 체크섬은 릴리스 경로의 다음 단계이며, 지금은 둘
다 주장하지 않습니다.
