# 모델 연결

VOOL에는 모델이 포함되어 있지 않습니다. 직접 하나를 고르며, 그 선택에 따라 요청이
내 컴퓨터에 머무를지 밖으로 나갈지가 정해집니다.

## 로컬

로컬 런타임이 설치되어 실행 중이면 VOOL이 이를 감지하고 모델 목록을 보여 줍니다.
그중 하나를 선택하면 표시가 로컬로 바뀝니다. 설정에 관한 자세한 내용은
[로컬 모델 실행](../../../guides/local-models.md)에 있습니다.

## 클라우드

**설정 → API 키**에서 공급자 키를 추가하세요. 키는 이 컴퓨터의 암호화된 파일에
보관되며([보안 모델](../../../trust/security.md#keys) 참고),
**내 컴퓨터에서 공급자로 바로** 요청을 보내는 데 사용됩니다.

클라우드 모델을 선택하면 표시에 공급자 이름이 나타나며, 표시는 요청이 이루어지기 전에
바뀝니다.

OpenRouter에 해당하는 절차는 [OpenRouter 연결](../../../guides/openrouter.md)을 참고하세요.

## 전환

모델을 바꾸면 모드도 바뀝니다. 표시가 기준입니다. 로컬로 표시되어 있으면
다음 요청은 이 컴퓨터에서 처리됩니다.
