# 처음 실행

처음 실행하면 짧은 질문 네 개가 나옵니다. 어느 질문이든 건너뛸 수 있고, 모든 답은 나중에
바꿀 수 있습니다. 답하는 동안에는 아무것도 어디로도 전송되지 않습니다. 단, 클라우드 키를 추가하면
그 키를 해당 공급자에게 확인하는 과정만 예외입니다.

## 진행 과정

1. **어디서 생각할까요?** 로컬 모델로 이 컴퓨터에서, 또는 요금을 내는 공급자의 키로
   온라인에서. [모델 연결](connect-a-model.md)을 참고하세요.
2. **폴더 고르기.** VOOL이 작업할 프로젝트 폴더입니다.
   [작업 공간](../../../concepts/workspaces.md)을 참고하세요.
3. **혼자서 뭘 할 수 있나요?** VOOL이 무언가를 바꾸기 전에 얼마나 자주 멈추고 물어볼지 정합니다.
   [도구](../../../concepts/tools.md)를 참고하세요.
4. **뭐라고 불러야 할까요?** 선택 사항입니다. 이름이나 별명이면 충분하며, 이 정보는 이 컴퓨터에
   남습니다.

이후 모드 표시에는 로컬, 자동 또는 클라우드 공급자 이름이 나타나며, 현재 선택된 모델을
반영합니다.

**로컬 모델을 한 번 인증하세요.** 로컬 모델이 답변하려면 먼저
**설정 → 모델과 공급자 → 로컬 모델**을 열고 해당 모델의 **Certify**를 누르세요. 내 컴퓨터에서
짧은 검사가 실행됩니다.

## 처음 실행할 때 VOOL이 하지 않는 일

* 계정을 만들지 않습니다.
* 클라우드 키를 요구하지 않습니다. 앱을 쓰는 데는 로컬 모델이면 충분합니다.
* 드라이브를 색인하지 않습니다. 요청에 필요할 때만 파일을 읽습니다. 접근할 수 있는 폴더는
  [작업 공간](../../../concepts/workspaces.md)을 참고하세요.

{% hint style="info" %}
채팅 사이드바의 **+ 프로젝트**로 언제든지 다른 프로젝트 폴더를 고를 수 있습니다.
{% endhint %}
