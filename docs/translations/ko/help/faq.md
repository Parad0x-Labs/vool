# FAQ

## VOOL은 오프라인에서 작동하나요?

네, 로컬 모델을 쓰면 채팅과 파일에 대해서는 작동합니다. 클라우드 모델은 정의상 네트워크 연결이 필요합니다. 날씨나 가격 같은 실시간 정보는 '웹 검색'이 켜져 있을 때만(새로 설치하면 꺼져 있습니다) 공개 웹 서비스에서 가져오며, '로컬 전용'에서는 절대 가져오지 않습니다.

## 클라우드 키가 필요한가요?

아니요. 앱을 쓰는 데는 로컬 모델이면 충분합니다.

## 내 키는 어디에 저장되나요?

내 컴퓨터에 있는 VOOL 런타임 홈의 암호화된 파일에 저장되며, 내 사용자 계정만 읽을 수 있습니다.
Mac에서 VOOL이 이미 macOS 키체인에 보관하던 키는 그곳에 남습니다. 키는 내 컴퓨터에 머뭅니다.
[보안 모델](../trust/security.md#키)을 참고하세요.

## Parad0x가 내 프롬프트를 보나요?

로컬 모드에서는 보지 않으며, 클라우드 모드에서도 보지 않습니다. 클라우드 요청은 내 컴퓨터에서 내
공급자에게 바로 갑니다. [데이터 처리](../trust/data-handling.md)를 참고하세요.

## 앱을 열 때 시스템이 왜 경고하나요?

macOS 앱은 ad-hoc 서명은 되어 있지만 아직 Apple 공증을 받지 않아서, 처음 열 때 macOS가 확인을
요청합니다. 방법은 [설치](../getting-started/install.md#mac에서-처음-열기)에 있습니다.
[릴리스 상태](../trust/release-status.md)를 참고하세요.

## 내 모델을 쓸 수 있나요?

네. OpenAI 호환 로컬 엔드포인트를 제공하는 런타임이면 무엇이든 됩니다.
[지원 모델](../reference/models.md)을 참고하세요.

## 무료인가요?

애플리케이션은 베타 기간 동안 무료입니다. 클라우드 모델 사용료는 내 공급자가 내 계정으로
청구합니다.
