# 문제 해결

## macOS가 앱을 열지 않을 때

예상된 동작입니다. 앱은 아직 공증을 받지 않았습니다. 먼저 체크섬을 확인한 다음
**시스템 설정 → 개인정보 보호 및 보안**을 열고 **그래도 열기**를 클릭하세요. macOS 14에서는
대신 VOOL을 Control-클릭하고 **열기**를 선택해도 됩니다.

## Windows

이번 릴리스에는 Windows용 다운로드가 없습니다. Windows에서는 소스에서 설치하며,
실험적 지원입니다. [설치 안내](../getting-started/install.md#소스에서-설치)를 참고하세요.

## 로컬 모델이 목록에 없을 때

1. 런타임이 실행 중인지 확인합니다.
2. 모델을 하나 이상 내려받았는지(pull) 확인합니다.
3. 포트가 VOOL이 기대하는 포트와 같은지 확인합니다.

```bash
curl http://localhost:11434/api/tags
```

아무것도 반환되지 않으면 런타임이 실행되지 않은 것입니다.

## 응답이 느릴 때

대개 사용 가능한 메모리에 비해 모델이 큰 경우입니다.
[로컬 모델 실행](../../../guides/local-models.md)을 참고하세요.

## 처음부터 다시 시작

VOOL을 종료하고 [구성](../../../reference/configuration.md)에 나와 있는 구성 디렉터리를
삭제하세요. 작업 공간의 파일은 건드리지 않습니다.
