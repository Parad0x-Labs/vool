# 작업 공간

작업 공간은 채팅이 작업하는 프로젝트 폴더입니다. VOOL은 그 안의 파일을 읽고 바꾸며,
작동 모드가 요구할 때마다 먼저 묻습니다([도구](tools.md) 참고).

## 추가와 제거

폴더 고르기는 채팅의 **프로젝트 폴더 선택…** 또는 채팅 사이드바의 **+ 프로젝트**로 합니다.
프로젝트를 삭제하면 VOOL은 그 안에서 배운 것을 잊고, 그 프로젝트의 채팅을 다시 '일반'으로
옮깁니다. 내 파일은 건드리지 않습니다.

## 다른 폴더

작업 공간 밖에서도 VOOL의 파일 도구는 정해진 제한 안에서 홈 폴더에 접근할 수 있습니다.

| 폴더 | VOOL이 할 수 있는 일 |
| --- | --- |
| 데스크탑, 다운로드, 문서 | 읽기, 그리고 작동 모드에 따라 먼저 물은 뒤 파일 변경 |
| 사진, 동영상(Linux에서는 비디오), 음악 | 읽기만: 목록 보기, 찾기, 열기, 크기 재기. 변경은 절대 하지 않음 |
| `~/Projects` 같은 그 밖의 보이는 홈 폴더 | 읽기만 |
| 숨김 폴더(`~/.ssh` 등), 앱 및 시스템 데이터(`Library`, `Applications`, `AppData`), VOOL 자체의 데이터 폴더 | 절대 접근하지 않음 |

VOOL은 요청에 필요할 때만 이 폴더들을 살펴봅니다. 예를 들어 '내 세금 PDF 찾아 줘'나
'동영상에서 가장 큰 영상은 뭐야' 같은 요청입니다. 백그라운드에서 드라이브를 색인하지 않습니다.

## 범위 정하기 조언

* 작업 공간은 홈 디렉터리가 아니라 프로젝트를 가리키게 하세요.
* 자격 증명 파일, 키 자료, 암호 저장소는 데스크탑, 다운로드, 문서나 프로젝트 폴더에 흩어 두지
  말고 암호 관리자나 숨김 폴더에 보관하세요.
* 작업마다 별도의 프로젝트를 사용해 한 작업의 컨텍스트가 다른 작업에 닿지 않게 하세요.

{% hint style="warning" %}
클라우드 모델이 선택되어 있으면, VOOL이 읽는 모든 것은 프로젝트 폴더에 있든 홈 폴더에 있든
공급자에게 보내는 내용에 포함될 수 있습니다. 범위를 신중하게 정하세요.
{% endhint %}
