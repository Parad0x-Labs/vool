# 권한

VOOL은 무엇이든 실행하기 전에 무엇을 실행해도 되는지 결정합니다. 모델은 동작을 요청할 수 있지만,
그 동작이 일어날지는 내가 고른 모드와 내 답이 결정합니다. 읽기는 변경과 다르게 다루며, 비밀
정보, 결제, 보안 설정은 모든 모드에서 보호됩니다.

## 모드

메시지 입력란 옆의 메뉴에서 모드를 고르세요. 새 채팅은 **수동** 모드로 시작합니다.

| 모드 | 묻지 않고 실행 | 먼저 물음 | 절대 하지 않음 |
| --- | --- | --- | --- |
| 수동 | 파일 읽기와 목록 보기, 안전한 명령, 공개 웹의 읽기 전용 조회 | 모든 변경: 파일 편집, 명령, 네트워크 동작, 설정, Git, 배포, 메시지 | 저장된 비밀 정보 읽기 |
| 편집 검토 | 수동과 같음 | 수동과 같음. 편집 묶음마다 적용 전에 검토할 수 있는 변경으로 표시 | 저장된 비밀 정보 읽기 |
| 계획 | 파일 읽기와 목록 보기, 안전한 명령 | 없음: 읽기만 하고 계획을 제안 | 모든 변경, 모든 네트워크 동작 |
| 자동 | 파일 읽기, 생성, 편집, 명령, 네트워크와 브라우저 동작, 모델 공급자 | 삭제, 기존 파일 덮어쓰기, 의존성 설치, 공급자 설정 변경, Git 커밋·푸시·병합·리셋, 배포, 메시지 보내기, 결제, 설정 변경 | 저장된 비밀 정보 읽기, 보안 설정 변경, VOOL이 효과를 알 수 없는 모든 동작 |
| 권한 바이패스 | 보호되는 네 가지 범주를 제외한 모든 것 | 결제 | 저장된 비밀 정보 읽기, 보안 설정 변경, VOOL이 효과를 알 수 없는 모든 동작 |

모드, 스킬, 플러그인은 제공되는 것을 좁힐 수만 있습니다. 그중 어느 것도 모드가 허용하지 않는
동작을 허용하지 않습니다.

## 권한 요청에 답하기

동작에 내 답이 필요하면 메시지 입력란 위에 **권한 필요** 막대가 열립니다. 막대는 정확한 동작을
보여 줍니다. 실행될 명령줄, 또는 바뀔 파일, 그 변경을 되돌릴 수 있는지, 그리고 편집 미리보기입니다.
내가 답할 때까지 아무것도 실행되지 않으며, VOOL이 다시 시작되어도 요청은 나를 기다립니다. 시간이
지난 요청은 만료됨으로 표시되며 승인할 수 없습니다.

막대는 그 동작에 맞는 선택지만 보여 줍니다.

| 버튼 | 허용하는 것 |
| --- | --- |
| 한 번만 허용 | 이 정확한 동작 하나. |
| 이 작업에 대해 허용 | 이 작업 동안 같은 모드에서 같은 정확한 동작을 다시. 파일 편집이 아닌 동작에 제공됩니다. |
| 이 요청의 계획된 변경 *N*건 모두 허용 | 이 요청이 이미 계획한 파일 변경, 즉 세부사항 검토에 나열된 정확한 파일들뿐이며, 그 밖에는 아무것도 없습니다. |
| 이 채팅에서 작업 공간 편집 허용 | 이 채팅의 작업 공간 안에서의 읽기, 새 파일, 편집. 여덟 시간 동안, 또는 VOOL이 다시 시작되거나 채팅이 삭제될 때까지. |
| 이 프로젝트에서 허용 | 프로젝트 폴더 안에서의 읽기와 파일 쓰기. 프로젝트에 계속 유지되며, 다시 시작한 뒤와 새 채팅에서도 적용됩니다. |
| 세부사항 검토 | 결정하기 전에 전체 요청을 보여 줍니다. |
| 거부 | 동작이 실행되지 않습니다. |

무엇을 허용하든, 삭제, 이동, 덮어쓰기, 명령, 네트워크 동작, 비밀 정보, 결제는 모드 자체가 허용하지
않는 한 매번 따로 묻습니다.

## 권한 바이패스

바이패스는 내가 고른 범위 안에서, 내가 고른 시간 동안, 사용 가능한 도구를 하나하나 묻지 않고
실행합니다.

* **범위:** 현재 작업만, 이 채팅 세션, 또는 이 프로젝트.
* **지속 시간:** 15분 또는 30분, 1, 2, 4 또는 8시간, 15분에서 1440분 사이의 사용자 지정 길이,
  또는 이 채팅에만 적용되는 *내가 끌 때까지*.

시간제 바이패스는 어느 채팅에서나 작동합니다. *내가 끌 때까지*를 쓰려면 채팅이 프로젝트 폴더에
연결되어 있어야 하며, 그 폴더는 홈 폴더 전체, 디스크 최상위, 또는 VOOL 자체의 데이터가 있는
폴더일 수 없습니다. 바이패스가 켜져 있는 동안 배너에 범위와 끝나는 시점이 표시되고, 배너의
**×**를 누르면 즉시 꺼지며 채팅은 수동 모드로 돌아갑니다. 채팅을 삭제해도 그 채팅의 바이패스가
끝납니다. 바이패스는 작업 공간 밖의 접근을 절대 허용하지 않으며, 모델이 스스로 자기 권한을
넓히게 할 수 없습니다. 결제는 여전히 묻고, 비밀 정보와 보안 설정에는 계속 닿을 수 없습니다.

## 결제와 지출

동작을 승인해도 결제는 절대 승인되지 않습니다. 결제는 모든 모드에서 지갑 자체의 제안과 승인 절차를
거치며, 지갑의 한도가 적용됩니다. 유료 모델 호출은 공급자에게 연락하기 전에 내 지출 한도와 가격
안전장치의 통제를 받습니다. [지갑](../guides/wallet.md)과
[지출 한도와 가격 안전장치](../guides/spending-limits.md)를 참고하세요.

## 동작이 거부될 때

거부된 동작은 아무것도 바꾸지 않았으며, 메시지에 무엇이 왜 거부되었는지 나옵니다. 볼 수 있는
코드는 [`permission_denied`](../ERROR_BOOK.md#permission-denied), 허용된 폴더 밖의 변경에 대한
[`confinement_refusal`](../ERROR_BOOK.md#confinement-refusal), 이 모드가 제공하지 않는 도구에
대한 [`tool_unavailable`](../ERROR_BOOK.md#tool-unavailable)입니다.
[오류와 오류 코드](../reference/errors.md)를 참고하세요.
