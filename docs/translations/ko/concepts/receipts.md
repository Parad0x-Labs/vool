# 영수증

영수증은 실행에 대한 지속되는 기록입니다. 어떤 도구가 어떤 입력으로 호출되었고, 각각 무엇을
돌려주었는지 남깁니다.

## 영수증이 있는 이유

에이전트가 자기 작업을 요약한 것은 주장일 뿐입니다. 영수증은 그 주장을 대조해 확인할 수 있는
기록입니다.

## 영수증에 담기는 것

| 필드 | 의미 |
| --- | --- |
| `tool` | 실행된 동작 |
| `input` | 받은 입력 |
| `result` | 돌려준 결과 |
| `time` | 실행된 시각 |

영수증은 프로젝트 폴더가 아니라 이 컴퓨터에 있는 VOOL의 런타임 홈에 보관됩니다
([구성](../reference/configuration.md) 참고). 영수증이 내 컴퓨터 밖으로 나가는 것은 내가 미리 보고
보내기로 선택한 버그 보고서 안에 들어 있을 때뿐입니다
([버그 보고와 개인정보](../trust/bug-reporting.md) 참고).
