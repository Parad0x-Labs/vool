# 로컬과 클라우드

VOOL에는 두 가지 상태가 있습니다. 어느 쪽이 활성 상태인지 인터페이스에 항상 표시됩니다.

## 로컬

모든 것이 이 컴퓨터에 머뭅니다. 모델은 로컬 런타임에서 실행되고, 파일은 디스크에서 읽으며,
공급자에게는 어떤 요청도 보내지 않습니다.

## 클라우드(공급자 이름)

선택한 컨텍스트가 내 컴퓨터에서 내 키를 사용해 선택한 공급자에게 바로 전송됩니다.

'선택한 컨텍스트'란 앱이 그 요청을 위해 모은 것을 말합니다. 내 프롬프트에 더해, 요청에 필요한
파일과 이전 턴입니다. 보내기 전에 표시됩니다.

{% hint style="danger" %}
클라우드 모드는 데이터를 내 컴퓨터 밖으로 보냅니다. 그것이 클라우드 모드의 목적입니다. VOOL이
말하는 것은 *경로*에 관한 것입니다. 요청은 내 컴퓨터에서 내 공급자에게 갑니다. 아무것도
전송되지 않는다는 말이 아닙니다.
{% endhint %}

## 그 사이에 있는 것

Parad0x Labs가 운영하는 것은 아무것도 없습니다. 모델 트래픽을 위한 프록시도, 게이트웨이도,
중계 서버도 없습니다. 내 키는 내 컴퓨터의 앱이 공급자와 직접 통신하는 데 사용합니다.
