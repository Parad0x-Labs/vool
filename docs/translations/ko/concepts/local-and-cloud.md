# 로컬과 클라우드

VOOL은 두 가지 방식으로 답할 수 있습니다. 이 컴퓨터에서 답하거나, 클라우드 공급자를 통해 답합니다. 다음 요청이 어느 방식으로 실행되는지는 채팅 헤더에 표시됩니다. 예를 들어 VOOL Auto가 이 컴퓨터에서 답할 때는 **자동**과 **로컬 우선**이 표시됩니다.

## 로컬

모델과 파일은 이 컴퓨터에 머뭅니다. 모델은 로컬 런타임에서 실행되고, 파일은 디스크에서 읽으며,
공급자에게는 어떤 요청도 보내지 않습니다. 날씨나 가격 같은 실시간 정보는 '웹 검색'이 켜져 있을 때만(새로 설치하면 꺼져 있습니다) 공개 웹 서비스에서 가져오며, '로컬 전용'에서는 절대 가져오지 않습니다.

## 클라우드(공급자 이름)

선택한 컨텍스트가 내 컴퓨터에서 내 키를 사용해 선택한 공급자에게 바로 전송됩니다.

'선택한 컨텍스트'란 앱이 그 요청을 위해 모은 것을 말합니다. 내 프롬프트에 더해, 요청에 필요한
파일과 이전 턴입니다.

{% hint style="danger" %}
클라우드 모드는 데이터를 내 컴퓨터 밖으로 보냅니다. 그것이 클라우드 모드의 목적입니다. VOOL이
말하는 것은 *경로*에 관한 것입니다. 요청은 내 컴퓨터에서 내 공급자에게 갑니다. 아무것도
전송되지 않는다는 말이 아닙니다.
{% endhint %}

## 그 사이에 있는 것

Parad0x Labs가 운영하는 것은 아무것도 없습니다. 모델 트래픽을 위한 프록시도, 게이트웨이도,
중계 서버도 없습니다. 내 키는 내 컴퓨터의 앱이 공급자와 직접 통신하는 데 사용합니다.
