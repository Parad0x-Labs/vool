# 도구

도구는 런타임이 나를 대신해 할 수 있는 동작입니다. 파일 읽기, 명령 실행, 폴더 검색 같은
것입니다.

## 설계부터 검사 가능

모든 도구 호출은 무엇이 요청되었고, 무엇이 실행되었고, 무엇이 돌아왔는지 기록합니다. 실행 내용은
다시 실행하지 않고도 나중에 읽어 볼 수 있습니다.

## 권한

도구가 바로 실행될지 먼저 물을지는 내가 고른 모드와 동작에 따라 달라집니다. 새 채팅은 수동 모드로
시작하며, 이 모드에서는 모든 변경 전에 먼저 묻습니다. 자동 모드에서는 파일 생성과 편집, 명령,
네트워크 동작이 묻지 않고 실행되지만, 삭제, 덮어쓰기, 설치, Git 커밋과 푸시, 배포, 메시지 보내기,
결제, 설정 변경은 여전히 묻습니다. 모든 모드에서 파일 도구는 [작업 공간](workspaces.md) 안에서만
작동하고, 검색과 가져오기 도구는 아무것도 쓰지 않고 공개 자원만 읽으며, 저장된 비밀 정보는 절대
읽지 않습니다. 다섯 가지 모드 전체와 각 승인 버튼이 허용하는 것은 [권한](permissions.md)에서
다룹니다.

```text
tool: read_file
path: src/main.py
result: 412 lines
```

[영수증](receipts.md)도 참고하세요.
