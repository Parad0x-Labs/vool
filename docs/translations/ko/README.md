# VOOL

VOOL은 데스크톱 AI 어시스턴트입니다. 컴퓨터에 애플리케이션으로 설치되며, AI 모델을 그 컴퓨터에서
로컬로 실행하거나 내 API 키로 클라우드 AI 공급자에 연결할 수 있습니다. 수행하는 모든 작업을
읽을 수 있는 기록으로 남깁니다.

무료입니다. 로컬 모델을 쓰면 채팅과 파일에 인터넷 연결이 필요 없습니다. 날씨나 가격 같은 실시간 정보는 '웹 검색'이 켜져 있을 때만 공개 웹 서비스에서 가져옵니다. Mac(Apple Silicon 및 Intel)과 Linux x86_64용
다운로드가 있으며, Windows는 실험적 지원으로 소스에서 설치합니다.

이 문서는 VOOL 설치, 모델 연결, 그리고 VOOL이 내 파일과 메모리, 키를 어떻게 다루는지에 대한
개념을 설명합니다.

## 성능 비교

한 번도 사용되지 않은 LoCoMo 메모리 문항 150개에서, 모든 에이전트에 같은 모델이 답하고 같은 GPT-4o가
채점했을 때 VOOL의 메모리는 다른 오픈 소스 에이전트 두 개보다 나은 결과를 냈습니다.

| | VOOL | OpenClaw | Hermes |
| --- | --- | --- | --- |
| 정답 | **82.7%** (124 / 150) | 71.3% (107) | 62.7% (94) |
| 질문당 토큰 | **9.6k** | 51.8k | 33.5k |
| 질문당 비용 | **$0.0033** | $0.0100 | $0.0046 |

OpenClaw보다 토큰을 5.4배, Hermes보다 3.5배 적게 쓰며, 답변당 비용은 OpenClaw의 삼분의 일입니다.
VOOL 0.7에 들어 있던 메모리는 같은 문항에서 150개 중 123개를 맞혔습니다.
모든 실행 결과와 설정, 약점을 공개합니다: [메모리 벤치마크](https://github.com/Parad0x-Labs/vool/tree/main/docs/benchmarks).

## VOOL은 이런 앱입니다

* **데스크톱 애플리케이션.** 컴퓨터에 설치됩니다. 브라우저 탭도, 호스팅 서비스도
  아닙니다.
* **채팅과 파일은 오프라인에서 작동.** 로컬 모델을 선택하면 채팅과 파일에 인터넷 연결이 필요 없습니다. 날씨나 가격 같은 실시간 정보는 '웹 검색'이 켜져 있을 때만(새로 설치하면 꺼져 있습니다) 공개 웹 서비스에서 가져오며, '로컬 전용'에서는 절대 가져오지 않습니다.
* **기본은 로컬.** 로컬 모델을 선택하면 프롬프트와 파일이 내 컴퓨터에서
  처리됩니다.
* **모델에 구애받지 않음.** 로컬 런타임과 클라우드 공급자를 모두 선택할 수 있습니다. 클라우드 키는
  직접 준비하며, 키는 내 컴퓨터에 남습니다.
* **검증 가능.** 모든 도구 호출이 입력과 결과와 함께 기록되므로, 실행 내용을
  나중에 다시 읽어 볼 수 있습니다.

{% hint style="warning" %}
VOOL은 Apple Silicon Mac, Intel Mac, Linux x86_64용 베타입니다. Mac 앱은
아직 Apple 공증을 받지 않아서, 처음 열 때 macOS가 확인을 요청합니다.
[설치](getting-started/install.md#mac에서-처음-열기) 페이지에서 방법을 볼 수 있습니다. 설치하기 전에
[릴리스 상태](trust/release-status.md)를 확인하세요.
{% endhint %}

## 두 가지 답변 방식, 분명하게

VOOL은 두 가지 방식으로 답하며, 다음 요청이 어느 방식으로 실행되는지 채팅 헤더에 항상 표시됩니다. 예를 들어 **자동**과 **로컬 우선**입니다.

1. **로컬** — 작업이 이 컴퓨터 안에 머뭅니다.
2. **클라우드** — 선택한 컨텍스트가 내 컴퓨터에서 내 키를 사용해
   선택한 공급자에게 바로 전송됩니다.

중간에 Parad0x가 운영하는 중계 서버는 없습니다. 자세한 내용은
[데이터 처리](trust/data-handling.md)에 있습니다.
