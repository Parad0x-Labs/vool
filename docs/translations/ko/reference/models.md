# 지원 모델

VOOL에는 모델이 포함되어 있지 않습니다. 첫 로컬 모델은 처음 사용할 때 내려받습니다. 내가 고른 런타임과 공급자에 연결합니다.

## 로컬 런타임

Ollama, llama.cpp, vLLM, MLX는 자동으로 감지됩니다. localhost에서 OpenAI 호환 엔드포인트를 제공하는 다른 런타임은
직접 지정할 수 있습니다.

## 클라우드 공급자

클라우드 모델에는 내 컴퓨터에서 내 키로 접속합니다. 클라우드 모델을 선택하면 앱이 클라우드 모드가
됩니다(표시에 공급자 이름이 나타남). [로컬과 클라우드](../concepts/local-and-cloud.md)를
참고하세요.

[OpenRouter](../guides/openrouter.md)는 가장 폭넓은 단일 연결입니다. 키 하나로 여러 공급자를 쓸
수 있습니다.

## 고르기

| 작업 | 적절한 선택 |
| --- | --- |
| 비공개 파일, 네트워크 없음 | 로컬, 7B 이상 |
| 일상적인 코딩 | 로컬 7–14B 코딩 모델 |
| 긴 추론 | 더 큰 클라우드 모델 |
| 비용 관리 | 먼저 로컬, 그럴 가치가 있을 때 클라우드 |
