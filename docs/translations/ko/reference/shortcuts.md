# 키보드 단축키

macOS에서는 `⌘`, Windows와 Linux에서는 `Ctrl`입니다.

| 동작 | 단축키 |
| --- | --- |
| 새 세션 | `⌘ N` |
| 명령 팔레트 | `⌘ K` |
| 모델 전환 | `⌘ M` |
| 작업 공간 패널 열기/닫기 | `⌘ J` |
| 현재 실행 중지 | `Esc` |
| 설정 | `⌘ ,` |
