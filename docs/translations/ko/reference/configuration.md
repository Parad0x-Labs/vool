# 구성

## 위치

VOOL은 설정, 채팅, 메모리, 기록을 하나의 런타임 홈(runtime home)에 보관합니다.

| 설치 | 런타임 홈 |
| --- | --- |
| macOS 앱 | `~/Library/Application Support/VOOL/runtime` |
| Linux tarball 및 소스 설치 | `~/.vool_runtime` |
| Windows(실험적, 소스에서 설치) | `%LOCALAPPDATA%\VOOL` |

VOOL을 시작하기 전에 `VOOL_HOME`을 설정하면 그 폴더를 대신 사용합니다. 시작 로그에는 사용 중인
홈이 출력됩니다.

키는 설정 파일이나 로그에 기록되지 **않습니다**. 키는 이 런타임 홈 안의 별도 자격 증명 파일에
암호화되어 보관되며, 내 사용자 계정만 읽을 수 있습니다. Mac에서 VOOL이 이미 macOS 키체인에
보관하던 키는 그대로 그곳에 남습니다. [보안 모델](../trust/security.md#키)을 참고하세요.

## 설정

설정은 앱의 **설정**에서 바꿉니다. VOOL이 무엇을 할 수 있는지 정하는 설정은 다음과 같습니다.

* **모델** — 활성 모델이며, 턴이 로컬인지 클라우드인지를 결정합니다.
* **작업 공간** — 채팅이 작업하는 프로젝트 폴더입니다. VOOL이 접근할 수 있는 다른 폴더는
  [작업 공간](../concepts/workspaces.md)을 참고하세요.
* **작동 모드** — 여기가 아니라 메시지 입력란 옆의 메뉴에서 고릅니다. 수동은 모든 변경 전에 묻고,
  자동은 일상적인 편집과 명령을 실행하게 하되 삭제, 덮어쓰기, 설치, 지출, 설정 변경은 여전히
  묻습니다. [권한](../concepts/permissions.md)을 참고하세요.
* **웹 접근과 암호화폐** — 둘 다 내가 켜기 전까지 꺼져 있습니다.

VOOL은 제품 텔레메트리를 보내지 않으므로 제품 텔레메트리 설정도 없습니다.

## 초기화

VOOL을 종료하고 런타임 홈을 다른 곳으로 옮겨 두세요. 작업 공간 파일은 건드리지 않으며, VOOL은 새
프로필로 다시 시작합니다. 저장된 키도 함께 옮겨지므로 **설정 → API 키**에서 다시 추가하세요.
macOS 키체인에 보관된 키는 키체인 접근에서 제거할 때까지 그곳에 남습니다.
