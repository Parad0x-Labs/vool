# VOOL로 코딩하기

## 작업 공간을 저장소로 설정하기

[작업 공간](../concepts/workspaces.md)이 프로젝트 루트를 가리키게 하세요. VOOL은 트리 전체를
불러오지 않고 필요한 파일만 읽습니다.

## 코드를 기준으로 묻기

파일이나 심볼의 이름을 말하면 런타임에 출발점이 생깁니다.

> `src/auth/`에서 세션 시간 제한이 설정된 곳을 찾고, 시간이 만료되면 어떤 일이 일어나는지
> 설명해 줘.

## 적용하기 전에 검토하기

수동 모드에서는 모든 편집 전에 먼저 묻습니다. 자동 모드에서는 일상적인 편집과 명령이 자동으로
실행되어 활동 기록에 표시되며, 삭제와 덮어쓰기는 여전히 묻습니다. 큰 변경 전에는 커밋해 두세요.
그러면 diff를 읽기 쉽고 되돌리기도 쉽습니다.

## 로컬 또는 클라우드

코딩은 두 모드 모두에서 됩니다. 7B 로컬 코딩 모델로 대부분의 일상적인 편집을 처리할 수 있고,
더 큰 클라우드 모델은 더 긴 추론을 처리합니다. 보내기 전에 모드 표시가 어느 쪽이 활성인지
알려 줍니다.
