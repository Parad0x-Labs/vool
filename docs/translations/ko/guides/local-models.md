# 로컬 모델 실행

## 런타임 설치

VOOL은 로컬 모델 서버와 통신합니다. macOS 앱에는 자체 로컬 모델 실행 프로그램이 들어 있으므로
Mac에서는 이 단계를 건너뛰어도 됩니다. Linux와 소스 설치에서는 Ollama 같은 서버를 설치해 시작한
다음 모델을 내려받으세요(pull).

```bash
ollama serve
ollama pull qwen2.5-coder:7b
```

## VOOL이 런타임을 가리키게 하기

**설정 → 모델과 공급자**를 여세요. 실행 중인 로컬 런타임은 자동으로 감지됩니다. 모델을 선택하면
모드 표시가 로컬로 바뀝니다.

## 한 번 인증하기

로컬 모델은 인증을 받은 뒤에만 답변을 작성합니다. **설정 → 모델과 공급자 → 로컬 모델**을 열고
모델을 등록한 다음 **Certify**를 선택하세요. 인증은 내 컴퓨터에서 짧은 도구 검사를 실행합니다.
아무것도 내려받지 않고 누구에게도 연락하지 않습니다. 모델이 통과하기 전까지 VOOL은 그 모델이
최종 답변을 작성하지 못하게 합니다.

## 크기

| 모델 크기 | 필요한 메모리(RAM) | 알맞은 용도 |
| --- | ---: | --- |
| 3B | ~4 GB | 짧은 편집, 간단한 질문 |
| 7–8B | ~8 GB | 일반 용도, 대부분의 코딩 |
| 14B | ~16 GB | 더 긴 추론 |
| 32B+ | 32 GB 이상 | 더 무거운 작업, 더 느림 |

{% hint style="info" %}
양자화된 빌드는 메모리를 크게 줄입니다. 4비트로 양자화한 7B 모델은 약 5 GB에서 여유 있게
실행됩니다.
{% endhint %}

## 느릴 때

* 더 작거나 더 강하게 양자화된 모델을 고르세요.
* 메모리를 많이 쓰는 다른 애플리케이션을 닫으세요.
* 컨텍스트를 줄이세요. 요청에 들어가는 파일이 적을수록 처리할 양도 줄어듭니다.
