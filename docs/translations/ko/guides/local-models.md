# 로컬 모델 실행

## 런타임 설치

VOOL은 기본적으로 Ollama를 사용해 로컬 모델을 실행합니다. OpenAI 호환 엔드포인트가 있는 다른 로컬 런타임도 작동합니다. Ollama는 별도의 프로그램으로, [ollama.com](https://ollama.com)에서 따로 설치합니다. macOS 앱에는 자체 로컬 모델 실행 프로그램이 들어 있으므로
Mac에서는 이 단계를 건너뛰어도 됩니다. Linux와 소스 설치에서는 Ollama를 설치해 시작한
다음 모델을 내려받으세요(pull).

```bash
ollama serve
ollama pull qwen3:4b
```

VOOL은 기본적으로 로컬 모델을 대신 골라 줍니다. 내 컴퓨터에 맞는 크기의 Qwen 모델입니다. 많은 컴퓨터에서 그 모델은 `qwen3:4b`이고, 메모리가 32 GB 이상인 컴퓨터에서는 더 큰 Qwen 모델이 기본입니다.

## VOOL이 런타임을 가리키게 하기

**설정 → 모델과 공급자**를 여세요. 실행 중인 로컬 런타임은 자동으로 감지됩니다. 모델을 선택하면
모드 표시가 로컬로 바뀝니다.

## 한 번 준비하기

로컬 모델은 VOOL이 확인한 뒤에만 답변을 작성합니다. **설정 → 모델과 공급자 → 로컬 모델**을 열고 모델 옆의 **이 모델 사용**을 누르세요. VOOL은 내 컴퓨터에서 그 모델이 VOOL의 도구를 충분히 잘 써서 대신 답할 수 있는지 조용히 확인합니다. 확인에는 한두 분쯤 걸릴 수 있으며, 아무것도 내려받지 않고 누구에게도 연락하지 않습니다. 통과하면 모델에 **준비됨**이 표시되고 VOOL이 그 모델로 답합니다. 그 전까지 VOOL은 그 모델이 최종 답변을 작성하지 못하게 합니다.

* **잘 맞지 않음:** 모델이 VOOL의 도구를 충분히 잘 쓰지 못합니다. VOOL이 대신 할 수 있는 일을 보여 줍니다. 이 컴퓨터에 맞게 고른 모델을 쓰거나 내려받거나, 클라우드 모델을 쓰세요.
* **확인이 끝나지 않음:** Ollama가 열려 있는지 확인한 다음 **다시 시도**를 누르세요. 느린 컴퓨터는 한 번 더 시도해야 할 수 있습니다.

VOOL이 시작될 때 준비된 로컬 모델이 없으면, 이 컴퓨터에 있는 모델 중 최대 세 개를 내가 고른 모델부터 확인하고 처음 통과한 모델을 사용합니다. 이 컴퓨터에 너무 큰 모델은 건너뜁니다. 준비된 모델은 항상 준비되지 않은 모델보다 먼저입니다.

## 크기

| 모델 크기 | 필요한 메모리(RAM) | 알맞은 용도 |
| --- | ---: | --- |
| 3B | ~4 GB | 짧은 편집, 간단한 질문 |
| 7–8B | ~8 GB | 일반 용도, 대부분의 코딩 |
| 14B | ~16 GB | 더 긴 추론 |
| 32B+ | 32 GB 이상 | 더 무거운 작업, 더 느림 |

{% hint style="info" %}
양자화된 빌드는 메모리를 크게 줄입니다. 4비트로 양자화한 7B 모델은 약 5 GB에서 여유 있게
실행됩니다.
{% endhint %}

## 느릴 때

* 더 작거나 더 강하게 양자화된 모델을 고르세요.
* 메모리를 많이 쓰는 다른 애플리케이션을 닫으세요.
* 컨텍스트를 줄이세요. 요청에 들어가는 파일이 적을수록 처리할 양도 줄어듭니다.
