# 스킬 찾기와 Eyebrow 검사

스킬 및 플러그인 페이지에는 **탐색**, **스킬 코덱스**, **내 추가 기능**, **보안**의 네 탭이
있습니다. 탐색은 앱과 함께 제공되는 텍스트 전용 VOOL 스킬 53개를 포함해 VOOL 자체 스킬을 먼저
보여 주고, 그다음 검토된 카탈로그 추가 기능을 보여 주며, 공개 GitHub 저장소를 고정된 리비전으로
조회할 수 있습니다. 스킬 코덱스는 VOOL 팀 스킬을 편집자 추천과 주목할 항목보다 위에 먼저 보여
줍니다. 검색은 대소문자와 흔한 구분 기호를 무시하며, 카테고리와 정렬 컨트롤로 목록을 좁힐 수
있습니다. 출처, 라이선스, 리비전, 요구 사항은 내려받기 전에 볼 수 있습니다.

## 처음 사용할 때

1. 보안 탭에 Eyebrow API 키를 저장하세요. 설정 → API 키에서도 저장할 수 있습니다. 키는 기존 자격
   증명 저장소가 관리합니다. 저장만으로는 연결을 테스트하거나 무엇을 검사하지 않습니다. 연결
   테스트를 눌러야 명시적으로 Eyebrow에 연결합니다.
2. 탐색에서 스킬을 고르고, 그 공개 콘텐츠를 내려받아 Eyebrow로 보내는 것을 승인하세요. 이는
   요금제에 따라 서비스의 검사 허용량을 소모합니다. 자동 재시도는 없습니다.
3. 돌아온 보고서를 읽으세요. HTTP 응답이 성공했다는 것만으로는 깨끗한 결과가 아닙니다. 이 초기
   카탈로그는 발견 사항과 정책 위반이 없는 완전한 `pass` 보고서일 때만 설치를 허용합니다. 거부하면
   준비된 다운로드를 설치하지 않고 버립니다.
4. 설치를 따로 수락하세요. VOOL은 라이선스를 보존하고, 기존 플러그인 수명 주기를 통해 설치하고,
   검토된 정확한 패키지를 검증한 다음 스킬을 켭니다. 스킬이 제안할 수 있는 모든 동작에는 기존
   권한이 그대로 적용됩니다.

검사는 특정 바이트에 대한 공급업체의 평가일 뿐, 안전성, 호환성, 답변 품질을 보장하지 않습니다.
카탈로그에 포함되었다고 게시자가 인증된 것은 아닙니다.

## 경계

콘텐츠는 40자 고정 리비전의 공개 GitHub 저장소에서만 가져오며, 스킬 파일과 라이선스 파일은
SHA-256으로 고정됩니다. 이 버전에는 비공개 저장소, 압축 파일 해제, 설치 스크립트, 실행 파일/MCP
플러그인 가져오기 기능이 없습니다. Eyebrow에는 독립된 SKILL.md만 보내며, 로컬 채팅, 작업 공간
파일, 자격 증명, 라이선스 내용은 검사용으로 제출하지 않습니다.

다운로드는 검토와 수락 전까지 아무 작용도 하지 않습니다. 로컬에서 인증된 영수증이 보고서를 고정된
콘텐츠에 묶습니다. 설치는 만료된 검토(24시간), 수정된 준비 파일, 이미 있는 대상 디렉터리를
거부합니다. 런타임은 관리되는 스킬을 모델 컨텍스트에 추가하기 전에 수명 주기 상태와 검토된
바이트를 확인합니다. 파일이 추가되거나, 심볼릭 링크가 생기거나, 내용이 바뀌면 그 스킬은 사용할 수
없게 됩니다. 지침은 통째로 삽입되거나, 프롬프트 예산이 부족해 빠졌다고 명시적으로 기록됩니다.
검사된 지시가 조용히 잘리지는 않습니다.

이러한 검사는 이미 운영 체제 사용자 권한으로 실행 중인 악성 코드를 격리하지 않습니다. 이전부터
수동으로 설치되어 있던 플러그인에는 적용되지 않습니다. 검사 영수증으로 새 실행 권한이나 지갑
권한이 부여되지는 않습니다.

## API와 실패 처리

`GET /api/addons`는 연결 테스트나 검사 없이 카탈로그와 로컬 상태를 돌려줍니다. `POST /api/addons`는
`save_key`, `remove_key`, `test_key`, `scan`, `install`, `reject`를 지원합니다. 변경 요청은
루프백, JSON, 같은 출처의 브라우저 요청이어야 하며, 작업별 필드만 받습니다. 호출자가 제공한 소스
URL과 경로는 거부됩니다.

클라이언트는 `/v1/scan`에서 Eyebrow v1의 인라인 스킬 소스 요청을 사용하며, bearer 인증, 고정된
HTTPS 출처, 리디렉션 없음, 제한된 응답 크기, 자동 재시도 없음이 적용됩니다. 명시적인 연결
테스트에는 `/v1/version`을 사용합니다. API 참조: https://eyebrow.cc/api/reference .

흔히 보는 유형별 실패는 다음과 같습니다.

| 코드 | 의미 / 복구 |
| --- | --- |
| `eyebrow_key_missing` / `eyebrow_unauthorized` | 키를 저장하거나 교체하세요. |
| `eyebrow_quota` | 다시 시도하기 전에 서비스 허용량을 확인하세요. |
| `eyebrow_timeout` / `eyebrow_unreachable` | 자동 재시도는 없습니다. 시간이 초과된 검사도 허용량을 소모할 수 있습니다. |
| `eyebrow_invalid_report` / `eyebrow_no_coverage` | 증거가 불완전합니다. 아무것도 켜지지 않습니다. |
| `addon_source_changed` / `addon_changed` | 고정되거나 검토된 바이트가 다릅니다. 활성화하지 마세요. |
| `review_untrusted` / `review_expired` | 설치하기 전에 새 검토를 받으세요. |
| `addon_already_installed` | 기존 파일은 보존되었습니다. 자동 교체는 구현되어 있지 않습니다. |

## 현재 제한 사항과 검증

자동 업데이트, 임의 카탈로그 가져오기, 이미 있는 변경된 팩의 제자리 복구/재설치 흐름은 없습니다.
앱을 다시 시작한 뒤 대기 중인 검토를 복구하는 기능은 UI에 노출되어 있지 않습니다. 새 인터페이스
문자열은 현재 영어로 대체 표시되며, 완전한 번역을 주장하지 않습니다.

자동화된 테스트는 공개 다운로드와 Eyebrow 응답을 명시적으로 모의(mock)한 상태에서 실제 수명 주기,
스킬 불러오기, API 처리기, 제공되는 브라우저 UI를 실행합니다. 이 테스트는 런타임과 인터페이스
동작을 증명할 뿐, 실제 Eyebrow 가용성이나 모델의 역량을 증명하지 않습니다. 실제 키를 쓰는 검사와
네이티브 패키지 앱 수락은 릴리스 점검으로 남아 있습니다. 이 테스트를 실행하는 데 키나 유료 서비스
호출은 필요하지 않습니다.
